## 2. 未割り当て454問からの追加

- 計算問題（168問）は、各科目の「解き方」の章（`*-forms`）に結びついているので、論点の章には足していない。
- 記述・組合せ・物質選択の問題の論点（pt-／qp-）のうち、論点の章に入れるものを177件、既存の章に足した（`qpoint_chapters.yaml`）。主な足し先：一般の化学物質による健康障害（がん、10件）、関係法令の測定対象・頻度（th03、6件）、デザインの物性（tp13、12件）・ろ過捕集（tp10、9件）、粉じんのろ過材・フィルター（tp06、9件）、特定化学物質の物質別測定法（tp01、28件）など。
- 特定化学物質の構造式・官能基の問題（6問）は、解法の章（`bk-tokka-forms` テーマ8）で扱っているので、足していない。
- 既存の章に入らない86件は、新しい章の候補にした（`new_chapter_candidates.yaml`）。

## 5. サイト側への連絡

- 割り当ては、問題文のキーワードによる仕分けで、論点名だけの規則より精度は上がったが、境界の点は残っている。
- 新章候補を採用する場合、同じ論点が元の章と候補の両方に出ないよう、元の章から外してほしい。
