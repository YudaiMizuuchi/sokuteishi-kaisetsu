## 2. 作業の手順（コマンド）
```

python3 tools/build_substances.py           # 物質別の一覧（/tmp/GB3.txt, /tmp/GB4.txt が必要）
```

### JIS（日本産業規格）の扱い（2026年11月6日）
- JIS も根拠資料に加える（分析機器・分析方法・保護具など。選択科目の分析方法は、JISの試験方法〔例：JIS K 0102〕を元にしたものが多い）。参照先：kikakurui.com（簡易閲覧）。**旧版が混じるので、規格番号に制定（改正）年を付けて記録する**（例：JIS T 8152:2012）。
- 確認は、法令・告示・通達と同じく、**サイト構築側が行ったものを正とする**。参考書執筆側は、JISの根拠どりをしなくてよい（確認してほしい記述を、執筆メモに書く）。
- 確認結果は、`data/law/JIS_<番号>_<年>_要点.md` に残す（本文は写さず、要点・数値・箇条番号）。すでにある：JIS T 8152:2012（防毒マスク。吸収缶の色。保存ページから確認）。
- kikakurui.com のページは、取得ツールが、検索結果・提供されたURLにないものを開けない。規格番号で検索してから開く。開けないときは、ページの保存（ZIP）かURLを、本人に依頼する。現行版かどうかは、このサイトだけでは判定できないので、年つきで記録し、確認できた範囲で書く。
- 優先順位：法令・告示・通達 → 登録講習テキスト（科目内容） → JIS（裏付け）。食い違うときは、整合メモで指摘する。
