## 1. 今の状態（要点）
- 公開問題 2,800問（共通4科目×460、選択4科目×240）。解説は、選択科目で36問が未執筆（`explanation` が空）。細かい論点（`minor_note`）が58問。
- **問題の区分は5ランク（S・A・B・C・D）**。S・A・B＝既出で、科目内の相対評価（境目は `tools/compute_freq.py` の `THRESHOLDS`）。C＝既出だが1回だけ。D＝完全な初見（捨てるのはDだけ）。解法の印：暗記／原理／消去法／トレンド／物質の表／初見。
- 判定の入力：論点（`data/master/points.yaml`）の回数、共通科目のパターン（`book.yaml`）、問題単位の回数、原理（`data/master/principles.yaml`。分析・有機溶剤・特定化学物質・金属類・鉱物性粉じんのみ）、物質の表（確認済みの物質のみ）。
- 期待得点率は、サイトに載せない（本人が把握するためだけ）。`python3 tools/backtest.py` → `/tmp/backtest.md`（受験者の立場：その回より前の出題だけで判定）。

## 2. 作業の手順（コマンド）
```
pip install janome pyyaml          # 初回のみ
python3 tools/build_points.py --update      # 論点マスタの更新（新しい回を追加したとき）
python3 tools/link_principles.py --apply    # 原理と論点の紐づけを反映（principle_links.yaml → principles.yaml）
python3 tools/compute_freq.py apply         # 区分・出題頻度を、各問の freq に書き込む
rm -rf _site && npx @11ty/eleventy          # ビルド（3,5xx ファイル）
python3 tools/backtest.py                   # バックテスト
python3 tools/fit_thresholds.py             # 境目の探索（結果を表示するだけ。反映は THRESHOLDS を手で書き換える）
python3 tools/ocr_xml_to_text.py <XML> /tmp/GB3.txt   # ガイドブックのOCR→テキスト
python3 tools/build_substances.py           # 物質別の一覧（/tmp/GB3.txt, /tmp/GB4.txt が必要）
```
ZIPは、`node_modules`・`_site`・`.git` を除いて、`/mnt/user-data/outputs/sokuteishi-site.zip` に出力する（依頼があったときだけ）。

## 3. 設計上の決定（変えない）
- 論点＝1つの事実のまとまり（細かめ）。ひっかけパターン＝論点、頻出テーマ＝論点のまとまり。章立ては、参考書の目次案を参考にした仮のもの（後で、論点のまとまりから見直す）。
- 原理への紐づけは、「正答の正誤が、その原理だけから直接導ける」ときだけ。暗記が要る事実は、紐づけない。
- ランクの境目は科目ごと、目標は S15％・A25％・B30％（CとDは、既出か初見かで決まる）。選択科目のBの下限は3回。
- 出題傾向は、共通科目で、令和5年度第1回以降、正答の既出率が急落している（一般2〜4割、関係法令4〜6割）。選択科目には断絶がない。
- 出典表記：書籍は書名のみ（章・ページは書かない。ただし、物質別の表は、ガイドブックのページを示す）。年度表記は「令和元年度」。
- 共通の注意：サイトの区分は、過去の全回にもとづく目安（カードに注意書きあり）。

## 5. 注意
- 論点マスタのキーは、（科目, 回|問|選択肢番号）。科目を含めないと、別の科目の論点を取り違える（過去にバグがあった）。
- `build_points.py` の自動グループ化は、決定的（実行のたびに同じ結果）。ただし、論点のIDは、`--update` を、同じ順序で実行する前提。
- バックテストの「期待得点率」は、受験者がS〜C（と、物質の表）を学習する前提の目安。選択科目の評価回数は少ない（5回）ので、傾向として見る。
- ガイドブック3・4のOCRは、誤りがある。物質ごとの値は、本文を確認して、書き直したものだけを、`verified.yaml` に入れる。
