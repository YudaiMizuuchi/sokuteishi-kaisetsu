# 参考書の執筆計画（2026年11月15日 改訂。運営者の承認済み）

## 1. 方針（決まったこと）

- **参考書で扱うのは、体系的・原理的に学ぶ事項**（ランク S・A の論点と、同じ原理・同じ表にぶら下がる B）。**演習で覚える事項**（ランク C・D、単独の暗記の B）は、過去問の解説と一問一答の中で完結させ、参考書の表の行にしない。
- B は、ランクでは決めず、性質で分ける：S・A の論点と同じ原理・同じ表の中にあるものは参考書に入れ、単独の暗記事項（数値、物質名、条文の細目）は演習に回す。
- 残りの章は、**S・A が核の章だけ**を書く。物質表の章と、C の論点だけの章は、書かない。
- 章は軽くする（本文 3,000〜4,000字が目安）。表の行は、S・A と、ぶら下がる B だけ。出た回の並び、「問題文に出る回数」、根拠の注記（「過去問の正答による」「ナレッジにない」）、章・節番号つきの出典は、本文に書かない。根拠は、書籍名・法令名だけを、末尾に書く。正確さの確認は、これまでどおりサイト側で行うが、本文には出さない。
- 書いてある93章は、すぐには書き直さない。**重い章を1〜2章だけ新しい形に直して、見比べてから決める**。

- 「章全体の回数」（章の論点の和集合）は、1回ずつの論点を足し合わせても大きくなる。**章の順番は、一番多い論点（原理の章は、原理としての回数）のランクと、未執筆で止まっている S・A の問題の数で決める**。
