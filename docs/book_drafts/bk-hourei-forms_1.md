## 導入クイズ

**Q1** 鉛業務を行う屋内作業場の作業環境測定は、何か月（何年）以内ごとに1回か。

① 1か月　② 6か月　③ 1年

**Q2** 厚生労働大臣が定める規格を具備しなければ、譲渡・貸与できない防毒マスクは、どれか。

① 送気マスク　② 硫化水素用防毒マスク　③ アンモニア用防毒マスク

**Q3** 製造に際して、厚生労働大臣の許可が必要な物質は、どれか。

① オルト-トリジン　② MOCA　③ クロロメチルメチルエーテル

答え：Q1は③（鉛は1年以内ごとに1回。記録は3年保存）。Q2は③（防毒マスクの対象は、ハロゲンガス用・有機ガス用・一酸化炭素用・アンモニア用・亜硫酸ガス用の5種類。送気マスクと硫化水素用は、対象外）。Q3は①（オルト-トリジンは第1類物質。MOCAとクロロメチルメチルエーテルは、第2類物質）。3問とも、この章の表の1行で答えが出る。

## 3. そのほかの典型テーマ

### テーマ2　規格具備・型式検定の対象［S］

**出題実績**：23回中22回（問7が19回）。「厚生労働大臣が定める規格を具備しなければ、譲渡し、貸与し、又は設置してはならないものに該当しないもの」。「厚生労働大臣の登録を受けた者が行う型式検定を受けなければならないものに該当しないもの」の形でも出る。

**根拠**：労働安全衛生法第42条（譲渡等の制限等）、同施行令第13条第3項。型式検定は、法第44条の2、施行令第14条の2。

**覚える表**（過去問の正答と解説にもとづく）

| | 該当する（規格の具備、または型式検定が必要） | 該当しない |
|---|---|---|
| 防毒マスク | **ハロゲンガス用、有機ガス用、一酸化炭素用、アンモニア用、亜硫酸ガス用**の5種類 | シアン化水素用、硫化水素用、ホルムアルデヒド用、**酸性ガス用** |
| 防じん・電動ファン付き | ろ過材及び面体を有する防じんマスク（使い捨て式、吸気補助具付きを含む）、防じん機能を有する電動ファン付き呼吸用保護具、防毒機能（ハロゲンガス用・有機ガス用・アンモニア用・亜硫酸ガス用）を有する電動ファン付き呼吸用保護具 | **送気マスク**（規格も型式検定も対象外） |
| ほかの機械等（規格） | 排気量 40 cm³ 以上の内燃機関を内蔵するチェーンソー、波高値による定格管電圧が10キロボルト以上のエックス線装置（医療用などを除く）、再圧室、潜水器 | 光散乱方式による相対濃度計、放射線測定器、化学防護服、放射性物質による汚染防止のための防護服、防振手袋、放射線装置室 |

**覚え方**：防毒マスクの5種類は、「ハロゲン・有機・一酸化炭素・アンモニア・亜硫酸ガス」。測定や作業の道具のうち、**送気マスクと相対濃度計は、規格の対象ではない**。

**ひっかけパターン**：「シアン化水素用」「硫化水素用」「ホルムアルデヒド用」「酸性ガス用」の防毒マスクを、規格の対象にする。送気マスクを、型式検定の対象にする。

**例題**（2024-02|hourei|7）アンモニア用、亜硫酸ガス用、シアン化水素用の防毒マスク、防じん機能を有する電動ファン付き呼吸用保護具、防じんマスクのうち、該当しないもの。
→ シアン化水素用防毒マスク。

### テーマ3　有機溶剤等の区分［S］

**出題実績**：23回中18回（問14が18回）。二つのパターンがある。①有機溶剤の混合物の重量割合から、第1種・第2種・第3種有機溶剤等の区分を決める。②物質名と区分（第1種・第2種・第3種有機溶剤、特別有機溶剤、第3類物質）の組合せの誤りを選ぶ。

**混合物の区分の決め方**（有機則による区分。過去問の解説の手順）

1. 第1種有機溶剤が重量の**5％を超える** → **第1種有機溶剤等**。
2. 1に当たらず、第1種と第2種の**合計が5％を超える** → **第2種有機溶剤等**。
3. 1・2に当たらず、有機溶剤の**合計が5％を超える** → **第3種有機溶剤等**。
4. 合計が5％以下 → 有機溶剤等ではない。

「5％を超える」は、5％ちょうどを含まない。条文は、第2種の混合物を「第1種又は第2種を5％超」と書いている。合計で判断する運用は、通達による（過去問の解説の手順も、この運用）。

**物質の区分**（過去問の正答にもとづく。表に載せたのは、過去問で正誤が確かめられた物質）

| 区分 | 物質 |
|---|---|
| 第1種有機溶剤 | 1,2-ジクロルエチレン、二硫化炭素 |
| 第2種有機溶剤 | トルエン、キシレン、クロルベンゼン、1,1,1-トリクロルエタン、メチルエチルケトン、シクロヘキサノン |
| 第3種有機溶剤 | ミネラルスピリット、石油ベンジン、コールタールナフサ |
| 特別有機溶剤（特化則） | エチルベンゼン、クロロホルム、1,4-ジオキサン、スチレン、トリクロロエチレン、1,2-ジクロロエタン、1,2-ジクロロプロパン |
| 特化則の第3類物質 | フェノール |

**特別有機溶剤に該当しない（過去問）**：ノルマルヘキサン、二硫化炭素、エチルエーテル、ベンゼン、クロルベンゼン。

**根拠**：特別有機溶剤は、特化則第2条第1項第3号の2に規定する物質（作業環境測定基準の本文で確認）。有機溶剤は、施行令別表第6の2に掲げる物（同）。区分は、有機則第1条第1項第2〜5号と令別表第6の2の原文（サイト側の照合）と一致。

**ひっかけパターン**：「1,2-ジクロルエチレン／特別有機溶剤」「二硫化炭素／特別有機溶剤」「クロルベンゼン／特別有機溶剤」「ベンゼン／特別有機溶剤」「1,2-ジクロロエタン／第1種有機溶剤」。（1,2-ジクロルエチレンと二硫化炭素は第1種、クロルベンゼンは第2種、ベンゼンは特化則の別の区分、1,2-ジクロロエタンは特別有機溶剤。）

**例題**（2026-08|hourei|14）第1種・第2種・第3種の重量割合が、(1) 5％・5％・90％、(2) 4％・4％・92％、(3) 3％・3％・3％、(4) 2％・2％・2％、(5) 0％・0％・4％。第3種有機溶剤等はどれか。
→ (4)。第1種と第2種の合計が4％で、5％以下。有機溶剤の合計が6％で、5％を超える。

**例題**（2025-08|hourei|14）第2種有機溶剤等はどれか。（3）3％・4％・5％。
→ 第1種3％＋第2種4％＝7％で、5％を超える。

### テーマ4　製造許可が必要な物質［A］

**出題実績**：23回中10回（問6・8）。「その製造に際し厚生労働大臣の許可が必要となる物質」。

**覚えること**：製造に際して、厚生労働大臣の許可が必要なのは、特定化学物質の**第1類物質**（労働安全衛生法第56条、施行令第17条）。過去問で許可が必要とされた物質：**ベリリウム及びその化合物、オルト-トリジン、アルファ-ナフチルアミン、ベンゾトリクロリド**。

**許可が不要（第2類物質）**：MOCA、リフラクトリーセラミックファイバー、クロロメチルメチルエーテル、パラ-ジメチルアミノアゾベンゼン。

**ひっかけパターン**：MOCAを、第1類物質と思い込む。

**例題**（2023-02|hourei|6）MOCA、リフラクトリーセラミックファイバー、クロロメチルメチルエーテル、オルト-トリジン、パラ-ジメチルアミノアゾベンゼンのうち、製造に許可が必要なもの。
→ オルト-トリジン（第1類物質）。

### テーマ5　作業主任者の選任［A］

**出題実績**：23回中9回（問4・6）。「法令上、作業主任者の選任が規定されていないもの」「都道府県労働局長の免許を受けた者から選任するもの」。

**覚える表**（過去問の正答と解説にもとづく）

| 区分 | 作業 |
|---|---|
| **選任の規定がない** | 特定粉じん作業、屋内におけるアーク溶接作業 |
| 選任の規定がある（技能講習の修了者） | 酸素欠乏危険場所における作業、鉛蓄電池を解体する工程における鉛等の切断の業務に係る作業（鉛作業主任者）、有機溶剤作業主任者、特定化学物質作業主任者、石綿作業主任者 |
| 選任の規定がある（**免許**を受けた者） | **エックス線作業主任者**、ガンマ線透過写真撮影作業主任者、高圧室内作業主任者 |

**ひっかけパターン**：特定粉じん作業・アーク溶接作業に、作業主任者の選任が必要と思い込む。鉛・酸素欠乏・有機溶剤・石綿の作業主任者を、免許が必要と思い込む（正しくは技能講習）。

### テーマ6　特別教育の対象業務［B］

## 4. 解き方まとめ・公式まとめ

### 解き方まとめ

1. **定期測定（問4〜7）**：保存期間は、基本が3年。例外は、粉じん 7年、石綿 40年、放射線 5年、特別管理物質 30年。頻度は、基本が6か月。例外は、鉛 1年、放射線 1か月、暑熱 半月。5つの選択肢のうち、例外の項目から先に確かめる。
2. **規格具備・型式検定（問7）**：防毒マスクは、ハロゲンガス用・有機ガス用・一酸化炭素用・アンモニア用・亜硫酸ガス用の5種類だけ。送気マスクと相対濃度計は、対象外。
3. **有機溶剤等の区分（問14）**：混合物は、「第1種 ＞ 5％」→「第1種＋第2種 ＞ 5％」→「合計 ＞ 5％」の順。物質は、1,2-ジクロルエチレン・二硫化炭素が第1種、クロルベンゼン・トルエン・キシレンなどが第2種、特別有機溶剤は、特化則のエチルベンゼン・クロロホルム・トリクロロエチレンなど。
4. **製造許可**：第1類物質（オルト-トリジン、ベリリウム化合物、アルファ-ナフチルアミン、ベンゾトリクロリド）。MOCAは第2類。
5. **作業主任者**：特定粉じん作業とアーク溶接作業は、選任の規定なし。免許は、エックス線・ガンマ線透過写真撮影・高圧室内の作業主任者。
6. **改正のある項目は、年度を確かめる**：電離則の眼の水晶体の限度など。
