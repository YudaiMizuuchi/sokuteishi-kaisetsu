「作業環境測定を、誰が行うか」は、関係法令で毎回のように出る。①作業環境測定士の種類（第1種・第2種）と業務の範囲、②測定士でなくてもできる測定（指定作業場でない作業場）、③個人サンプリング法の登録と対象、④作業環境測定機関、の4つが中心。誤っているものを選ぶ形で、「第1種か第2種か」「登録を受けた作業場の種類の制限があるか」「指定作業場か」が、1つだけ崩してある。

**令和8年10月1日の改正（令和8年告示第325号ほか）**：作業環境測定法・同施行令・同施行規則に、「個人ばく露測定」の規定が加わった。令和8年度第1回（令和8年8月）までは改正前、**令和8年度第2回（令和9年2月）から、改正後の内容が出題されうる**。この章は、改正前から変わらない部分を中心に書き、改正後に加わる部分は、第6節に分けて書く。

## 導入クイズ

**Q1** 作業環境測定士の登録を取り消された者は、取消しの日から起算して何年を経過しないと、作業環境測定士となれないか。

① 1年　② 2年　③ 5年

**Q2** 作業環境測定士に行わせなければならない作業環境測定（指定作業場の測定）に、**当たらない**ものはどれか。

① 特定粉じん作業を行う屋内作業場の粉じん濃度の測定　② 坑内の作業場の粉じん濃度の測定　③ 有機溶剤を取り扱う屋内作業場の濃度の測定

**Q3** 個人サンプリング法について登録を受けられるのは、どの作業環境測定士か。

① 第1種のみ　② 第1種と第2種　③ 第2種のみ

答え：Q1は②（2年。法第6条第2号）。Q2は②（坑内の作業場は、令第21条第4号の作業場で、指定作業場ではない）。Q3は②（第2種も受けられる。規則第6条第1項第1号）。3問とも、この章の表の1行で答えが出る。

## 2. 作業環境測定士（法・施行規則）

**出題実績**：23回中20回（問8が14回。問6・9もある）。「作業環境測定士に関する次の記述のうち、法令上、誤っているもの」。

| 項目 | 第1種作業環境測定士 | 第2種作業環境測定士 |
|---|---|---|
| 指定作業場の測定 | 行える | 行える。ただし、**簡易測定機器以外の機器を用いて行う分析**（解析を含む）は、**除く**（法第2条第7号） |
| 指定作業場以外の事業場の測定 | 行える（第1種の名称で） | 行える（第2種の名称で） |
| **デザイン・サンプリング**（個人サンプリング法を除く） | **登録を受けた作業場の種類にかかわらず**、すべての指定作業場で行える（規則第3条第1項第1号ロ） | 行える（同） |
| **分析**（簡易測定機器以外） | **当該指定作業場の属する別表の作業場の種類について登録を受けた**第1種に限る（規則第3条第1項第2号イ） | **行えない** |
| 分析（簡易測定機器） | 行える | 行える。**作業場の種類にかかわらず** |
| 個人サンプリング法（デザイン・サンプリング） | **個人サンプリング法について登録を受けた**測定士に限る（第1種・第2種を問わない）（規則第3条第1項第1号イ、第6条第1項第1号・第4号） | 同じ |

**簡易測定機器**（規則第2条）：①検知管方式によりガス・蒸気の濃度を測定する機器（これと同等以上の性能のもの）、②グラスファイバーろ紙を装着して相対沈降径がおおむね10 µm以下の浮遊粉じんを重量法で測定する機器を標準として較正された、浮遊粉じんの重量を測定する機器（光散乱方式の相対濃度計など）、③その他厚生労働大臣が定める機器（第3号の機器は、確認できた範囲では、定められていない）。

**表②　資格・登録・取消し**（法第5〜7条、第11条、第12条、第18条、第44条、第4条。原文で確認）

| 項目 | 内容 |
|---|---|

| 欠格（第6条） | ①心身の故障で、業務を適正に行えない者、②登録を取り消され、**取消しの日から起算して2年を経過しない**者、③法令に違反して罰金以上の刑に処せられ、執行を終わってから**2年を経過しない**者 |
| 登録の取消し・業務停止（第12条） | 欠格に当たるとき、取り消す。**登録に関し不正の行為**、**作業環境測定基準に違反**（第4条第1項）、**虚偽の測定結果を表示**、作業環境測定の業務に関し不正の行為があったときは、登録の取消し、又は、**期間を定めて**指定作業場についての業務の停止・名称の使用の停止を命じられることがある |

**ひっかけパターン**（過去問で誤りとして出た組）

- 「登録を取り消された者は、**1年間**は測定士となれない」（正しくは、**2年**）。
- 「第1種測定士は、**登録を受けた作業場の種類以外**の指定作業場では、デザイン・サンプリングを行えない」（正しくは、行える。作業場の種類は、**分析**の範囲）。
- 「放射性物質の登録だけの第1種は、**光散乱方式の相対濃度計**による粉じん測定を行えない」（正しくは、行える。簡易測定機器による分析は、作業場の種類にかかわらず）。
- 「第2種測定士は、塩素の測定の**デザイン・サンプリング**を行えない」（正しくは、行える）。第2種が行えないのは、簡易測定機器以外の機器による分析。

## 3. 測定士に行わせなければならない測定（指定作業場）

**出題実績**：23回中20回のうち、多くが、このテーマ。「作業環境測定士でなければ行えない（行わせなければならない）」のは、**指定作業場の作業環境測定**だけ。

**表③　労働安全衛生法施行令第21条の作業場と、指定作業場**（作業環境測定法施行令第1条第1項、施行規則第1条。原文で確認。令和8年度第1回まで〔改正前〕）

| 令第21条 | 作業場 | 指定作業場 | 測定士でなくてよいか |
|---|---|---|---|
| 第1号 | 土石、岩石、鉱物、金属又は炭素の粉じんを著しく発散する**屋内**作業場（特定粉じん作業を行うもの） | **該当** | 測定士が行う |
| 第2号 | 暑熱、寒冷、多湿の屋内作業場 | 該当しない | 測定士でなくてよい |
| 第3号 | 著しい騒音を発する屋内作業場 | 該当しない | 同上 |
| 第4号 | **坑内**の作業場（炭酸ガス、気温、通気量） | 該当しない | 同上（**ずい道等の内部の粉じん**の測定も同じ） |
| 第5号 | 中央管理方式の空気調和設備を設けた建築物の室（事務所） | 該当しない | 同上 |
| 第6号 | 別表第2の放射線業務の作業場 | **放射性物質取扱作業室**（電離則第53条第2号）と**事故由来廃棄物等取扱施設**（同条第2号の2）に限り、**該当** | 空気中の放射性物質の濃度の測定は、測定士が行う。**管理区域の外部放射線の線量当量率などの測定は、測定士でなくてよい**。表面汚染の測定も、作業環境測定ではない |
| 第7号 | 特定化学物質（第1類・第2類）、石綿、コークス炉上の作業場（屋内） | **該当** | 測定士が行う。硫化水素、ホルムアルデヒド、エチルベンゼンなど、第2類物質を取り扱う屋内作業場の測定も、測定士が行う。**溶接ヒューム**（令別表第3第2号34の2）は、第7号から除かれ、**測定士でなくてよい** |
| 第8号 | 鉛業務を行う屋内作業場（令別表第4第1〜8号、第10号、第16号。遠隔操作の隔離室を除く） | **該当** | 測定士が行う |
| 第9号 | 酸素欠乏危険場所（酸素・硫化水素の濃度） | 該当しない | **測定士でなくてよい**（第2種酸素欠乏危険作業の硫化水素の測定を含む） |
| 第10号 | 有機溶剤を製造し、取り扱う屋内作業場（令別表第6の2） | **該当** | 測定士が行う |

**ほかに押さえること**

- **第3類物質**（二酸化硫黄など）は、令第21条第7号に含まれないので、指定作業場ではない。測定士でなくてよい。
- **指定作業場以外の作業場の測定**は、測定士でない者に行わせることができる。
- **管理区分の決定（評価）**は、測定士の独占業務ではない。**測定士でない者**にも行わせられる（作業環境評価基準による評価）。
- 事務所の室の測定項目：一酸化炭素・二酸化炭素の含有率、室温、外気温、相対湿度（2か月以内ごと）。**浮遊粉じん量は含まれない**（建築物衛生法の項目）。
- 室に供給される空気中の**ホルムアルデヒド**の量の測定は、指定作業場の測定ではなく、測定士でなくてよい。

**ひっかけパターン**（過去問で誤りとして出た組）

- 「第2種酸素欠乏危険作業の**硫化水素**濃度の測定は、測定士でなければ行えない」。
- 「**管理区域**の外部放射線の測定は、測定士に行わせなければならない」。
- 「放射性物質取扱作業室の**表面汚染**の測定は、測定士でなければ行えない」。
- 「**ずい道等**の内部（坑内）の粉じんの測定は、第1種測定士に行わせなければならない」。
- 「**指定作業場**の測定の**評価**は、測定士でない者に行わせられない」。

## 4. 個人サンプリング法

**出題実績**：23回中11回（令和3年度第1回以降の11回は、毎回。問9・11）。個人サンプリング法は、労働者の身体に装着する試料採取機器等を用いて行うデザイン・サンプリング（規則第3条第1項第1号イ）。**C測定**（単位作業場所の全体を代表する測定）と**D測定**（発散源に近接して、濃度が最も高くなると思われる時間の15分間の測定）から成る（作業環境測定基準第10条第5項。手順は、`bk-design-forms` テーマ6）。

**表④　個人サンプリング法の登録・対象・手順**（施行規則第3条・第6条・第52条・第54条、作業環境測定基準第2条第4項・第10条第5項・第11条・第13条第5項、作業環境評価基準第4条。原文で確認）

| 項目 | 内容 |
|---|---|
| 登録を受けられる者 | **第1種・第2種のどちらも**（規則第6条第1項第1号：登録講習の科目のうち個人サンプリング法に係るものを修了した者）。「第1種でなければ登録できない」は**誤り** |
| 登録が必要な業務 | 指定作業場の**デザイン・サンプリング**を個人サンプリング法で行うとき。**簡易測定機器を用いるものも含めて**、登録が必要（例外の規定はない）（規則第3条第1項第1号イ） |
| 登録が**不要**な業務 | **分析**。個人サンプリング法による測定の分析は、登録のない測定士でも行える。ただし、簡易測定機器以外の機器による分析は、作業場の種類について登録を受けた第1種に限る（規則第3条第1項第2号） |
| 登録を受けた測定士の範囲 | **作業場の種類にかかわらず**、個人サンプリング法の対象となる測定の個人サンプリングを行える。有機溶剤の登録だけの第1種でも、個人サンプリング法の登録があれば、特定化学物質のデザイン・サンプリングを行える |
| 作業環境測定機関 | 個人サンプリング法を行う機関は、**個人サンプリング法について登録を受けた測定士**（第1種・第2種を問わない）が置かれていること（規則第54条第1号）。これとは別に、分析を行う作業場の種類ごとに、その種類について登録を受けた**第1種**測定士が置かれていること（同条第2号）。両者を混ぜた「指定作業場の種類ごとに、個人サンプリング法について登録を受けた第1種測定士を1人」は**誤り** |
| 対象になるもの（作業環境測定基準） | **粉じん**：遊離けい酸の含有率が**極めて高いもの**を除く（第2条第4項）。**特定化学物質**：令別表第3の**一部の物**だけ（第10条第5項に列挙。**管理濃度の値で一律に決まるのではない**）。**鉛**（第11条）。**有機溶剤**：令別表第6の2の**すべて**。特別有機溶剤も含む（第13条第5項） |
| 対象にならないもの | **石綿**（ろ過捕集方法と計数方法。第10条の2）、**放射性物質**（第9条）。特定化学物質のうち、第10条第5項に列挙されていない物 |
| 手順（C測定） | ばく露量がほぼ均一と見込まれる**作業ごと**に、適切な数の労働者に装着。数は**5人を下回ってはならない**。採取時間は**全時間**（2時間を超え、濃度がほぼ均一なら、2時間を下回らない範囲で短縮可）。労働者が5人未満のときは、時間を分割して、同数とみなせる |
| 手順（D測定） | 発散源に近接する場所の作業がある単位作業場所では、**濃度が最も高くなると思われる時間**に、**15分間**。**労働者が動いているから不要、とはならない** |
| 評価 | C測定・D測定は、A測定・B測定と**同じ方法**で、管理区分を決める（評価基準第4条）。D測定だけで済ませる許可、A測定の評価値とD測定の測定値の組合せ、は**ない** |
| 許可の特例 | 評価が2年以上第1管理区分で継続した単位作業場所は、所轄労働基準監督署長の許可を受けて、**検知管方式**による測定ができる（測定基準第10条第3項、第13条第3項）。その場合も、1以上の測定点で、原則の方法を同時に行う。「D測定のみ」にできるのではない |
| 管理濃度の10分の1 | 測定値が管理濃度の**10分の1に満たない**測定点は、10分の1とみなして区分できる（評価基準第2条第3項） |

**ひっかけパターン**（過去問で誤りとして出た組）

- 「個人サンプリング法の登録は、**第1種**でなければ受けられない」。
- 「**簡易測定機器**を用いる個人サンプリング法は、登録がなくても行える」。
- 「特定化学物質のうち、**管理濃度が一定値以下**のものが対象」（物質ごとに定められている）。
- 「個人サンプリング法が登録を受けるには、**指定作業場の種類ごとに**、個人サンプリング法の登録を受けた**第1種**を置く」。
- 「**石綿**は、個人サンプリング法によれる」。
- 「**遊離けい酸の含有率が一定の値を超える**粉じんは対象外」（除かれるのは、極めて高いもの。特定粉じん作業の粉じんは、遊離けい酸の含有率にかかわらず対象）。
- 「**坑内**の作業場（ずい道等）の粉じんの個人サンプリングは、登録が必要」（指定作業場でないので、登録を受けていない測定士でもよい）。
- 「**溶接ヒューム**の濃度の測定は、個人サンプリング法の登録が必要」（溶接ヒュームは、令第21条第7号から除かれる）。

## 5. 事業者・作業環境測定機関・第3管理区分の措置

**表⑤　事業者と作業環境測定機関**（法第3条、第4条、第33条〜第35条の3、施行規則第3条・第52条〜第62条。原文で確認）

| 項目 | 内容 |
|---|---|
| 事業者の責務（法第3条第1項） | 指定作業場の作業環境測定は、**その使用する作業環境測定士**に実施させる |
| 委託（同条第2項、規則第3条第2項） | 自ら行えないときは、**作業環境測定機関**、又は、厚生労働大臣が指定する機関（国・地方公共団体の機関など）に**委託しなければならない**。個人サンプリング法は、個人サンプリング法について登録を受けた機関に |

**第3管理区分の場所の措置**（有機則第28条の3の2。特化則・鉛則・粉じん則にも同様の規定。有機則の原文で確認）

評価の結果、第3管理区分となった場所で、措置を講じていない（又は評価していない）ものは、**遅滞なく**、次の流れで進める。

1. **作業環境管理専門家**の意見を聴く。専門家は、**当該事業場に属さない者**（外部の者）に限る。**「当該事業場に専属の」は誤り**。
2. 専門家が、第1管理区分又は第2管理区分とすることが**可能**と判断 → **直ちに**、改善措置を講じ、効果を確認するため、濃度を測定して評価する。
3. 専門家が**困難**と判断（又は措置後も第3管理区分）→ 直ちに、①**個人サンプリング測定等**の結果に応じて、有効な**呼吸用保護具**を使用させる、②面体を有する呼吸用保護具は、**適切に装着**されていることを確認し、結果を記録して**3年間**保存、③**保護具着用管理責任者**を選任し、呼吸用保護具を常時有効かつ清潔に保持させる、④専門家の意見の概要などを労働者に周知する。
4. 上の措置を講じたときは、**遅滞なく**、**第3管理区分措置状況届**を、所轄**労働基準監督署長**に提出する（第28条の3の3）。
5. 管理区分が改善されるまでの間は、**6か月以内ごと**に1回、個人サンプリング等で濃度を測定し、保護具を使用させる。面体の装着の確認は、**1年以内ごと**に1回（第28条の3の2第5項）。

**粉じんの測定の特例**（粉じん則第26条）：粉じんの濃度の測定は、**6か月以内ごと**に1回（第1項）。評価が2年以上、第1管理区分で継続した単位作業場所は、所轄労働基準監督署長の**許可**を受けて、測定を「別に厚生労働大臣の定めるところ」によることができる（第3項）。測定の頻度を、1年以内ごとに緩和するものではない。記録は**7年**保存（第8項）。

## 7. 解き方・覚え方のまとめ

1. **まず、「指定作業場か」を判断する**：令第21条の第1号（粉じん）、第7号（特化物・石綿）、第8号（鉛）、第10号（有機溶剤）、第6号の一部（放射性物質取扱作業室・事故由来廃棄物等取扱施設）だけが、指定作業場。**坑内、暑熱・騒音、事務所、酸素欠乏、管理区域の外部放射線、第3類物質、溶接ヒューム、表面汚染**は、指定作業場でない → 測定士でなくてよい。
2. **第1種と第2種**：違いは**分析**だけ。第2種は、簡易測定機器以外の分析ができない。**デザイン・サンプリングは、登録を受けた作業場の種類にかかわらず、どの指定作業場でも**できる。作業場の種類の制限は、分析（第1種）だけ。
3. **個人サンプリング法**：登録は、第1種・第2種のどちらも。**デザイン・サンプリングに登録が必要**（簡易測定機器でも）。**分析は登録不要**。対象は、粉じん（遊離けい酸が極めて高いものを除く）、特化物の一部、鉛、有機溶剤すべて。**石綿・放射性物質は対象外**。
4. **数字**：登録の取消し後 **2年**。測定機関の記録 **3年**。作業の記録（特別管理物質）**1か月を超えない期間ごと・30年**。粉じんの測定の記録 **7年**。
