労働衛生関係法令の**問1**は、23回すべて、「労働（安全）衛生管理体制」。誰を、何人以上の事業場で、いつまでに、どんな資格の者から選ぶか、が問われる。誤っているものを選ぶ形で、人数の数字（50人、300人、500人、1,000人、3,000人）と、業種、専属・専任、が1つだけ崩してある。この章は、その数字を、1つの表にそろえる。教育（問3）と、化学物質管理者（問2）も、ここに加える。

## 導入クイズ

**Q1** 衛生管理者は、選任すべき事由が発生した日から何日以内に選任するか。

① 7日　② 14日　③ 30日

**Q2** 常時1,500人の労働者を使用する事業場で、選任しなければならない衛生管理者は、何人以上か。

① 3人　② 4人　③ 5人

**Q3** 事業場の労働者で、作業環境測定を実施している作業環境測定士を、衛生委員会の委員にすることについて、正しいのはどれか。

① 指名しなければならない　② 指名することができる　③ 指名できない

答え：Q1は②（14日。規則第7条第1項第1号）。Q2は②（千人を超え二千人以下は4人。規則第7条第1項第4号）。Q3は②（指名することができる。法第18条第3項）。3問とも、この章の表の1行で答えが出る。

## 2. 選任の基準（総括安全衛生管理者・衛生管理者・産業医・推進者）

**表①　誰を、何人以上の事業場で選ぶか**（法第10条〜第13条、令第2条〜第5条、規則第2条〜第3条・第7条・第12条の2〜第12条の3・第13条。原文で確認）

| 区分 | 選任すべき事業場（常時使用する労働者数） | 選任の期限・方法 | 資格・充てる者 |
|---|---|---|---|
| **総括安全衛生管理者**（法第10条、令第2条） | **業種で異なる**。**林業・鉱業・建設業・運送業・清掃業：100人以上**。**製造業（物の加工業を含む）、電気業、ガス業、熱供給業、水道業、通信業、各種商品卸売業、家具・建具・じゆう器等卸売業、各種商品小売業、家具・建具・じゆう器小売業、燃料小売業、旅館業、ゴルフ場業、自動車整備業、機械修理業：300人以上**。**その他の業種：1,000人以上** | 事由の発生から**14日以内**（規則第2条）。選任したら、所轄労働基準監督署長に報告。職務を行えないときは、**代理者**を選任（規則第3条） | **事業の実施を統括管理する者**をもって充てる（法第10条第2項）。「**又はこれに準ずる者**」ではない |
| **衛生管理者**（法第12条、令第4条） | **50人以上**（業種を問わない） | 事由の発生から**14日以内**。その事業場に**専属**の者（規則第7条第1項第1号・第2号）。**少なくとも毎週1回**作業場等を巡視（規則第11条） | **都道府県労働局長の免許**を受けた者、**医師、歯科医師、労働衛生コンサルタント**など（規則第7条・第10条）。業種ごとの免許の区分あり |
| **産業医**（法第13条、令第5条） | **50人以上**（業種を問わない） | 事由の発生から**14日以内**（規則第13条第1項第1号）。**3,000人を超える**ときは、**2人以上**（同項第4号）。**毎月1回**以上、作業場等を巡視（規則第15条。一定の情報の提供を受け、事業者の同意があるときは、2か月に1回） | **医師**で、一定の要件を備えた者（規則第14条第2項）。法人の代表者・事業を営む個人（事業場の運営について利害関係を有しない者を除く）、事業の実施を統括管理する者は、選べない（規則第13条第1項第2号） |
| **安全衛生推進者・衛生推進者**（法第12条の2、規則第12条の2・第12条の3） | **10人以上50人未満**。安全管理者を選任すべき業種（令第2条第1号・第2号の業種）は**安全衛生推進者**、それ以外は**衛生推進者** | 事由の発生から**14日以内**。その事業場に**専属**の者（労働衛生コンサルタントなどは、専属でなくてよい） | 都道府県労働局長の登録を受けた者が行う講習を修了した者、など |
| **衛生委員会**（法第18条、令第9条） | **50人以上**（業種を問わない） | **毎月1回以上**開催（規則第23条） | 表⑤ |

**ひっかけパターン**（過去問で誤りとして出た組）

- 「常時**100人以上**の労働者を使用する事業場では、**業種に関係なく**、総括安全衛生管理者を選任」（正しくは、業種で100人・300人・1,000人。製造業は**300人**）。
- 「常時300人以上の労働者を使用する事業場では、**業種に関係なく**」（同じ。誤り）。
- 「総括安全衛生管理者には、統括管理する者**又はこれに準ずる者**を充てる」（正しくは、**統括管理する者**。「準ずる者」が入るのは、委員会の議長の指名）。
- 「衛生管理者・産業医は、50人以上で、**業種に応じて**」（正しくは、**業種にかかわらず**50人以上）。

**例題**（2023-02|hourei|1）「常時100人以上の労働者を使用する事業場においては、その業種に関係なく総括安全衛生管理者を選任しなければならない」→ 誤り。製造業などは300人以上、その他の業種は1,000人以上。

## 3. 衛生管理者

**出題実績**：23回すべて（問1）。

**表②　衛生管理者の人数・専任・衛生工学**（規則第7条・第10条・第12条。原文で確認）

| 項目 | 内容 |
|---|---|
| **人数**（第7条第1項第4号） | 50人以上200人以下：**1人**。200人超500人以下：**2人**。500人超1,000人以下：**3人**。1,000人超2,000人以下：**4人**。2,000人超3,000人以下：**5人**。3,000人超：**6人**（以上） |
| **専任**（第5号） | 衛生管理者のうち**少なくとも1人**を**専任**とする：①常時**1,000人を超える**労働者を使用する事業場、②常時**500人を超える**労働者を使用する事業場で、**坑内労働**又は労働基準法施行規則第18条各号の業務（有害業務。下の表）に常時**30人以上**を従事させるもの |
| **衛生工学衛生管理者**（第6号・第12条） | 常時**500人を超える**労働者を使用する事業場で、**坑内労働**又は労働基準法施行規則第18条第1号・第3号〜第5号・第9号の業務（高熱・暑熱、有害放射線、じんあい・粉末、異常気圧、有害物のガス・蒸気・粉じん。下の表）に常時**30人以上**を従事させるものは、衛生管理者のうち**1人**を、**衛生工学衛生管理者免許**を受けた者のうちから選任し、衛生工学に関する事項を管理させる |
| 業種と免許（第3号） | **農林畜水産業、鉱業、建設業、製造業（物の加工業を含む）、電気業、ガス業、水道業、熱供給業、運送業、自動車整備業、機械修理業、医療業、清掃業**：**第一種衛生管理者免許**若しくは**衛生工学衛生管理者免許**を有する者、又は、医師・歯科医師・労働衛生コンサルタントなど。**その他の業種**：**第二種**も可。**衛生工学衛生管理者免許**は、事業場の規模・業種にかかわらず、衛生管理者として選任できる |

- 「2人以上の衛生管理者を選任する事業場では、そのうち**1人を専任**」（正しくは、専任は、1,000人超、又は、500人超で有害業務30人以上のとき）。

## 5. 衛生委員会・安全衛生委員会

**出題実績**：23回中13回（問1の選択肢。問8にも出る）。

**表④　衛生委員会**（法第18条・第19条、令第9条、規則第23条。原文で確認）

| 項目 | 内容 |
|---|---|
| 設置（令第9条） | 常時**50人以上**の労働者を使用する事業場。**衛生委員会は、業種を問わない**（安全委員会は、業種と規模が政令で決まる）。安全委員会と衛生委員会を設けるときは、**安全衛生委員会**に代えられる（法第19条）。そのため、過去問は、「50人以上の事業場では、その業種に応じて、衛生委員会又は安全衛生委員会を設けなければならない」を、正しい記述としている |
| 委員（法第18条第2項） | ①**総括安全衛生管理者**、又は、総括安全衛生管理者以外の者でその事業の実施を統括管理するもの若しくは**これに準ずる者**のうちから事業者が指名した者（1人。**議長**になる）、②**衛生管理者**のうちから指名した者、③**産業医**のうちから指名した者、④当該事業場の労働者で、**衛生に関し経験を有する**者のうちから指名した者 |
| 議長（法第18条第4項、第17条第3項） | **第1号の委員**（上の①）。総括安全衛生管理者又は統括管理する者**若しくはこれに準ずる者** |
| 推薦（同条第4項） | 第1号の委員以外の委員の**半数**は、労働者の過半数で組織する労働組合（ないときは、労働者の過半数を代表する者）の**推薦**に基づき指名する |
| **作業環境測定士**（法第18条第3項） | 当該事業場の労働者で、**作業環境測定を実施している作業環境測定士**であるものを、委員として**指名することができる**（**義務ではない**）。外部の機関に委託している場合の測定士を、指名しなければならないのでもない |
| 開催（規則第23条第1項） | **毎月1回以上** |
| 議事（同条第3項・第4項） | 開催の都度、**遅滞なく**、議事の概要を労働者に周知。委員会の意見、講じた措置、重要な議事を記録して、**3年間**保存 |
| 産業医（同条第5項） | 衛生委員会等に対して、労働者の健康を確保する観点から必要な調査審議を**求めることができる** |

**ひっかけパターン**（過去問で誤りとして出た組）
