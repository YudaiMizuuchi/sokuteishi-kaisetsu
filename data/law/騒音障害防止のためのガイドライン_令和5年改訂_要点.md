# 騒音障害防止のためのガイドライン（令和5年4月20日 基発0420第2号）の要点

出典：厚生労働省「騒音障害防止のためのガイドライン」（令和5年4月20日基発0420第2号の別添。**平成4年10月1日基発第546号のガイドラインを改訂**）。確認：サイト側（令和8年11月9日）。確認方法：安全衛生情報センターのページ（本体）と、厚生労働省・建設業労働災害防止協会が公開する全文 PDF（別紙1〜4、別表、解説を含む）を通読した。**本文は写さず、要点だけを書く**。章には、「騒音障害防止のためのガイドライン（令和5年4月20日基発0420第2号）別紙1」のように書く。

## 1. 平成4年版からの主な変更点（改訂のポイント）
- **騒音障害防止対策の管理者の選任**を追加（5(1)。衛生管理者・安全衛生推進者等から選任。ライン管理者・職長等でもよい〔解説〕）。元方事業者の指導・援助（5(2)）。
- **聴覚保護具の選定基準**を明示（7(1)）：**JIS T 8161-1**に規定する試験方法で測定された**遮音値**を目安に、必要かつ十分な遮音値のものを選ぶ（周囲の音を聞く必要がある場合や会話が必要な場合は、遮音値が必要以上に大きいものを選ばない）。
- **騒音レベルの新しい測定方法**：**個人ばく露測定**（別紙3）と、**等価騒音レベルの推計**（別紙4）を追加。
- **騒音健康診断の検査項目の見直し**：定期健康診断の **4,000 Hz の選別聴力検査の音圧を、40 dB から 25 dB及び30 dB に変更**。雇入時等健康診断と二次検査の聴力検査に、**6,000 Hz** を追加（250・500・1,000・2,000・4,000・6,000・8,000 Hz）。
- 作業時間の管理（7(2)）：作業環境を改善しても、**第Ⅰ管理区分とならない場合又は等価騒音レベルが 85 dB 未満とならない場合**は、許容基準の表を参考に、騒音作業に従事する時間の短縮を検討。**日本産業衛生学会「許容濃度等の勧告（2022年度）」の騒音の許容基準**（等価騒音レベル 85 dB：8時間、90 dB：2時間30分、100 dB：15分 など）。**実効休止時間**＝騒音レベルが **80 dB 未満**にとどまっている時間（解説）。

## 2. 対象（別表）
- **別表第1**（8項目の屋内作業場。**安衛則第588条・第590条**により、6月以内ごとに1回、定期に、等価騒音レベルを測定する義務）。**別表第2**（**52項目**。安衛則上の義務はないが、等価騒音レベルが **85 dB 以上**になる可能性が大きい作業場）。それ以外でも、騒音レベルが高いと思われる業務は、同様の対策が望ましい。

## 3. 作業環境管理（6）
- **別表第1**：別紙1（作業環境測定）により、測定・評価・措置・記録。**6月以内ごとに1回、定期に**（施設・設備・作業工程・作業方法を変更した場合は、その都度）。
- **別表第2の屋内作業場**：別紙1。**騒音源が移動する場合等**は、別紙3（個人ばく露測定）でもよい。定期の測定は、**第Ⅰ管理区分が継続している場所**又は**等価騒音レベルが継続的に 85 dB 未満の場所では、省略できる**。
- **別表第2の坑内の作業場**：別紙2（定点測定）又は別紙3。**屋外作業場**：別紙2又は別紙3。**地面の上に騒音源があって、周辺に建物や壁等がない場所**は、別紙4（推計）でもよい（周囲に建物や壁等がある場合は、反響で高くなる可能性があるので、推計は不適切）。いずれも、85 dB 未満が継続的な場所は、定期の測定を省略できる。
- 等価騒音レベルの測定の実施者：特に定めていないが、**作業環境測定士や衛生管理者等**に実施させるか、**作業環境測定機関**に委託することが望ましい（解説）。

## 4. 別紙1：作業環境測定による等価騒音レベルの測定
- **測定**：作業環境測定基準第4条第1号・第2号の方法による等価騒音レベルの測定（A測定）と、騒音源に近接する場所で作業が行われる単位作業場所では、同第3号の方法による測定（B測定）。**作業が定常的に行われている時間帯に、1測定点について 10 分間以上**継続。
- **評価**（単位作業場所ごと）：**A測定平均値**（**算術平均**。**80 dB 未満の測定値は含めない**）と**B測定値**で、**85 dB・90 dB** の境目：
  - A測定平均値が **85 dB 未満**：B測定が 85 dB 未満＝**第Ⅰ管理区分**、85 dB 以上 90 dB 未満＝**第Ⅱ管理区分**、90 dB 以上＝**第Ⅲ管理区分**。
  - A測定平均値が **85 dB 以上 90 dB 未満**：B測定が 85 dB 未満・85 dB 以上 90 dB 未満＝**第Ⅱ管理区分**、90 dB 以上＝**第Ⅲ管理区分**。
  - A測定平均値が **90 dB 以上**：B測定にかかわらず**第Ⅲ管理区分**。
  - **A測定のみを実施した場合は、B測定の欄は 85 dB 未満の欄**で評価。（**平成4年版と同じ**）
- **措置**：第Ⅰ＝作業環境の継続的維持に努める。第Ⅱ＝**標識によって明示**する等、施設・設備・作業工程・作業方法の点検・改善（第Ⅰ管理区分となるよう努める）、**必要に応じて聴覚保護具を使用**させる。第Ⅲ＝標識によって明示する等、点検・改善（第Ⅰ又は第Ⅱ管理区分となるよう努める。**改善したときは、直前と同様の方法で測定し、評価**）、**聴覚保護具を使用させた上で、使用状況を管理者に確認させ、使用について作業中の労働者が容易に知ることができるよう、見やすい場所に掲示**。**手持動力工具を使用する業務**は、第Ⅰ管理区分が継続している場所を除き、**聴覚保護具を使用させる**。
- **記録**：測定日時・測定方法・測定箇所・測定条件・測定結果・評価日時・評価箇所・評価結果・測定及び評価を実施した者の氏名・措置の概要を、**3年間保存**。

## 5. 別紙2〜4
- **別紙2（定点測定）**：騒音源に近接する場所で、騒音レベルが最も大きくなると思われる時間に、作業が行われる位置で測定（測定基準第4条第3号の方法）。**1測定点 10 分間以上**。結果：**85 dB 未満**＝継続的維持に努める。**85 dB 以上 90 dB 未満**＝点検・改善（85 dB 未満となるよう努める）、必要に応じて聴覚保護具。**90 dB 以上**＝点検・改善、**聴覚保護具を使用させ、使用状況の確認と掲示**。記録：3年間。
- **別紙3（個人ばく露測定）**：**ばく露計**は、等価騒音レベルを測定できる**JIS C 1509-1 又は IEC 61252** の精度を満たすもの（防爆性能が必要な場所もある）。**同種の業務を行うグループごとに1台以上**。**マイクロホン部分を、測定対象者の頭部・首・肩の近くに装着**。**終日又は半日**、装着させたまま騒音作業を行わせる。**2時間ごとに反復継続する作業を行うことが明らかな場合等は、測定の開始から終了までが 1時間以上であれば、短縮してよい**。測定中の測定者の立会いは不要。措置は別紙2と同様。記録：3年間。
- **別紙4（推計）**：**Lp＝Lw−20 log r−8**（Lp：推計値〔dB〕、Lw：音響パワーレベル〔dB〕、r：騒音源からの距離〔m〕）。音響パワーレベルは、機械等の表示を参考にする。措置は別紙2と同様。記録：3年間。

## 6. 健康管理（8）・教育（9）
- **雇入時等健康診断**（騒音作業に常時従事する労働者の雇入れ・配置替え時）：既往歴・業務歴の調査、自覚症状・他覚症状の有無の検査、**オージオメータによる 250・500・1,000・2,000・4,000・6,000・8,000 Hz の聴力検査**、その他。**定期健康診断**（6月以内ごとに1回。第Ⅰ管理区分が継続している場所又は等価騒音レベルが継続的に 85 dB 未満の場所の労働者は、省略できる）：既往歴・業務歴、自覚症状・他覚症状、**オージオメータによる 1,000 Hz（30 dB）及び 4,000 Hz（25 dB及び30 dB）の選別聴力検査**。30 dB で異常が認められる者等は、**二次検査**。
- **事後措置**：前駆期の症状・軽度の聴力低下がある者は、第Ⅱ管理区分の場所又は 85 dB 以上 90 dB 未満の場所でも、聴覚保護具を使用。中等度以上の聴力低下がある者は、聴覚保護具の使用、作業時間の短縮、配置転換など。**健康診断結果は、5年間保存**。定期健康診断の結果は、**所轄労働基準監督署長に報告**。
- **労働衛生教育**：管理者に対する教育（騒音の人体に及ぼす影響〔30分〕、適正な作業環境の確保と維持管理〔80分〕、聴覚保護具の使用及び作業方法の改善〔40分〕、関係法令等〔30分〕。計3時間）。騒音作業に常時従事する労働者に対する教育（騒音の人体に及ぼす影響、聴覚保護具の使用）。第Ⅰ管理区分が継続している場所又は 85 dB 未満の場所の労働者は、省略できる。
- **聴覚保護具**（解説）：騒音発生源対策・伝ぱ経路対策で低減できない場合に、**二次的**に使用。耳栓と耳覆い（イヤーマフ）。非常に強烈な騒音には、**併用**が有効。非常の際の警報は、音響ではなく、赤色回転灯などを用いる。
- **等価騒音レベル**（解説。JIS Z 8731:2019）：ある時間 T について、変動する騒音の騒音レベルを、**エネルギー的な平均値**として表した量。積分型騒音計で直接求められる。**普通騒音計**で、一定時間間隔ごとに測り、**10 log［(10^(L₁/10)＋…＋10^(Lₙ/10))/n］**で求めることもできる。

## 7. 作業環境測定基準第4条との関係（令和8年9月30日までの規定）
- 測定点：床面上に **6 m 以下の等間隔**で引いた縦横の線の交点の、**床上 120 cm 以上 150 cm 以下**（ほぼ均一なら 6 m 超）。**5以上**。**騒音計は、等価騒音レベルを測定できるもの**、**A 特性**。**1測定点 10 分間以上**。（原文：`作業環境測定基準.txt` 第4条。令和8年10月1日以降の変更は、確認していない）
- **騒音の評価（管理区分）は、作業環境評価基準ではなく、このガイドライン**（作業環境評価基準に、騒音の規定はない）。
