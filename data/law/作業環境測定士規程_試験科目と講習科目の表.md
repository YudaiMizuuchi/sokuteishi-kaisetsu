# 作業環境測定士規程（昭和51年労働省告示第16号）— 試験・講習科目の表（令和8年告示第325号による改正後）

出典：厚生労働省 法令等データベース https://www.mhlw.go.jp/web/t_doc?dataId=74159000&dataType=0&pageNo=1 （本人提供のURL。サイト側が、令和8年11月に、取得）。第1条（受験資格）・附則は、`作業環境評価基準_測定士規程_測定機関基準_抜粋.md` を参照。

## 第2条　試験の科目と範囲（試験の時間は、一科目について一時間）
| 試験の科目 | 範囲 |
|---|---|
| 労働衛生一般 | 作業場における有害原因が人体に及ぼす影響／作業環境の評価及び改善／作業方法の改善／労働衛生保護具 |
| 労働衛生関係法令 | 労働安全衛生法、作業環境測定法及びじん肺法並びにこれらに基づく命令のうち労働衛生に係るもの |
| 作業環境について行うデザイン及びサンプリング | 統計に関する基礎理論／ガス、蒸気及び粉じんの性質／測定点等の設定方法／**個人ばく露測定（作業環境測定法第2条第3号に規定する個人ばく露測定）の対象となる労働者等の設定方法**（令和8年10月1日に追加）／測定機器の選択方法／試料採取機器の原理及び使用方法／採取した試料の管理方法／簡易測定機器の原理及び使用方法 |
| 作業環境について行う分析に関する概論 | 分析化学の基礎理論／定性分析／重量分析／容量分析／機器分析 |
| 規則別表第一号の作業場（粉じん）の分析の技術 | 重量分析方法、エックス線回折分析方法及び計数方法による土石、岩石、鉱物、金属又は炭素の粉じんの分析に関する理論及び方法 |
| 規則別表第二号の作業場（放射性物質）の分析の技術 | 全アルファ・全ベータ・全ガンマ放射能計測方法、アルファ線・ベータ線・ガンマ線スペクトル分析方法、放射化学分析方法及び蛍光光度分析方法による放射性物質の分析に関する理論及び方法 |
| 規則別表第三号の作業場（特定化学物質）の分析の技術 | 吸光光度分析方法、ガスクロマトグラフ分析方法、高速液体クロマトグラフ分析方法、原子吸光分析方法、蛍光光度分析方法及び重量分析方法による、令別表第三第一号（6及び8を除く。）及び第二号（3の2、10、11、13、13の2、15の2、21、22、23の3、27の2、33、34の2、34の3及び37を除く。）に掲げる物の分析 |
| 規則別表第四号の作業場（金属類）の分析の技術 | 吸光光度分析方法、原子吸光分析方法、蛍光光度分析方法及び誘導結合プラズマ質量分析方法による、令別表第三第一号6並びに第二号3の2、10、11、13、13の2、15の2、21、22、23の3、27の2及び33に掲げる物並びに鉛の分析 |
| 規則別表第五号の作業場（有機溶剤）の分析の技術 | 吸光光度分析方法及びガスクロマトグラフ分析方法による、令別表第六の二第1号から第47号までに掲げる物の分析 |

## 第3条　講習の科目・範囲・時間
| 講習の科目 | 範囲 | 時間 |
|---|---|---|
| 労働衛生管理の実務 | 有害因子と健康障害／有害物の体内侵入の形態／有害物の量に関する指標／作業環境管理の進め方 | 6時間 |
| デザイン及びサンプリングの実務のうち**個人サンプリング法**に係るもの | 作業環境測定の目的／個人サンプリング法に係るデザインの方法／同サンプリングの方法／簡易測定機器とその取扱い | 8時間 |
| 同、**個人ばく露測定**に係るもの（令和8年10月1日に新設） | 作業環境測定の目的／個人ばく露測定に係るデザインの方法／同サンプリングの方法／個人ばく露測定の結果の評価／呼吸用保護具の選択 | 8時間 |
| 同（個人サンプリング法及び個人ばく露測定に係るものを除く） | 作業環境測定の目的／デザインの方法／サンプリングの方法／簡易測定機器とその取扱い | 12時間 |
| 規則別表第一号〜第五号の作業場の分析の実務（粉じん／放射性物質／特定化学物質／金属類／有機溶剤） | 各号の、試験の分析の技術と同じ方法・物 | 各12時間 |
- 講習の講師は、作業環境測定法別表第3各号の表の条件に適合する知識経験を有する者（第2項）。講習では、修了試験を行う（第3項）。実施の細則は、厚生労働省労働基準局長が定める（第4項）。
- 附則（令和2年告示第18号、令和3年4月1日適用）：すでに試験に合格している者が個人サンプリング法の講習を受ける場合、「簡易測定機器とその取扱い」→「簡易測定機器とその取扱い　関係法令」、8時間→9時間。
- 附則（令和8年告示第325号第3条・第4条）：令和8年10月1日前の「新個人ばく露測定講習」は、改正後の第3条の例による。令和8年10月1日前に試験に合格している者が受ける新個人ばく露測定講習は、「呼吸用保護具の選択」に関係法令（安衛法、測定法、令、測定法施行令、安衛則、有機則、鉛則、特化則、規則、粉じん則と関係告示）が加わり、8時間→9時間。
