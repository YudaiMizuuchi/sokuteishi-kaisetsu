## 標準液の調製に使う試薬（物質別各論の「試薬」の項）

| 金属・分析法 | 標準液の調製 |
|---|---|
| カドミウム（ジチゾン吸光光度。1.1） | 塩化カドミウム（無水物）を精製水に溶かし、**塩酸**を加える |
| カドミウム（APDC 溶媒抽出−原子吸光。1.2） | 塩化カドミウム（無水物）を精製水に溶かし、**硝酸**を加える |
| クロム（吸光光度・原子吸光。2.1〜2.3） | **二クロム酸カリウム又はクロム酸カリウム**を、精製水に溶かす |
| バナジウム（NBPHA 吸光光度 3.1、原子吸光） | **メタバナジン酸アンモニウム**（無水物）を、温精製水に溶かす |
| 砒素（吸光光度。4.1） | 三酸化二砒素を、**10 M 硝酸**と臭素酸カリウム溶液で、加熱して溶かす |
| 砒素（原子吸光。4.2） | 別の要点ファイル（アルカリ溶液に溶かす） |
| 水銀（原子吸光。5.2） | **塩化水銀(Ⅱ)**を精製水に溶かし、硫酸を加える。標準原液は、**硬質ガラス製の試薬瓶に入れて、冷暗所に保存** |
| ベリリウム（蛍光光度。6.2） | **硫酸ベリリウム（四水和物）**を精製水に溶かし、硫酸を加える |
| マンガン（吸光光度。7.1） | **過マンガン酸カリウム**を精製水に溶かし、硫酸と亜硫酸水素ナトリウムで処理する |
| マンガン（原子吸光） | **酸化マンガン(Ⅳ)**を、塩酸に加熱溶解する |

- **整合メモ（マンガン）**：過去問の「標準液は、過マンガン酸カリウムを用いて調製する」〔誤〕は、**原子吸光分析法**の問。吸光光度分析法では、過マンガン酸カリウムを使う。章では、「原子吸光分析法では」と書く。
- **整合メモ（砒素）**：10 M 硝酸で溶かすのは、吸光光度分析法の標準液。過去問では、水素化物発生原子吸光の問で、「希硝酸で溶解」が誤り（3回）、「10 M 硝酸で溶解」が正しい記述（1回）として出ている。
- 硫酸ベリリウム（四水和物）を「高温乾燥後、使用する」という記述は、標準液の項に、ない。

## 保存容器（総論の「容器およびその洗浄法」）

- 標準液・試薬・試料液の保存容器は、金属の溶出が少ない、**超硬質ガラス製、ポリエチレン製又はテフロン製**。
- ポリエチレン製容器は、**表面吸着性**と、ポリエチレン自身の**還元性**を考えて、保存する物質・濃度によって選ぶ。**とくに水銀は、この影響を受けやすい**。
- テフロンは、金属の溶出が少ないが、**表面吸着性は、超硬質ガラスより大きい**。
- 「水銀の標準液に、テフロン容器は用いない」と、そのまま書いた箇所は、見つけていない（上の、表面吸着性の記述が、もとと思われる）。

## 溶媒抽出の試薬

- **カドミウム（APDC−MIBK。1.2）**：pH を 3.5〜4 に調節 → APDC 溶液を加えて金属キレートを作る → **硫酸アンモニウム溶液（飽和）**と MIBK を加えて、振とう抽出 → MIBK 層を最終試料液とする。**APDC 溶液は、MIBK 処理をしたもの**（用時調製）。**MIBK は、精製水と振り混ぜたもの**。
- **鉛（DDTC−MIBK）**：50％硫酸アンモニウム溶液を使う。**MIBK は、水で飽和しておく**。
- **バナジウム（NBPHA。3.1）**：NBPHA のクロロホルム溶液で抽出する（液は橙黄色）。
- **MIBK 層の水分**（総論の、有機溶媒抽出法の注意）：MIBK 層には **1〜3％の水分**が含まれているので、長時間放置すると濁りを生じ、分析に影響することがある。**分離と分析の操作は、できるだけ速く行う**。
- 「塩析」の語は、OCR の出力には、ない（硫酸アンモニウム溶液を加えて抽出する、という操作の記述だけ）。
