デザイン・サンプリングの**問4**（B測定）と、**問6〜8**（C測定・D測定、個人サンプリング法の対象）は、毎回のように出る。誤っているものを選ぶ形で、選択肢は、**最大値・算術平均値、10分・15分、2時間・1時間、必要・不要、できる・できない**の一語を入れ替えてある。この章は、**令和8年9月30日までの規定**（過去問の正誤の根拠）で、B測定・C測定・D測定を、一語ずつそろえる。**令和8年10月1日以降の変更点**は、**第7節に、別にまとめた**（令和8年度第2回〔令和9年2月〕から、新しい規定が出題されうる）。評価（第1評価値・第2評価値・管理区分）は `bk-design-tp01`。

## 導入クイズ

**Q1** B測定で、検知管を5本用いても測定時間の合計が10分に満たないとき、B測定値は、5本の指示値の、最大値か、算術平均値か。

① 最大値　② 算術平均値

**Q2** D測定の試料空気の採取時間は、何分間か。

① 10分間　② 15分間

**Q3** 均等ばく露作業に従事する労働者が5人未満のとき、C測定の測定値の数は、どうするか。

① 作業時間を分割して、5以上にする　② 3以上にする

答え：Q1は②（算術平均値。「最大値」は、誤りの形）。Q2は②（連続した15分間）。Q3は①（作業時間を分割して、測定値を5以上にする）。

## 2. B測定の対象・位置・時間

### テーマ1　B測定の対象・位置・時間［A］

**出題実績**：21回（平成27年度第1回〜令和8年度第1回のうち、21回）。

**原理**（J-86 2.4.4〜2.4.6）：単位作業場所で、有害物質の**発散源に近接する場所**で、**移動作業・間けつ作業・近接作業**のいずれかが行われるとき、A測定に追加して、**濃度が最も高い作業位置と時間**で行う測定が、**B測定**。B測定は、**A測定を補完**する測定。

**表①　B測定**（J-86 2.4.4〜2.4.6、作業環境測定基準第2条第1項第2号の2、過去問の正答）

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **必要な作業** | **発生源とともに労働者が移動しながら行う作業**（移動）、**原材料の投入・設備の点検等、間けつ的に有害物が発散する作業**（間けつ）、**有害物を発散するおそれのある装置・設備に近接して行う作業**（近接）のいずれかが行われる単位作業場所では、**B測定を行う**。**発生源に近接する場所で作業が行われない**場合は、B測定を**実施しなくてよい** | 「B測定は、A測定を補完するための測定なので、**全ての単位作業場所**で実施する必要がある」（令和5年度第2回）。「発生源に近接する場所において作業が行われない場合でも、B測定が必要」 |
| **目的** | **最も高い濃度**の場所と時間の測定。**個人ばく露濃度の測定ではない** | 「B測定は、**局所的及び短時間の個人ばく露**の評価のために行う」（平成29年度第1回・令和2年度第1回・令和3年度第1回・令和4年度第1回） |
| **測定点** | 濃度が**最大になると考えられる作業位置**。**測定時に労働者がいなくても、立ち入る**ならば、その作業位置で測定する | 「最大の測定値を示す箇所は、労働者が立ち入る可能性が**なくても**B測定を行う」（平成28年度第1回・平成30年度第1回） |
| **作業位置が複数** | 最大濃度になる位置が**予測できない**場合は、**すべての作業位置**で測定を行い、**最大の測定値**を B測定値とする | 「すべての作業位置で測定を行い、各測定値の**算術平均値**を B測定値とする」（令和4年度第2回・令和7年度第2回）。「全B測定点の測定値の**平均値**をB測定値とする」 |
| **移動作業** | **作業位置の移動に沿って**測定を行う | — |
| **高さ** | A測定同様、**床上 50 cm 以上 150 cm 以下**の範囲で、作業の実態に応じて選定する（J-86） | 「床上 **100 cm 以上 150 cm 以下**」（令和6年度第2回） |
| **時間帯** | 濃度が最大になる作業が、A測定の実施時間内に行われないときは、B測定を、A測定とは**別の時間**（その作業が行われる時間）に実施してよい | — |
| **サンプリング時間** | 原則として、**継続した10分間** | — |
| **採取・分析方法** | **A測定と同じ方法**を用いる。分粒装置を使用して捕集する特定化学物質は、**B測定でも分粒装置を使用**する | 「B測定では**分粒装置を使用しない**」（令和7年度第1回） |
| **連続2作業日** | 第1日目と第2日目の**ともに B測定を行い**、**最大値**を B測定値とする（令和7年度第2回・令和8年度第1回） | — |

**覚え方**：「**B測定は、一番濃いところを、10分間。複数なら、最大値**（平均ではない）」「**近接・移動・間けつの3作業**」。

**例題**（`2026-08|design|4`、`2026-02|design|4`、`2025-08|design|4`、`2025-02|design|4`、`2024-08|design|4`、`2024-02|design|4`、`2023-02|design|4`）。

## 3. B測定の機器と方法

### テーマ2　粉じん計・検知管・真空捕集瓶［A］

**出題実績**：19回（平成27年度第1回〜令和8年度第1回のうち、19回）。

**表②　B測定の機器別の方法**（J-86 2.4.6、過去問の正答）

| 機器 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **検知管** | **5本程度**を目安にする。**10分に満たない**ときは、**10分の間に、測定時間を均等に分布**させ、**5本の指示値の算術平均値**を測定値とする。合計が10分を超えるときは、開始から10分経ったときに使っている検知管までの値で、算術平均を求める | 「5本の指示値の**最大値**を B測定値とする」（令和8年度第1回） |
| **真空捕集瓶** | **5本程度**を目安にする。10分に満たないときは、10分の間に採取時間を**均等に分布**させ、各瓶の濃度の**算術平均値**を測定値とする | — |
| **光散乱方式の粉じん計**（デジタル粉じん計） | **10分間連続**して作動させる（令和5年度第1回） | — |
| **圧電天秤方式の粉じん計** | 測定時間を**2分**に合わせて、**連続して5回**測定し、各測定値の**算術平均値**を B測定値とする | 「5回の測定の**最大値**を B測定値とする」（令和6年度第1回） |
| **10分間未満でしか作動できない相対濃度計** | **繰り返し測定**で10分間作動させ、それぞれの測定値の**算術平均値**を B測定値とする。**1回当たりの作動時間は、すべて同一** | — |
| **質量濃度変換係数** | 相対濃度指示方法で B測定を行った場合は、**A測定の併行測定で求めた質量濃度変換係数と、同じもの**を用いる | 「質量濃度変換係数は、A測定とは**別に求めなければならない**」（令和5年度第1回） |

**覚え方**：「**検知管5本・10分に均等・算術平均**」「**圧電天秤は 2分×5回・算術平均**」「**変換係数は、A測定のものを使う**」。

## 4. C測定

### テーマ3　試料採取の数・時間・装着［A］

**出題実績**：10回（令和3年度第1回〜令和8年度第1回の、10回）。

**原理**（J-90、作業環境測定基準第10条第5項第1号〜第4号）：**個人サンプリング法**は、**均等ばく露作業**（労働者がばく露する量が、ほぼ均一と見込まれる作業）ごとに、労働者の**身体に装着**した試料採取機器で、**単位作業場所で作業に従事する全時間**を採取する測定。**C測定**は、全時間の時間加重平均値を得る測定。

**表③　C測定**（作業環境測定基準第10条第5項、過去問の正答）

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **労働者の数** | 均等ばく露作業ごとに、**5人を下回らない**数の労働者に装着する。**5人以上**の場合は、**5人以上**の労働者を選定する | — |
| **5人未満** | 作業時間を**分割**してサンプリングし、**測定値の数を5以上**とする（**採取した試料の数と同数の労働者に装着したものとみなせる**）。1人の場合は、**作業時間を5等分**し、試料の数を5とすることができる | 「分割後の作業時間は、**2時間以上**でなければならない」（令和7年度第1回） |
| **サンプリング時間** | 原則として、労働者が1作業日のうち**単位作業場所で作業に従事する全時間**。ばく露が**ほぼ均一**で、作業時間が**2時間を超える**ときは、**2時間を下回らない範囲**で、短縮できる。作業時間が**2時間以下**のときは、**全作業時間**（全時間であれば、2時間未満でもよい） | 「1時間サイクルの繰り返し作業で、均一なら、C測定のサンプリング時間を**1時間**とできる」（令和5年度第2回）。「C測定のサンプリング時間は、**全時間としなければならない**（短縮できない）」（令和7年度第2回の誤り） |
| **単位作業場所** | **均等ばく露作業ごと**に、その作業に従事する労働者の**行動範囲**を単位作業場所とする。A測定の単位作業場所より、**広範囲**となる場合がある。同一物質の均等ばく露作業が複数で、行動範囲が同じで、作業時間帯が異なるときは、**時間帯ごと**に別々に設定する | — |
| **装着** | 試料採取機器の**採取口**は、**労働者の呼吸域付近**（最も適切な部位）に装着する | 「装着する位置は、労働者の前面であれば**腰部**でもよい」（令和5年度第1回） |
| **単位作業場所外** | 労働者が単位作業場所外に出ても、測定結果に影響がないなら、**ポンプを停止しなくてよい**。その場合の測定値は、**単位作業場所の滞在時間での時間加重平均値** | — |
| **分粒装置** | 分粒装置を使う場合は、**サイクロン式**又は**慣性衝突式**。**多段平行板式**は、個人サンプリング法に**適さない** | 「分粒装置は、**多段平行板式**を使用する」 |
| **C測定とD測定の併用** | C測定とD測定は、**同じ時間帯**に実施でき、**同一の労働者**に装着してよい。ただし、**C測定用とD測定用の個人サンプラーは、別々**（各1つ） | 「C測定とD測定に係る個人サンプラーを装着する労働者は、**別の労働者としなければならない**」（令和8年度第1回）。「同一の労働者の場合は、**1つ**の個人サンプラーでよい」（令和6年度第2回・令和7年度第2回） |

**覚え方**：「**C測定は、5人・全時間・呼吸域**」「**5人未満は、時間を割って5つ**」「**2時間超で均一なら、2時間まで短縮**」「**C と D は、サンプラーを別々に**」。

**例題**（`2026-08|design|6`、`2026-02|design|8`、`2025-08|design|7`、`2025-02|design|7`、`2024-08|design|6`、`2024-02|design|8`、`2023-08|design|7`、`2023-02|design|7`）。

## 5. D測定

### テーマ4　15分間・最大値・15分未満［A］

**出題実績**：10回（令和3年度第1回〜令和8年度第1回の、10回）。

**原理**（J-90 2.5、作業環境測定基準第10条第5項第5号・第6号）：**D測定**は、測定対象物質の**発散源に近接**する場所で作業が行われる単位作業場所で、濃度が**最も高くなると思われる時間**に、**連続した15分間**、試料空気を採取し、15分間の時間加重平均濃度を得る測定（ACGIH の TLV-STEL の15分間を踏まえた）。

**表④　D測定**（過去問の正答）

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **時間** | **連続した15分間** | 「D測定の試料空気の採取等の時間は、**10分間**」（令和4年度第2回） |
| **時間帯** | 発散源に近接する場所で作業が行われる場合、濃度が**最大になると考えられる時間**に行う | — |
| **測定値が複数** | **最大値**を D測定値とする | — |
| **15分未満の作業** | D測定の対象となる作業の単位作業場所で、労働者が作業に従事する時間が**一日15分未満**のときは、D測定ができないので、**個人サンプリング法を選択できない**。作業が数分で終わり、**単位作業場所の外に移動**する場合も、**個人サンプリング法を選択できない**（15分間の継続測定ができない） | 「15分未満が**複数回**生じるときは、その**時間の合計が15分**となるように、D測定の試料空気の採取を行う」（令和6年度第1回。**複数回の合計は、認められない**） |
| **個人サンプラー** | 試料採取は、**身体に装着**する機器で行う | — |

**覚え方**：「**D測定は、連続15分・最大値・15分未満はアウト**」「**複数回の合計15分は、認めない**」。

**例題**（`2026-08|design|6`、`2026-02|design|8`、`2025-08|design|7`、`2024-08|design|6`、`2024-02|design|8`、`2023-02|design|7`）。

## 6. 個人サンプリング法の対象物質

**表⑤　対象物質**（過去問の正答。令別表第三の番号と物質の対応は、告示の本文による：未確認）

## 8. 解き方・覚え方のまとめ

1. **B測定**：近接・移動・間けつの作業で、**最も濃い位置・時間**を、**継続した10分間**。**複数位置は最大値**（平均ではない）。**高さは 50〜150 cm**。**A測定と同じ方法**（分粒装置も同じ）。**連続2作業日は、ともにB測定**。
2. **B測定の機器**：**検知管5本・10分に均等・算術平均**。**圧電天秤は 2分×5回・算術平均**。**光散乱は 10分連続**。**変換係数は、A測定のものを使う**。
3. **C測定**：**5人以上**（5人未満は、時間を分割して**測定値を5以上**）。**全時間**（均一で2時間超なら、**2時間まで**短縮可）。**呼吸域に装着**。**多段平行板式は不可**。
4. **D測定**：**連続15分間**。**最大値**。**15分未満は、個人サンプリング法を選べない**（複数回の合計は不可）。
5. **C と D**：同一労働者に装着できるが、**サンプラーは別々**。
6. **対象外**：フッ化水素・シアン化カリウム・コールタール・溶接ヒューム（令和8年9月30日まで）。
