この章では、分析概論の問17・18でよく出る、**ガスクロマトグラフ（GC）の検出器**を整理します。検出器ごとに、**何を利用して検出するか**と、**何の測定に向くか**を、セットで覚えます。

## 導入クイズ

**Q1** ECD（電子捕獲検出器）が得意なのは、ハロゲン化合物と飽和炭化水素のどちらか。

**Q2** FPD（炎光光度検出器）が検出するのは、硫黄とリンのほかに、臭素・塩素のうち、どちらか。

答え：Q1は、ハロゲン化合物。Q2は、どちらでもない（FPD は硫黄とリンの発光を利用する）。

## 1. この章の要点

- 「検出器と分析対象物質の、**不適切な組合せ**」を選ぶ問が、11回出ている。

## 2. しくみ（原理）

GCの検出器は、カラムから出てきた成分を、**電気信号**に変える装置です。**何を信号にするか**が、検出器ごとに違うので、**得意な物質**も違います。

| 検出器 | 信号になるもの | 得意な物質 |
|---|---|---|
| **FID**（水素炎イオン化） | 水素炎中で、試料が**イオン化**してできる電流 | **有機化合物**（炭化水素など） |
| **ECD**（電子捕獲） | **β線**で生じた二次電子が、試料に**捕獲**されて減る電流 | **ハロゲン化合物**（電子を捕まえやすい物質） |
| **FPD**（炎光光度） | **水素過剰の還元炎**中での、**硫黄・リン**に特有な発光 | **硫黄化合物・リン化合物** |
| **PID**（光イオン化） | **グロー放電の紫外線**で試料が**イオン化** | **芳香族・不飽和炭化水素** |
| **TID（FTD）**（熱イオン化） | 窒素・リンを含む化合物の一部が**熱イオン化**して増えるイオン電流 | **有機リン化合物**など（窒素・リン） |
| **TCD**（熱伝導度） | 成分とキャリヤーガスの**熱伝導率の差** | キャリヤーガスと熱伝導率が違う**すべての化合物** |

### 組合せの考え方

- **FID**：炭素と水素を含む有機化合物が燃えるとイオンができる。**無機ガスや希ガスは燃えない**ので、検出できない。
- **ECD**：電子を**捕まえやすい**物質ほど高感度。**ハロゲン**（トリクロロエチレンなど）が得意。**飽和炭化水素**（n-ヘキサン）、**脂肪族炭化水素**、**芳香族炭化水素**（ベンゼン）は、電子を捕まえにくいので、不適切。
- **FPD**：硫黄・リンの発光を測る。**炭化水素**（n-ヘキサン、ベンゼンなど）は、不適切。
- **PID**：紫外線でイオン化できる**芳香族・不飽和炭化水素**が得意。**飽和炭化水素**は、不適切とされる。
- **TID**：窒素・リンを含む化合物が得意。**炭化水素**は、不適切。

## 4. 解き方・覚え方

組合せの問は、**不適切な1つ**を探します。**FPD と ECD** に炭化水素が組まれていたら、まず疑います（この2つの炭化水素の組合せが、不適切の正答の7回を占める）。

| 検出器 | 覚え方 |
|---|---|
| FID | **有機**（無機ガス・希ガスは不可） |
| ECD | **ハロゲン**（炭化水素は不可） |
| FPD | **硫黄・リン**（炭化水素は不可） |
| PID | **紫外線**で芳香族・不飽和炭化水素 |
| TID | **窒素・リン** |
| TCD | **熱伝導率の差**で、ほぼ何でも |
