# 章の原本（執筆メモ付き）

執筆側が書いた章の原本（動画台本メモ・執筆メモを含む版）。サイトには出さない（ビルドの入力ではない）。サイトに載せる版は `book/<章ID>.md`（`tools/clean_book_md.py` で制作用の節を取り除いたもの）。

- 用途：執筆側に直しを頼むとき、`revise/`（取り込み版）と一緒に渡す。
- 2026年11月10日に、執筆側から34章分を受け取った（ほかの29章は、原本がない）。**取り込み版より古いことがある**（例：`bk-hourei-th04` は、原本がない）。本文が食い違うときは、`book/` の取り込み版が正。
- 今後、執筆側の返却 ZIP の章の md（と `原本_更新版/`）は、取り込みのときに、ここにも置く。
