この章では、**ヒ素の水素化物発生原子吸光分析法**を、「還元で水素化ヒ素（アルシン）をつくり、加熱して原子にする」という流れで整理します。金属類のヒ素の問に、毎回のように出ます。ひっかけは、**還元と酸化の取り違え**と、**原子化にアセチレン-空気フレームを使う**という誤りです。

## 導入クイズ

**Q1** 水素化ヒ素を発生させる試薬を2つ挙げよ。

**Q2** ヒ素の原子化に、アセチレン-空気フレームは用いるか。

答え：Q1は、水素化ホウ素ナトリウム、亜鉛粉末懸濁液。Q2は、用いない（水素-アルゴンフレームや加熱石英セルなどで、水素化ヒ素を加熱する）。

## 1. この章の要点

- 試料液のヒ素を**三価**にする予備還元には、**塩化スズ(Ⅱ)とヨウ化カリウム**（塩化スズ(**Ⅳ**)は誤り）。
- 水素化ヒ素の発生には、**水素化ホウ素ナトリウム**、または**亜鉛粉末懸濁液**。どちらも**還元**であって、酸化ではない。
- 発生する水素化物は、**アルシン（AsH₃）**。
- 原子化は、**水素化ヒ素を加熱**して行う。**水素-アルゴンフレーム、加熱石英セル、電気加熱炉**を用いる。**アセチレン-空気フレームではない**。

## 2. しくみ（原理）

### 流れは「還元 → 発生 → 加熱して原子化」

試料を酸で溶かすと、ヒ素は、**五価と三価**が混ざった状態で液中にあります。水素化物発生法は、次の順に進みます。

1. **予備還元**：水素化物になりやすいのは**三価**のヒ素です。そこで、**塩化スズ(Ⅱ)とヨウ化カリウム**を加えて、五価を**三価に還元**します。塩化スズ(Ⅱ)は、自分が酸化される（Ⅱ → Ⅳ）ことで、相手を**還元**する試薬です。**塩化スズ(Ⅳ)を使えば、還元できません**。
2. **水素化ヒ素の発生**：**水素化ホウ素ナトリウム**（酸と反応して、強い還元力を持つ水素を出す）か、**亜鉛粉末**（酸性で水素を出す）で、ヒ素(Ⅲ)を**水素化ヒ素（アルシン）**に還元します。気体になって、液から分離されるので、**妨害物質が減ります**。
3. **加熱して原子化**：発生したアルシンを、**水素-アルゴンフレーム**、**加熱石英セル**、**電気加熱炉**などに送って、**熱で分解**し、ヒ素原子にして、**吸光度**を測ります。

### なぜアセチレン-空気フレームを使わないのか

ヒ素は、いったん**気体の水素化物**にして、別の装置に送ります。原子化は、その水素化物を**加熱して分解する**操作で、試料溶液を霧にして吹き込む通常のフレーム法とは、**別の方式**です。ヒ素の水素化物発生法に「アセチレン-空気フレーム」と書いてあれば、誤りです（11回のうち、2回が、この誤りの形）。

### 取り違えの形

- 「水素化ホウ素ナトリウムと塩酸により、試料を**酸化**して水素化物を発生させる」→ **誤り**。水素化物の発生は**還元**。
- 「予備還元に、塩化スズ(**Ⅳ**)」→ **誤り**。塩化スズ(Ⅱ)。

## 4. 解き方・覚え方

ヒ素の問は、**1行ずつ、「還元か酸化か」「Ⅱか Ⅳ か」「フレームは何か」**を見ます。

1. 予備還元・発生は、**どれも還元**。「酸化」と書いてあれば誤り。
2. **塩化スズは(Ⅱ)**（還元剤）。(Ⅳ)は誤り。
3. 原子化は、**水素化物を加熱**。**アセチレン-空気フレームは誤り**。
4. 水素化物は**アルシン**（スチビンはアンチモン）。

暗記の1行表：

| 段階 | 試薬・条件 |
|---|---|
| 予備還元（五価 → 三価） | 塩化スズ(Ⅱ)＋ヨウ化カリウム |
| 水素化ヒ素の発生 | 水素化ホウ素ナトリウム、亜鉛粉末懸濁液 |
| 原子化 | 水素-アルゴンフレーム、加熱石英セル、電気加熱炉 |
