この章では、有機溶剤の問9〜15によく出る、**GC-MS（ガスクロマトグラフ質量分析法）**の原理のうち、**イオン化で何が起こるか**と、**質量電荷比（m/z）で分けるので、保持時間が同じでも区別できる**ことを整理します。代表的なイオン化法、質量分離部の種類、検出部は、`bk-yuki-tp01` で扱います。

## 導入クイズ

**Q1** 電子イオン化（EI）法では、分子イオンのほかに、何が生成されるか。

**Q2** GC-MS で、同じ保持時間の有機溶剤どうしは、定量分析できないか、できることがあるか。

答え：Q1は、フラグメントイオン。Q2は、できることがある。

## 1. この章の要点

- **電子イオン化（EI）法**は、**熱電子**を使ってイオン化します。**分子イオン**と**フラグメントイオン**が生成されます。
- イオン化条件によっては、**分子イオンが観察されない**場合があります。
- 質量分離部は、**質量電荷比（m/z）**の違いで分離します。だから、**同じ保持時間**の有機溶剤でも、定量できることがあります。
- 物質ごとに**特有のマススペクトル**が得られるので、**標準物質と比較**して、定性分析ができます。
- **イオン化されにくい化合物**の分析には、適していません。

## 2. しくみ（原理）

### イオン化で、何が起こるか

GC で分けた成分は、MS に入り、まず**イオン化**されます。代表的な**電子イオン化（EI）法**では、**熱したフィラメントから出た熱電子**を、気体の分子にぶつけます。分子が電子を1つ失うと、**分子イオン**ができます。

ぶつけるエネルギーが大きいので、分子イオンが**壊れて（開裂して）**、いくつかの**フラグメントイオン**（かけら）にもなります。したがって、EI 法では、**分子イオンとフラグメントイオンが生成**されます。壊れやすい物質では、分子イオンがほとんど残らず、**分子イオンが観察されない**ことがあります（イオン化条件によっても変わります）。

**化学イオン化（CI）法**は、試薬ガスから作ったイオンで穏やかにイオン化するので、分子イオンが壊れにくい方法です。**EI 法は、CI 法に比べて、分子イオンが開裂しやすい**ので、「起こりにくい」は誤りです。

イオン化は、イオンが空気分子にぶつかって消えないよう、**高真空の中**で行います。「高圧下で行われる」は誤りです。

### m/z で分けるから、保持時間が同じでも区別できる

できたイオンは、**質量分離部**に送られ、**質量電荷比（m/z）**の違いで分けられます。GC だけでは、同じ保持時間に出てくる2つの成分は、1つのピークに重なって区別できません。しかし、MS では、成分ごとに**m/z の違うイオン**を見分けられるので、同じ保持時間の有機溶剤でも、**定量分析できることがあります**（「定量分析できない」は誤り）。

### マススペクトルで定性する

イオンを m/z ごとに並べたものが、**マススペクトル**です。分子の壊れ方は、物質ごとに決まっているので、**物質に特有のマススペクトル**が得られます。そこで、測定対象物質と**標準物質のマススペクトルを比較**して、**定性分析**を行います。未知の物質でも、分子の構造の手がかりが得られるので、同定ができます。

### 適さない化合物

イオン化されなければ、MS で検出できません。**イオン化されにくい化合物の分析には、適していません**。「酸素を含む化合物の分析には適していない」は誤りです（酸素を含むかどうかではなく、イオン化されやすいかどうかです）。

## 4. 解き方・覚え方

誤りの選択肢は、**言い換えの否定**と**向きの入れ替え**です。

- 「同じ保持時間の有機溶剤は、定量分析**できない**」→ 誤り（できることがある）。
- 「EI は、CI に比べて、開裂が**起こりにくい**」→ 誤り（起こりやすい）。
- 「イオン化は**高圧下**」→ 誤り（高真空）。
- 「**酸素を含む**化合物に適さない」→ 誤り（イオン化されにくい化合物）。

| 覚えること | 一言 |
|---|---|
| EI 法 | 熱電子 → 分子イオン＋フラグメントイオン |
| 分子イオン | 条件によっては、観察されないことがある |
| EI と CI | EI のほうが、開裂しやすい |
| 質量分離 | m/z の違い。保持時間が同じでも区別できる |
| 定性 | 標準物質のマススペクトルと比較 |
