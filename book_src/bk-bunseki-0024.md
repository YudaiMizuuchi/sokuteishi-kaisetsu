## 2. 有効数字と数値の丸め

### 原理1　有効数字と数値の丸め（pr-bunseki-0024）［A］

**出題実績**：10回（平成27年度第1回、平成27年度第2回、平成28年度第2回、平成29年度第1回、平成29年度第2回、平成30年度第1回、令和元年度第1回、令和元年度第2回、令和3年度第1回、令和6年度第1回）。

**原理**：**有効数字**は、確実な数に、最後の桁の不確実な数を1つ加えたもの（『分析概論』4.6.1）。0は、小数点の位置を示すだけなら、有効数字でない（0.001002 g の、最初の3つの0）。1.230 の最後の0は、有効数字。**足し算・引き算**は、測定値のうち、**最後の桁の位が一番大きいもの（小数点以下の桁が最も少ないもの）にそろえる**。**掛け算・割り算**は、**有効数字の桁数が最も少ない測定値と、同じ桁数に丸める**。定数や、百分率の 100 は、有効数字に入らない。丸めは、**四捨五入**（JIS Z 8401:2019 箇条2 b)・注記4：丸めの幅が 10^k のとき、規則B〔大きい方〕＝いわゆる四捨五入。JIS は、ちょうど真ん中の値について、偶数丸め〔規則A〕を推奨する。参考）。『分析概論』4.6.1(2) は、足し算では、先に丸めてから足しても、足してから丸めてもよい（結果が最後の桁で食い違うことがあるが、一般に重要でない）とする。一方、JIS Z 8401:2019 箇条2 c) は、丸めを**常に1段階**で行うことを求める（2回以上の丸めは、誤差の原因）。過去問の答えは、**途中で丸めず、足してから、最後に1回だけ丸める**値（令和元年度第2回で、先に丸めると、234.2 になり、選択肢にない）。**有効数字**は、JIS Z 8401:2019 注記3（丸めの幅の位以上の数字列）と一致する。足し算・引き算・掛け算・割り算の桁そろえと、有効数字の数え方（先頭の0・末尾の0）は、JIS にない（『分析概論』4.6.1 と過去問の正答による）。

## 3. 誤差と統計量

### 原理2　誤差と統計量（pr-bunseki-0025）［B］

**出題実績**：9回（令和2年度第2回、令和3年度第2回、令和4年度第1回、令和4年度第2回、令和5年度第1回、令和5年度第2回、令和6年度第2回、令和7年度第1回、令和8年度第1回）。

**原理**：**精度**は、分析値の**ばらつき**（分散・標準偏差で表す）。**正確さ（真度）**は、無限回繰り返したときの平均値（母平均）が、真の値にどれだけ近いかを示す（**かたより**）。**誤差**は、本来、**真の値と測定値の差**で、「測定値の平均値と各測定値との差」は誤差ではない（**偏差**）。優れた方法は、精度と真度の両方が高い方法。迅速性のために、ある程度、精度と真度を犠牲にすることもある（『分析概論』4.1.2）。**分散**は、偏差の2乗の総和を n で割ったもの、**不偏分散**は、n−1 で割ったもの。**標準偏差**は、分散の平方根。**不偏分散の平方根**は、母集団の標準偏差の推定値。分析値は、**平均値に、標準偏差や不偏分散の平方根を ± でつけて**表す（4.6.3・4.6.4）。**独立な量の和や差の標準偏差**は、**分散を足して、平方根**をとる（σ² ＝ σ₁² ＋ σ₂²）。

**覚え方**：「**分散は n、不偏分散は n−1**。標準偏差は、分散の平方根」「**独立な量は、差でも、分散を足す**（σ₁² ＋ σ₂²）」「**誤差は、真の値との差。平均との差は、偏差**」「**偶然誤差は平均で減る。系統誤差は減らない**」。誤りの形は、n と n−1 の入れ替え、σ の足し算・引き算、誤差と偏差の混同。

## 4. 解き方・覚え方のまとめ

1. **足し算・引き算**：小数点以下の桁が最も少ないものにそろえる（足してから丸める）。**掛け算・割り算**：有効数字の桁数が最も少ないものにそろえる。**モル質量**：桁数の最も少ない原子量にそろえる。
2. **桁数**：先頭の 0 は数えない、末尾の 0 は数える（1.270×10⁻³ は4桁、0.0515 は3桁）。
3. **精度＝ばらつき**（分散・標準偏差）。**正確さ（真度）＝かたより**。**誤差＝真の値との差**（平均との差は、偏差）。
4. **分散は n、不偏分散は n−1**。標準偏差は、分散の平方根。**分析値は、平均 ± 標準偏差**。
5. **独立な量の和・差の標準偏差は、√（σ₁²＋σ₂²）**。
6. **偶然誤差**は、正規分布に従い、繰り返して平均すると減る。**系統誤差**は、一定か、予測可能に変化する。

**公式まとめ（暗記の1行表）**

| 項目 | 内容 |
|---|---|
| 平均値 | x̄ ＝ Σxᵢ ÷ n |
| 分散 | σₙ² ＝ Σ（xᵢ−x̄）² ÷ n |
| 不偏分散 | V ＝ Σ（xᵢ−x̄）² ÷（n−1） |
| 標準偏差 | σ ＝ √分散。分析値 ＝ 平均 ± σ（又は ± √V） |
| 独立な量の和・差の標準偏差 | σ² ＝ σ₁² ＋ σ₂² |
| 足し算・引き算／掛け算・割り算 | 小数点以下の桁が最少にそろえる／有効数字の桁数が最少にそろえる |
