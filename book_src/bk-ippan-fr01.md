この章では、労働衛生一般の最初の問に出る、厚生労働省の「化学物質等による危険性又は有害性等の調査等に関する指針」（リスクアセスメント指針）のうち、**リスク低減措置の優先順位**、**ばく露限界との比較**、**リスクの見積りの考え方**を整理します。

## 導入クイズ

**Q1** リスク低減措置で、個人用保護具の使用は、衛生工学的対策・管理的対策より先か、後か。

**Q2** リスクの見積りは、必ず数値化しなければならないか。

答え：Q1は、後（ほかの対策を講じても十分に低減できないとき）。Q2は、必ずしも数値化する必要はない。

## 1. この章の要点

- 低減措置の優先順位は、**代替・運転条件の変更 → 工学的・衛生工学的対策 → 管理的対策 → 個人用保護具**。**個人用保護具は、いちばん最後**。
- 個人ばく露濃度を**ばく露限界**と比較してリスクを見積もった結果、ばく露濃度がばく露限界を**相当程度下回る**場合は、**リスク低減措置を検討する必要はない**。
- リスクの見積りは、**リスク低減の優先度を定める**ために行うので、**必ずしも数値化する必要はない**（相対的な分類でもよい）。

## 2. しくみ（原理）

### リスクアセスメントの流れ

リスクアセスメントは、次の順に進めます。

| 段階 | 内容 |
|---|---|
| 1. 危険性・有害性の特定 | 対象の業務を洗い出し、化学物質の危険性・有害性を調べる |
| 2. リスクの見積り | 危険の起こりやすさ（発生可能性）と、その重大さ（重篤度）、またはばく露の程度と有害性の程度から、リスクの大きさを見積もる |
| 3. 低減措置の検討 | 見積りの結果に応じて、どんな対策をとるかを決める |
| 4. 実施 | 決めた措置を実施する |
| 5. 記録・周知 | 結果を記録して、関係者に知らせる |

### リスクの見積り

見積りの目的は、**どのリスクから先に手を打つか（優先度）を決める**ことです。だから、**必ずしも数値化しなくてもよく**、「大・中・小」のような相対的な分類でもかまいません。「数値化して行わなければならない」「必ず数値化する必要がある」は、誤りです。

見積りの方法には、発生可能性と重篤度を考える方法（表にする、数値化して加算・乗算する、など）と、**ばく露の程度と有害性の程度を考える方法**があります。後者の代表が、**個人ばく露濃度をばく露限界と比べる**方法です。ここでいうばく露限界は、許容濃度や TLV-TWA などの値のことです。測定した個人ばく露濃度が、ばく露限界を**相当程度下回る**なら、リスクは十分に低く、**低減措置を新たに検討する必要はありません**。

### 低減措置の優先順位

リスクを下げる対策には、**効果が確実なもの**から順に、優先順位がついています。

| 優先順位 | 対策 | 例 |
|---|---|---|
| 1 | 代替・運転条件の変更など（根本から変える） | 有害性のより低い物質への代替、運転条件・取り扱う物の形状の変更 |
| 2 | 工学的対策・衛生工学的対策（設備で囲う・吸い込む） | 密閉化、局所排気装置の設置、防爆構造化 |
| 3 | 管理的対策（人の決まりで守る） | 作業手順の改善、立入禁止、マニュアルの整備 |
| 4 | **個人用保護具**（人に着けさせる） | 有害性に応じた有効な保護具の選択・使用 |

個人用保護具は、**上の対策を講じても、十分にリスクを低減できないときに行う**ものです。着け忘れや、ずれがあれば、効果がなくなるからです。また、**上の優先順位の高い措置で、十分にリスクが下がる**のなら、それより低い優先順位の措置の検討は、必要ありません。

## 4. 解き方・覚え方

この問は、「指針に関する記述のうち、誤っているもの」で、①〜③は、ほとんど正しい記述として出ます（誤りの形があるのは、③の「必ず数値化」だけです）。**誤りの選択肢は、ほかの論点にある**ので、次の言い方に注意します。

1. 「**ハザード**は、労働災害発生の可能性と重篤度の**組合せ**」は、誤り（ハザードは、危険性・有害性そのもの。組合せはリスク）。
2. 重篤度の見積りは、「過去に**実際に**発生した負傷・疾病の重篤度」ではなく、「**最悪の状況を想定した**最も重篤な負傷・疾病」。

| 項目 | 覚え方 |
|---|---|
| 見積りの方法 | 一定の尺度で数値化して、加算または乗算する方法もある |
| 重篤度の尺度 | 傷害や疾病の種類にかかわらず、基本的に休業日数等を使う |
| 保護具の次 | 優先順位の高い措置で十分に低減されるなら、低い措置の検討は不要 |
| 管理濃度との関係 | 個人ばく露濃度を、管理濃度（作業環境評価基準）と比べる方法は、誤り |

## 5. 例題

- `2018-02|ippan|1`：リスクアセスメント指針の、誤りを選ぶ問。**「リスクの見積りは、数値化して行わなければならない」が誤り（正答）**。必ずしも数値化しなくてよい。ばく露濃度がばく露限界を相当程度下回るときは低減措置の検討が不要なこと、保護具より管理的対策を優先することは、正しい。
- `2017-08|ippan|1`：同じ指針の問で、**「リスクの見積りは、リスク低減の優先度を定めるために行うので、必ず数値化する必要がある」が誤り（正答）**。優先度を定めるためだから、必ずしも数値化しなくてよい。保護具は優先順位の高い対策を講じても低減できない場合に行うこと、運転条件の変更等は防爆構造化・局所排気装置の設置より優先することは、正しい。
- `2023-02|ippan|1`：同じ指針の問で、**「過去に実際に発生した負傷又は疾病のうち、最も重篤であったものの重篤度を、見積りの重篤度とする」が誤り（正答）**。最悪の状況を想定した最も重篤なものを見積もる。数値化は必ずしも不要なこと、ばく露限界を相当程度下回る場合の扱い、個人用保護具は優先順位の高い対策を講じても低減できない場合に行うこと、優先順位の高い措置で十分に低減されれば低い措置の検討は不要なことは、正しい。

**根拠**：化学物質等による危険性又は有害性等の調査等に関する指針（厚生労働省）
