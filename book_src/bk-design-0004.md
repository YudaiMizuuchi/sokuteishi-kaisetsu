この章では、デザイン・サンプリングの問12・13によく出る、**液体捕集法**の原理を整理します。ガス状物質は、気泡と液の境目から、液に**溶ける（又は、反応する）**ことで捕まります。この1本の筋から、**気泡の大きさ**、**流量**、**捕集液の温度**、**捕集液の選び方**の向きが決まります。ガスと粒子では、流量の向きが逆になる点に注意します。拡散効果と真空捕集びんは `bk-design-tp09` で扱います。

## 導入クイズ

**Q1** バブラーによるガス状物質の捕集で、気泡が小さいほど、捕集率は高くなるか、低くなるか。

**Q2** 小型ガス吸収管による有機溶剤の捕集で、捕集液の温度が低いほど、捕集率は高くなるか、低くなるか。

答え：Q1は、高くなる。Q2は、高くなる。

## 1. この章の要点

- バブラーでは、気泡が**小さい**ほど、捕集率は**高く**なります。
- 小型ガス吸収管（ミゼットインピンジャーでも、ガス状物質なら同じ）では、流量が**大きい**ほど、捕集率は**低く**なります。
- 有機溶剤など揮発性物質では、捕集液の温度が**低い**ほど、捕集率は**高く**なります。
- 液体捕集では、測定対象物質を**溶かす**、又は**反応する**捕集液を使います（反応しない液は誤り）。

## 2. しくみ（原理）

### ガスは、気泡と液の境目から溶け込む

ガス状物質の液体捕集は、試料空気を**捕集液の中に通し**、ガスを液に**溶かす**、又は液と**反応させて**捕まえます。ガスが液に入れるのは、**気泡と液が接している面**です。この面を通して、少しずつ溶け込みます。

### ① 気泡が小さいほど、捕集率が高い

同じ量の空気でも、**小さな気泡**にすると、気泡の**表面積の合計**が大きくなります。**気体と液体が接する面積が大きい**ほど、溶け込みやすいので、**捕集率は高く**なります。バブラーは、空気の出口にグラスフィルターを付けて、気泡を小さくしています。逆に、「気泡が大きいほど、捕集率は高い」は誤りです。

### ② 流量が大きいほど、捕集率が低い

流量が大きいと、気泡は**速く**液の中を通り抜けます。ガスが液に溶ける**時間（接触時間）が短く**なるので、溶け残ったガスが抜け、**捕集率は低く**なります。

### ③ 捕集液の温度が低いほど、捕集率が高い

有機溶剤は揮発しやすい物質です。捕集液の温度が**高い**と、溶け込んだ溶剤が、また**蒸発**して逃げます。温度が**低い**ほど、**よく溶け**、**蒸発しにくい**ので、捕集率は高くなります。氷水で冷やして捕集するのは、このためです。

### ④ 捕集液の選び方

捕集液は、測定対象物質を**溶かす**、又は**反応する**ものを選びます。水に溶けにくい物質（キシレンなど）の捕集に、精製水を使っても、溶けません。「測定対象物質と反応しない捕集液を用いる」「キシレンの捕集液に精製水」は、誤りです。

### ガスと粒子で、流量の向きが逆

同じミゼットインピンジャーでも、**粒子状物質**の捕集は**慣性衝突**なので、流量が**大きい**ほど捕集率は**高く**なります（`bk-design-0012`）。**ガス状物質**は、溶ける時間が要るので、流量が**大きい**ほど**低く**なります。**向きが逆**です。

## 4. 解き方・覚え方

**ガス状物質**は、「溶ける面積・時間」で向きを決めます。

- 気泡が小さい → 面積が大きい → 捕集率**高**。
- 流量が大きい → 時間が短い → 捕集率**低**。
- 液温が低い → よく溶け、蒸発しにくい → 捕集率**高**。

**粒子状物質**（ミゼットインピンジャー）は、慣性衝突なので、向きが逆です（流量が大きいほど**高**）。問題文が「ガス状物質」か「粒子状物質」かを、まず見ます。

| 覚えること | 一言 |
|---|---|
| 気泡 | **小さい**ほど高い |
| 流量（ガス） | **大きい**ほど低い（粒子は逆） |
| 液温 | **低い**ほど高い |
| 捕集液 | 溶かす・反応する液（反応しない液は誤り） |

- `2017-08|design|12`：同じ形の問。**「バブラーによるガス状物質の捕集では、気泡が大きいほど捕集率は高くなる」が誤り（正答）**。小さいほど高くなります。
