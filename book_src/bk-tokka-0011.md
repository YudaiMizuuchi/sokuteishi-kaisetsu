この章では、問に出る2つの物質の**沸点・融点・蒸気圧の大小**を、**分子間力**という1つの考え方で決める方法を整理します。特定化学物質の問13〜問15に、ほぼ毎年出る範囲です。物質ごとの数値を暗記するのではなく、**大小関係を理由から導く**章です。

## 導入クイズ

**Q1** 分子量が大きく、分子間力が強い物質は、沸点が高いか低いか。常温での蒸気圧は、大きいか小さいか。

**Q2** 沸点が 25 ℃より低い物質は、常温（25 ℃）で、気体か液体か。

答え：Q1は、沸点は高く、常温での蒸気圧は小さい。Q2は、気体。

## 1. この章の要点

- **分子量が大きいほど**、また**分子間力が強いほど**（水素結合・極性が強いほど）、**沸点・融点は高く、蒸気圧は小さい**。
- 常温で**気体か液体か**は、**沸点と 25 ℃の大小**で決まる（沸点が 25 ℃より低ければ気体）。
- 水の**融点は 0 ℃、沸点は 100 ℃**。これを物差しにして、「水の融点より高い」「水の沸点より低い」を判断する。
- **蒸気圧が大きい物質ほど、沸点が低い**。

ランクは、12回のうち出た回数で付けた（S：5回以上、A：4回、B：3回、C：それ以下）。サイトの問題カードの区分は、論点ごとに付けるので、話題のランクとずれることがある。

## 2. しくみ（原理）

### 分子間力：分子どうしを引き合う力

液体が沸騰して気体になるとき、分子は、**となりの分子との引き合いを振り切って**、飛び出します。固体が融けるときも、分子を並べて固定している引き合いを、ゆるめます。だから、**引き合い（分子間力）が強い物質ほど、沸点・融点が高く**なります。逆に、引き合いが弱い物質は、わずかな熱で飛び出すので、**常温でも蒸気になりやすく、蒸気圧が大きく**なります。

分子間力の強さは、次の3つで決まります。

- **分子量**：大きい分子ほど、ファンデルワールス力（すべての分子にはたらく弱い引力）が強い。→ **分子量が大きいほど、沸点が高い**。
- **極性**：分子の中に、電気の偏り（プラスとマイナス）があると、分子どうしが引き合う。
- **水素結合**：N−H や O−H をもつ分子は、とくに強く引き合う。→ **分子量が小さくても、沸点・融点が高くなる**。

### 問に出る組合せを、理由で決める

過去問に出た組合せの大小関係は、次のとおりです（数値ではなく、**大小**だけを覚えます）。

| 組合せ | 分子間力の考え方 | 大小関係 |
|---|---|---|
| 臭化メチル と ヨウ化メチル | ヨウ化メチルの方が分子量が大きい | ヨウ化メチルの方が、沸点・融点が**高い**。蒸気圧は臭化メチルの方が**大きい**。25 ℃では、臭化メチルは気体、ヨウ化メチルは液体 |
| 塩化ビニル と 臭化メチル | 臭化メチルの方が分子量が大きい | 臭化メチルの方が、沸点・融点が**高い**（両物質とも 25 ℃で気体） |
| シアン化水素 と 硫化水素 | 分子量は硫化水素の方が大きいが、シアン化水素は極性が強く、水素結合をつくる | **シアン化水素の方が**、沸点・融点が**高い**（分子量の大小と逆） |
| エチレンイミン と エチレンオキシド | エチレンイミンは N−H をもち、水素結合をつくる | エチレンイミンの方が、融点が**高く**、20 ℃の蒸気圧は**小さい**。エチレンオキシドは 25 ℃で気体 |

シアン化水素の組と、エチレンイミンの組のように、**分子量の大小と逆になる**ことがあるので、**水素結合（N−H、O−H、H−CN の H）をもつか**を、先に見ます。

### 水を物差しにする

問には、「水の融点より」「水の沸点より」という言い方が出ます。水は、**融点 0 ℃・沸点 100 ℃**です。

- **臭化メチルの沸点は、水の融点（0 ℃）より高い**：臭化メチルは、0 ℃よりは高く、25 ℃よりは低い温度で沸騰します（そのため、25 ℃では気体）。
- 問に出る物質の多くは、**沸点が水の沸点（100 ℃）より低い**ので、「両物質とも、沸点は水の沸点より低い」は正しい記述です。
- 問に出る物質の**融点は、水の融点より低い**（0 ℃より低い温度で融ける）ものが、多いです。

### 「常温で液体か気体か」

沸点が **25 ℃より低い**物質は、常温で**気体**です（臭化メチル、塩化ビニル、エチレンオキシド）。沸点が 25 ℃より高い物質は、常温で**液体**です（ヨウ化メチル、エチレンイミン）。「両物質とも、常温では液体」は、片方が気体の組合せでは、誤りになります。

## 4. 解き方・覚え方

大小の比較の問は、次の順で考えます。

1. **分子量**の大きい方を探す。→ 大きい方が、沸点・融点が高く、蒸気圧が小さい。
2. **N−H・O−H・H−CN の H**など、**水素結合**をつくる分子があれば、そちらを「引き合いが強い」と判断する（分子量の大小に逆らってよい）。
3. 「常温（25 ℃）で気体か液体か」は、**沸点が 25 ℃より低いか**で決める。「水の融点・沸点より高い・低い」は、0 ℃・100 ℃と比べる。

暗記の1行表：

| 項目 | 内容 |
|---|---|
| 分子間力が強い | 沸点・融点が高い。蒸気圧は小さい |
| 蒸気圧が大きい | 沸点が低い。常温で気体になりやすい |
| 水の融点・沸点 | 0 ℃・100 ℃ |
| 臭化メチル と ヨウ化メチル | ヨウ化メチルの方が、沸点・融点が高い（臭化メチルの方が、蒸気圧が大きい） |

## 5. 例題

- `2016-08|tokka|15`：塩化ビニルと臭化メチルの物性の、誤りを選ぶ問。**「塩化ビニルの方が、臭化メチルより沸点が高い」が誤り（正答）**。臭化メチルの方が分子量が大きく、沸点・融点が高い。両物質とも融点は水の融点より低いこと、臭化メチルの沸点は水の融点より高いこと、両物質とも 25 ℃で気体であることは、正しい。
- `2020-08|tokka|14`：臭化メチルとヨウ化メチルの物性の、誤りを選ぶ問。**「両物質とも、常温（25 ℃）では液体である」が誤り（正答）**。臭化メチルは、沸点が 25 ℃より低く、気体。臭化メチルの方が蒸気圧が大きいこと、ヨウ化メチルの方が融点が高いこと、両物質とも液体の密度が水より大きいこと、エチルアルコールによく溶けることは、正しい。
