この章では、吸光光度分析の「**どのセルと光源を、どの波長で使うか**」「**溶液の色と吸収する光の関係**」「**発色させた液を、どう扱うか**」を、3つの原理にまとめます。有機溶剤の問15〜問17に、ほぼ毎回出る範囲です。

## 導入クイズ

**Q1** 紫外部の吸光度を測るとき、使えるセルは、ガラス製と石英製のどちらか。光源は何か。

**Q2** 青色の溶液と赤色の溶液では、可視部の主な吸収波長域は、どちらが長波長側にあるか。

答え：Q1は、石英製。光源は重水素ランプ。Q2は、青色溶液（赤〜橙の光を吸収する）。

## 1. この章の要点

- **ガラスやプラスチックは、紫外光を吸収する**。紫外部の測定には、**石英セル**と**重水素ランプ**。可視部は、ガラス・プラスチックのセルと、タングステンランプ。
- 溶液の色は、**吸収された光の補色**。**青色溶液は長波長側（赤〜橙）**、赤色溶液は短波長側（緑〜青）の光を吸収する。
- 測定波長は、**吸収極大**の波長。吸収極大やモル吸光係数は、**pH や呈色後の時間**で変わる。
- **加熱して発色**させたら、**常温に戻してから**測る。発色液は**退色**することがあるので、**安定しているうちに**測る。

## 2. しくみ（原理）

### 原理①　セル・光源の材質と波長：材質が光を吸収するなら、その波長は測れない

吸光光度計では、光が **光源 → モノクロメータ（波長を選ぶ）→ 試料セル → 検出器** の順に通ります。試料を測っているつもりでも、光が**セルの材質そのものに吸収**されてしまえば、正しく測れません。サングラス越しに、暗い色の物を見ようとするようなものです。

- **石英セル**：紫外部（200 nm 付近〜）から可視部まで光を通すので、**全測定波長領域**で使えます。
- **ガラスセル**：**400 nm より短波長の光を吸収**するので、**紫外部には使えません**（可視部だけ。「340 nm 以下の紫外域に使用する」「400 nm 以下を吸収するガラスセルが紫外部に適している」は誤り）。JIS K 0115:2020 では、ガラス製セルを 340 nm 以上の範囲で使うとしていますが、**紫外部に使えない**点は同じです。
- **プラスチック製セル**：安価で使い捨てできますが、紫外部の光を吸収するので、**可視領域の測定**に使います。

光源は、波長ごとに使い分けます。**紫外部（200〜400 nm）は重水素ランプ**、**可視部はタングステンランプ（ハロゲンタングステンランプ）**です。「紫外領域の光源に、ハロゲンタングステンランプ」は誤りです。

### 原理②　溶液の色と吸収波長：見える色は、吸収された光の「補色」

白色光（いろいろな波長の混合）を試料液に通すと、液が**ある色の光を吸収**し、**残りの光が目に届きます**。残りの色は、吸収された色の**補色**（反対側の色）です。

- **青色の溶液**は、補色にあたる**赤〜橙の光（長波長側）**を吸収しています。
- **赤色の溶液**は、補色にあたる**緑〜青の光（短波長側）**を吸収しています。
- 鉄（Ⅱ）とフェナントロリンの錯イオンは、**濃赤色**で、吸収極大は 510 nm（緑）です。

だから、**青色溶液の吸収波長域は、赤色溶液のそれより長波長側**にあります。「短波長側」は、入れ替えの誤りです。

### 原理③　発色反応の測定条件：感度と安定を、守る

無色の対象物質は、発色試薬を加えて**発色**させてから、吸光度を測ります。そのときの条件は、**感度と再現性**の2つから、決まります。

- **測定波長は、吸収極大の波長**にします。吸収極大では、モル吸光係数が最大で、**感度が最も高く**、波長が少しずれても吸光度があまり変わりません。ただし、共存物質や発色試薬自身の吸収が大きいときは、その影響のない波長を選びます。
- 吸収極大の波長や吸光度は、**pH や呈色後の時間**などの条件で変わります。「pH や溶媒の種類によらず一定」は誤りです。
- 反応を速めるために**加熱**したら、**常温に戻して**から測ります（温度で吸光度が変わるため。「できるだけ早く測る」は誤り）。
- 発色させた液は、時間がたつと**退色**することがあります。直射日光は、退色を早めます。**発色が安定しているうちに**測ります。

## 4. 解き方・覚え方

1. **紫外**と書いてあれば、**石英セル＋重水素ランプ**。ガラスやプラスチックのセル、タングステンランプが紫外に使えると書いてあれば、誤り。
2. **色の問**は、「その色の補色を吸収している」と考える。青なら赤〜橙＝長波長側。
3. **発色の問**は、「感度を最大にする（吸収極大）」「条件で変わる（pH・時間）」「温度を戻す」「退色前に測る」の4つ。「一定」「できるだけ早く」と言い切ったものは、疑う。

暗記の1行表：

| 項目 | 内容 |
|---|---|
| 石英セル | 紫外〜可視の全域 |
| ガラス・プラスチックのセル | 可視のみ |
| 光源 | 紫外は重水素ランプ、可視はタングステンランプ |
| 青色溶液 | 赤〜橙（長波長側）を吸収 |
| 測定波長 | 吸収極大 |
| 加熱後 | 常温に戻して測る |
| 発色液 | 退色前に測る |

## 5. 例題

- `2023-08|yuki|15`：吸光光度分析の誤りを選ぶ問。**「ガラス製セルは、波長 340 nm 以下の紫外域の測定に使用する」が誤り（正答）**。ガラスは短波長の光を吸収するので、紫外域には使えない。測定波長は吸収極大の波長、加熱したら常温に戻して測る、可視領域の光源はタングステンランプ、光電子増倍管は紫外領域の検出器に使える、は正しい。
- `2022-08|yuki|17`：**「発色反応のために試料液を加熱した場合は、できるだけ早く吸光度を測定する」が誤り（正答）**。常温に戻してから測る。吸収極大波長や吸光度は pH や呈色後の時間で変わること、石英セルは全測定波長領域で使えること、吸収極大が2つ以上あるときはモル吸光係数の大きい方の波長を選ぶことは、正しい。
