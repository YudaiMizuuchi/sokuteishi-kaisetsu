この章では、粉じんの質量濃度を求めるときに使う**天秤**について、**秤量値がずれる理由**と、**電子天秤のしくみ**を整理します。デザイン・サンプリングの、天秤の問に出ます。

## 導入クイズ

**Q1** 周囲より温度の高い試料を秤量すると、秤量値は真値より大きいか、小さいか。

**Q2** 電子天秤は、直示天秤より、温度の影響を受けやすいか。

答え：Q1は、小さくなる。Q2は、受けやすい（振動の影響は、電子天秤のほうが小さい）。

## 1. この章の要点

- **周囲より温度の高い試料**を秤量すると、秤量値は**真値より小さく**なる（**低い**試料では、**大きく**なる）。
- **天秤が水平でない**状態で秤量すると、秤量値は**真値より小さく**なる。
- **零位（電磁力平衡）方式**の電子天秤は、可動部の**微小変位**を、差動トランス、光電素子等で検出し、変位が**ゼロ**になるよう、**電磁力**で平衡をとる。
- **温度の影響は、電子天秤のほうが大きく**、**振動の影響は、電子天秤のほうが小さい**（直示天秤と比べて）。

## 2. しくみ（原理）

### 誤差の要因は、「温度」「水平」「帯電・振動」など

天秤は、**質量だけ**を測りたいのに、まわりの条件で、**測定値がずれる**ことがあります。この章では、出題の多い温度と水平を扱います。

### 温度：熱い試料は軽く、冷たい試料は重く出る

試料が**周囲より熱い**と、試料のまわりの空気が温められて、**上向きの気流**（対流）ができます。この気流が皿を**持ち上げる**ように働くので、秤量値は**真値より小さく**なります。逆に、**周囲より冷たい**試料では、空気が冷やされて**下向きの気流**ができ、皿を押し下げるので、秤量値は**真値より大きく**なります。ろ紙を、秤量する前に、**天秤室の温度になじませる**のは、このためです。

### 水平：傾くと、軽く出る

天秤は、**鉛直に下向きにかかる重さ**を測る装置です。**水平が保たれていない**と、重さの**一部しか**測る向きにかからず、秤量値は**真値より小さく**なります。天秤内部の**水準器**で、常に水平に保ちます。

### 電子天秤のしくみ（零位方式）

**零位（電磁力平衡）方式**は、次のように働きます。

1. 荷重がかかると、**可動部**が、わずかに**動く**（微小変位）。
2. この変位を、**差動トランス、光電素子**などで**検出**する。
3. 変位が**ゼロに戻る**よう、**電磁力**（磁力）で**外から力を加えて**、釣り合わせる。
4. そのとき**加えた力**から、質量を求める。

**ストレインゲージ**で、荷重の変化量を検出するのは、この方式ではありません（弾性体のひずみを測る**力測定方式**の考え方）。

### 電子天秤と直示天秤：温度と振動

過去問では、直示天秤と比べて、電子天秤は、**温度の影響が大きく**、**振動の影響が小さい**とされます。「電子天秤は、温度変化による感度の変化が、直示天秤に比べて**小さい**」は、**誤り**です（5回のうち2回が、この誤りの形）。

## 3. 頻出の表

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| 試料の温度（8回・S） | 周囲より**高い**試料 → 秤量値は**小さく**。**低い**試料 → **大きく** | この論点は、すべて正しい記述として出る |
| 零位方式（5回・A） | 微小変位を**差動トランス、光電素子**等で検出し、**電磁力**で平衡をとる | 「荷重の変化量を**ストレインゲージ**で検出する」（5回中1回） |
| 水平（5回・A） | 水平が保たれていないと、秤量値は**小さく**なる | この論点は、すべて正しい記述として出る |
| 温度・振動の影響（5回・A） | 温度の影響は**電子天秤が大きい**。振動の影響は**電子天秤が小さい** | 「電子天秤は、**温度変化による感度の変化が小さい**」（5回中2回） |

## 4. 解き方・覚え方

1. **熱い → 軽く出る**、**冷たい → 重く出る**（上昇気流で、持ち上がるイメージ）。
2. **傾き → 軽く出る**（真値より小さい）。
3. 零位方式 ＝ **差動トランス・光電素子で検出 ＋ 電磁力で戻す**。**ストレインゲージは別の方式**。
4. 電子天秤は、**温度に弱く、振動に強い**（直示天秤との比較）。

| 条件 | 秤量値 |
|---|---|
| 試料が熱い | 小さい |
| 試料が冷たい | 大きい |
| 水平でない | 小さい |

## 5. 例題

- `2022-08|funjin|11`：電子天秤の、誤りを選ぶ問。**「電子天秤は、比較的操作が簡便で、読み取りも容易であるとともに、温度変化による感度の変化も直示天秤に比べ小さい」が誤り（正答）**。温度の影響は、電子天秤のほうが大きい。試料の温度が高いと秤量値が小さくなること、零位方式の検出が差動トランス、光電素子等であること、力測定方式が弾性体のひずみを測ることは、正しい記述。
- `2016-08|funjin|10`：天秤の、誤りを選ぶ問。**「零位（電磁力平衡）方式の電子天秤では、荷重の変化量をストレインゲージで検出する」が誤り（正答）**。差動トランス、光電素子等で、微小変位を検出する。温度の影響は電子天秤が大きいこと、振動の影響は電子天秤が小さいこと、試料が熱いと秤量値が小さくなることは、正しい記述。
