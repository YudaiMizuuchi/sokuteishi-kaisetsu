この章では、有機溶剤の分析で使う**標準液のつくり方**、**検量線の使い方**、**GC-MS の定量**、**吸光光度分析（分光光度計）**を、まとめて整理します。定量下限を求める式は `bk-yuki-0016` で扱い、ここでは手順だけです。

## 導入クイズ

**Q1** 検量線の範囲を超えた高濃度の試料液は、検量線を延長して定量してよいか。

**Q2** 分光光度計で、モノクロメータは、どこに置くか。

答え：Q1は、延長してはいけない（誤り）。Q2は、光源と試料セルの間。

## 1. この章の要点

- **検量線は、標準液の濃度範囲の中で使う**。範囲を超えた試料液は、**外挿（延長）せず**、希釈して測り直す。
- **標準液**は、標準物質を**脱着溶媒**で希釈してつくる。高濃度の**標準原液を冷暗所に保管**し、検量線をつくる**都度**、希釈して標準系列液をつくる。
- **GC-MS** の定量は、**ターゲットイオン**のピーク面積（又は高さ）で行う。
- **分光光度計**は、光源 → **モノクロメータ** → **試料セル** → 検出器の順。検出器は、**光電子増倍管**。

## 2. しくみ（原理）

### 検量線は、「確かめた範囲」の中だけで使う

検量線は、濃度のわかった標準液で、「この濃度のときは、この大きさの信号」と**確かめた範囲**を表したものです。範囲の外は、信号と濃度の関係が**直線のままか、確かめていません**。だから、範囲を超えた試料液は、**延長して**値を出さず、**希釈して**範囲に入れて測り直します。

- FID は、直線範囲が広い検出器ですが、無限ではありません。「FID は直線範囲が広いので、検量線を延長してよい」は、誤りです。
- 試料の濃度が、標準系列液の**最高濃度と最低濃度のあいだ**に入るように、標準系列液をつくります。
- 検量線は、測定の都度、つくります。

### 標準液のつくり方

- 標準物質を**脱着溶媒**（活性炭から有機溶剤を脱着する溶媒）で希釈します。試料液と同じ溶媒にそろえるためです。
- 有機溶剤は、蒸気圧が高く、**揮発しやすい**ので、**高濃度の標準原液**を**冷暗所**に保管し、検量線をつくる**都度**、必要な濃度に希釈します。
- 標準液の**保存可能期間**は、**溶質と溶媒の組合せ**によって異なります。

### GC の定量下限を求める手順

標準液で**検量線**をつくる → 定量下限付近の**標準試料を5回（以上）繰り返し分析**する → 測定値を検量線から濃度にして、その**標準偏差**を求める。標準偏差から定量下限を出す式は、`bk-yuki-0016` で扱います。

### GC-MS の定量

GC-MS では、成分を**ターゲットイオン**（その成分を代表するイオン）で検出し、その**ピーク面積**（又は**高さ**）で定量します（JIS K 0123:2018）。

### 分光光度計

光は、**光源 → モノクロメータ → 試料セル → 検出器**の順に進みます。

- **光源**：**可視部**（約350〜800 nm）は**タングステンランプ**、**紫外部**（約200〜400 nm）は**重水素ランプ**。
- **モノクロメータ**：光源からの光を**単色光**にします（回折格子）。**光源と試料セルの間**に置きます。
- **検出器**：**光電子増倍管**。紫外領域にも、可視領域にも使えます。
- **試料セル**：**紫外部**は**石英セル**。ガラスセルは、400 nm より短い波長の光を吸収するので、**可視部**で使います。
- **ランベルト・ベールの法則**：吸光度は、濃度と光路長に比例します。
- 測定できる**波長範囲**は、通常 **200〜1000 nm**。**溶媒**は、試料の溶解性の高いものを使います。

## 4. 解き方・覚え方

1. **外挿・延長は、誤り**（検量線）。「濃度範囲内」「希釈して再測定」が正しい。
2. 標準液は、**脱着溶媒・冷暗所・都度希釈**。
3. 穴埋めは、**波長で決める**：紫外部（250 nm、300 nm）なら、**重水素ランプ・モノクロメータ・石英セル**。可視部（520 nm）なら、**タングステンランプ・モノクロメータ**（ガラスセルでよい）。「スリット」は誤り。

| 項目 | 正しい値・語 |
|---|---|
| 光の進む順 | 光源 → モノクロメータ → 試料セル → 検出器 |
| 紫外部・可視部の光源 | 紫外部＝重水素ランプ、可視部＝タングステンランプ |
