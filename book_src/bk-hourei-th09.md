労働衛生関係法令の**問3**（平成27年度第2回は問3と問4）は、**安全衛生教育**。出題は2つの形。**記述の正誤**（「教育に関する記述のうち誤っているもの」。雇入れ時・作業内容変更時の教育、特別教育の省略・記録3年・講師の資格はない・報告はない、職長等の教育の業種、能力向上教育の努力義務の中に、**「業種にかかわらず」「資格を有する者から選任」「報告しなければならない」「7年間」**などの誤りが1つ混ざる）と、**業務の語句**（「特別の教育を行わなければならない業務に該当しないものはどれか」。**特定粉じん作業・石綿使用建築物等の解体等・酸素欠乏危険場所・高圧室内作業・廃棄物の焼却施設**〔対象〕の中に、**特定化学物質・有機溶剤業務・鉛業務・騒音・重量物・暑熱・潜水**〔対象でない〕が混ざる）。この章は、**教育の種類と根拠**、**特別教育の対象になる業務・ならない業務の一覧**、**省略・記録・講師・報告**、**職長等の教育の業種**を、数値表にそろえる。

ほかの章との分担：酸素欠乏危険作業の特別教育の科目と作業は `bk-hourei-th16`、作業主任者（職長教育を受けない、など）は `bk-hourei-th02`、衛生管理者・衛生委員会・職長教育の業種を含む衛生管理体制は `bk-hourei-th15`。この章には、それぞれ**一覧表の1行**として入れ、詳しくは、その章を指す。

## 導入クイズ

**Q1** 特定化学物質を製造し、又は取り扱う業務に労働者を就かせるときは、特別教育を行わなければならないか。

① 行わなければならない　② 規定されていない

**Q2** 特別教育を行ったときの、受講者・科目等の記録の保存期間は、3年間か、7年間か。

① 3年間　② 7年間

**Q3** 職長等の教育は、事業場の業種にかかわらず、行わなければならないか。

① 業種にかかわらず　② 政令で定める業種

答え：Q1は②（規定されていない。特別教育の対象は、安衛則第36条に掲げられた業務だけ。「行わなければならない」は、誤りの形）。Q2は①（3年間。「7年間」は、誤りの形）。Q3は②（建設業、製造業〔一部を除く〕、電気業、ガス業、自動車整備業、機械修理業。「業種にかかわらず」は、誤りの形）。

## 2. 教育の種類と、雇入れ時の教育

### 数値表①　雇入れ時・作業内容変更時の教育

**出題実績**：10回（平成27年度第1回、平成28年度第2回、平成29年度第1回、平成30年度第1回、令和元年度第1回、令和2年度第1回、令和2年度第2回、令和3年度第2回、令和4年度第2回、令和6年度第1回）。

**原理**（労働安全衛生法第19条の2・第59条・第60条・第60条の2、労働安全衛生規則第35条〜第40条）：安全衛生教育は、次の5種類を区別する。

| 教育 | 対象 | 義務の強さ | 根拠 |
|---|---|---|---|
| **雇入れ時の教育** | 労働者を**雇い入れたとき**（業種・規模を問わない） | 行わなければならない | 安衛法第59条第1項、安衛則第35条 |
| **作業内容変更時の教育** | 労働者の**作業内容を変更したとき** | 行わなければならない | 安衛法第59条第2項、安衛則第35条 |
| **特別教育** | **危険又は有害な業務**で厚生労働省令で定めるもの（安衛則第36条） | 行わなければならない | 安衛法第59条第3項、安衛則第36条〜第39条 |
| **職長等の教育** | **新たに職務につくこととなった職長**その他の作業中の労働者を直接指導又は監督する者（**作業主任者を除く**）。**政令で定める業種**の事業場 | 行わなければならない | 安衛法第60条、令第19条、安衛則第40条 |
| **能力向上教育** | **安全管理者、衛生管理者、安全衛生推進者、衛生推進者**その他労働災害の防止のための業務に従事する者 | **努めなければならない**（努力義務） | 安衛法第19条の2 |

危険又は有害な業務に**現に就いている者**への教育は、**努力義務**（安衛法第60条の2）。雇入れ時・作業内容変更時の教育は、**十分な知識及び技能を有していると認められる労働者**については、その事項の教育を**省略**できる（安衛則第35条第2項）。

## 5. 解き方・覚え方のまとめ

1. **教育の5種類**：雇入れ時・作業内容変更時（全業種）、特別教育（危険・有害な業務）、職長等の教育（政令で定める業種の新任の職長。作業主任者を除く）、能力向上教育（努力義務）。
2. **特別教育の対象**：**酸欠・特定粉じん・透過写真（エックス線・ガンマ線）・高圧室内・焼却施設（焼却灰・保守点検・解体）・石綿使用建築物等の解体等**。**特定化学物質・有機溶剤・鉛・騒音・暑熱・重量物・潜水は、対象でない**。
3. **特別教育の細目**：科目の**省略は可**（第37条）、記録は**3年間**（第38条）、講師の**資格はない**、署長への**報告はない**。
4. **職長等の教育**：業種は、建設業・製造業（一部を除く）・電気業・ガス業・自動車整備業・機械修理業。省略は可。
5. 誤りの選択肢は、「特定化学物質（有機溶剤業務）に特別教育」「講師は資格を有する者から選任」「署長に報告」「7年間」「業種にかかわらず職長教育」「石綿等を取り扱う作業は、作業の内容にかかわらず特別教育」。

**公式まとめ（暗記の1行表）**

| 項目 | 内容 |
|---|---|
| 特別教育の対象 | 酸欠・特定粉じん作業（注水・注油を除く）・エックス線/ガンマ線透過写真・高圧室内・焼却施設・石綿使用建築物等の解体等 |
| 特別教育の対象でない | 特定化学物質・有機溶剤・鉛・騒音・暑熱・重量物・潜水 |
| 記録 | 受講者・科目等を、3年間保存（安衛則第38条） |
| 講師・報告 | 講師の資格の定めなし。署長への報告の定めなし |
| 省略 | 十分な知識及び技能がある者は、省略できる（特別教育：第37条、職長教育：第40条第3項、雇入れ時：第35条第2項） |
| 職長等の教育 | 政令で定める業種（建設業・製造業〔一部を除く〕・電気業・ガス業・自動車整備業・機械修理業）。作業主任者を除く |
| 能力向上教育 | 衛生管理者・安全衛生推進者等。努力義務 |
