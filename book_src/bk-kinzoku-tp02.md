この章では、金属類の前処理（**試料を酸で溶かす・灰にする**操作）を整理します。覚えるのは、「酸」だけではなく、**金属（と分析法）の組**です。同じ「湿式灰化」でも、バナジウムの原子吸光と、NBPHA 吸光光度法では、使う酸が違います。

## 導入クイズ

**Q1** 粉状ニッケル化合物の試料の溶解に、硫酸を用いることができるか。

**Q2** バナジウムの湿式灰化に使う酸は、原子吸光分析と NBPHA 吸光光度法で同じか。

答え：Q1は、用いない（硝酸、塩酸、又はその混酸）。Q2は、違う（原子吸光は硝酸＋過酸化水素水、NBPHA 吸光光度は硫酸＋過酸化水素水）。

- **マンガン**（原子吸光）の試料液の調製は、**塩酸と硝酸の混酸**。「硫酸と硝酸」は誤り。

## 2. しくみ（原理）

### 前処理の目的：金属を「溶液」にする

原子吸光分析、ICP、吸光光度分析は、金属を**イオンとして溶かした溶液**を測ります。ろ紙に捕集した粉じんの金属を、**酸で溶かし出す**のが前処理です。有機物が多い試料は、先に**湿式灰化**（酸と過酸化水素水で有機物を分解）します。測定に使う試料の状態は、蛍光光度分析などでは、**溶液**が最もよく使われます。

### 酸の性質：酸化力か、塩化物か

- **硝酸**：**酸化力がある**ので、多くの金属を溶かします。鉛・カドミウム・クロム（希硝酸）は、硝酸に溶けます。ただし**濃硝酸**は、ニッケルなどの遷移金属の表面に**酸化被膜**をつくり、かえって溶けません（「ニッケルは濃硝酸に溶ける」は誤り）。
- **塩酸**：酸化力はありませんが、**塩基性の酸化物**（酸化コバルト（Ⅱ）、酸化ニッケル（Ⅱ）、酸化マンガン（Ⅳ））を溶かします。酸化クロム（Ⅲ）は、塩酸に溶けません。
- **硫酸**：**希硫酸には酸化力がありません**。酸化バナジウム（Ⅴ）は、硫酸に溶けます。
- **過酸化水素水**：湿式灰化で、**有機物を分解する**（酸化を助ける）役目です。

### 金属と分析法の組で、使う酸が決まる

| 金属・分析法 | 試料の処理に使う酸 | ひっかけ（誤り） |
|---|---|---|
| マンガン（原子吸光） | **塩酸と硝酸の混酸**（塩酸：硝酸 ＝ 2：1 を用時調製） | 硫酸と硝酸の混酸 |
| 粉状ニッケル化合物（原子吸光） | **硝酸、塩酸、又はその混酸**。温浴で溶かす | 硫酸を用いる（ことができる） |
| バナジウム（原子吸光） | **硝酸と過酸化水素水**（湿式灰化） | |
| バナジウム（NBPHA 吸光光度） | **硫酸と過酸化水素水**（湿式灰化） | 塩酸と過酸化水素水、硝酸と過酸化水素水 |
| ベリリウム（吸光光度） | **塩酸と硫酸**（溶解） | |
| カドミウム（APDC 抽出－原子吸光） | 硝酸 | |

**「ニッケルは硫酸を使わない」のに、「ベリリウムは塩酸と硫酸」なのは、金属ごとに、溶けやすい酸が違う**からです。また、**同じバナジウムでも、あとの測定法が違えば、灰化の酸も違います**（NBPHA 吸光光度では、硝酸を使いません）。問題文の最初の1行（どの金属・どの分析法か）を、必ず確かめます。

### 温浴：酸を穏やかに働かせる

粉状ニッケル化合物の溶解は、**温浴**（約60 ℃）で、時間をかけて加熱します（「硝酸あるいは塩酸による溶解は、約60 ℃の温浴中で2時間加熱」）。直火でなく温浴にするのは、酸が急に沸騰したり、揮散したりするのを防ぐためです。溶解のあとの**不溶物**は、定量用ろ紙で除きます。

### クロム（Ⅵ）の発色と、硫酸の濃度

クロム（Ⅵ）は、ジフェニルカルバジドと反応して**赤紫色**に発色します。この反応は、**酸性**（硫酸 0.025〜0.1 mol/L 程度）で行います。標準液の酸濃度は、試料液と**そろえます**。

## 4. 解き方・覚え方

「試料の溶解・前処理の誤っているもの」は、次の順で見ます。

1. **問題文の金属と分析法**を確認する（組で覚える）。
2. **硫酸**が出てきたら、金属を確認する（ニッケル・マンガン：誤り。ベリリウム、バナジウムの NBPHA 吸光光度：正しい）。
3. **「ニッケルは濃硝酸に溶ける」**、**「酸化クロム（Ⅲ）は塩酸に溶ける」**は誤り。
4. **希硫酸の酸化力**：「酸化力がある」は誤り。

## 5. 例題

- `2026-08|kinzoku|18`：粉状ニッケルの原子吸光分析の、誤りを選ぶ問。**「試料の溶解には、硫酸を用いることができる」が誤り（正答）**。硝酸・塩酸（又は混酸）を使う。ガラス繊維ろ紙での捕集、温浴の使用、不溶物の定量用ろ紙での除去、酸による抽出率が 95 ％程度であることは、正しい。
- `2025-08|kinzoku|14`：NBPHA を用いる五酸化バナジウムの吸光光度分析の、誤りを選ぶ問。**「試料の湿式灰化には、硝酸と過酸化水素水が用いられる」が誤り（正答）**。この分析法では、硫酸と過酸化水素水を使う。リン酸が共存しても干渉しないこと、NBPHA がバナジウム（Ⅴ）と錯体をつくること、クロロホルム層に抽出されること、メンブランフィルターで捕集することは、正しい。
