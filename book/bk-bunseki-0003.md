この章では、吸光光度分析法の問13・14に出る**モル吸光係数 ε** を整理します。ε は、A ＝ ε × c × l の比例定数です。同じ話の続きは、`bk-bunseki-0001`（ランベルト・ベールの法則）と `bk-bunseki-0002`（吸光度と透過率）です。

## 導入クイズ

**Q1** モル吸光係数の単位は、mol⁻¹·L·cm⁻¹ か、mol·L⁻¹·cm か。

**Q2** モル吸光係数は、光路長に比例するか。

答え：Q1は、mol⁻¹·L·cm⁻¹。Q2は、比例しない。

## 1. この章の要点

- 単位は **mol⁻¹·L·cm⁻¹**。
- 波長によって**異なる**（吸収極大波長で、極大になる）。**溶媒**の種類によっても、異なることがある。
- 物質と波長で決まる**定数**で、濃度や**光路長には比例しない**。
- 単位濃度（mol/L）・単位長さ（cm）当たりの吸光度が、モル吸光係数。

ランクは、23回のうち出た回数で付けた。原理は、12回・S です。原理としては S なので、C の行も表に入れています。

| 話題 | 出た回数／23回 | ランク |
|---|---|---|
| ① 単位 | 7 | C |
| ② 波長 | 5 | C |
| ③ 溶媒 | 3 | C |
| ④ 定義 | 1 | C |
| ⑤ 光路長に比例しない | 1 | C |
| ⑥ 計算（濃度を求める） | 1 | C |

## 2. しくみ（原理）

A ＝ ε × c × l を変形すると、**ε ＝ A ÷（c × l）**。吸光度 A は単位のない数なので、ε の単位は、c（mol/L）と l（cm）の積の逆数、**mol⁻¹·L·cm⁻¹** になります（①）。「mol·L⁻¹·cm」は、逆数になっていないので誤りです。

ε は、物質ごと・波長ごとの「光の吸収されやすさ」を表す定数です。

- **波長**が変われば、吸収の強さが変わるので、ε も変わる。吸収極大波長で最大（②）。
- **溶媒**が変わると、分子のまわりの環境が変わり、ε が変わることがある（③）。
- **濃度や光路長**を変えても、ε は変わらない。変わるのは、吸光度 A のほう（⑤）。「光路長に比例する」のは、A です。

ε が大きいほど、同じ濃度でも吸光度が大きくなり（高感度）、④の定義のとおりです。

## 4. 解き方・覚え方

- **単位**は、式 ε ＝ A ÷（c × l）から出す。c と l の単位を**逆数**にする。
- **変わるもの**（波長・溶媒）と、**変わらないもの**（濃度・光路長）を分けて覚える。
- 計算は、c ＝ A ÷（ε × l）に、数を入れるだけ（くわしくは `bk-bunseki-0001`）。

| 覚えること | 一言 |
|---|---|
| 単位 | mol⁻¹·L·cm⁻¹（逆数） |
| 波長・溶媒 | 変わる |
| 濃度・光路長 | 変わらない（ε は定数） |

## 5. 例題

- `2021-02|bunseki|14`：吸光光度分析法の、誤りを選ぶ問。**「単位は、mol·L⁻¹·cm である」が誤り（正答）**。吸光度が濃度と光路長に比例すること、ε が溶媒や波長で異なることは、正しい。
- `2018-08|bunseki|14`：同じ形の問。**「溶媒の種類を変えても変化しない」が誤り（正答）**。変化することがあります。透過光がランベルト・ベールの法則に従うこと、単位が mol⁻¹·L·cm⁻¹ であることは、正しい。
- `2018-02|bunseki|13`：同じ形の問。誤りは、透過した光の強さが濃度に比例するという記述（この章の話ではなく、`bk-bunseki-0002`）。ε が波長で異なること、単位が mol⁻¹·L·cm⁻¹ であることは、正しい。
- `2016-08|bunseki|13`：同じ形の問。誤りは、透過する光の強さが光路長に比例するという記述（`bk-bunseki-0002`）。ε が波長・溶媒で異なることは、正しい。
