有機溶剤の問題は、毎回、**問1・2が物性**、**問4〜7が試料採取と検知管**。この章は、後者と物性をあわせて、**器具ごとの数字と条件**（1 L以上、1.33 kPa以下、5 L以上、50〜100 mL/min など）と、**組合せ**（捕集剤と脱着溶媒）を、一語ずつそろえる。誤っているものを選ぶ形で、選択肢は、数字・「必要」「不要」・「比例」「反比例」の1語が入れ替えてある。

ほかの章との分担：ガスクロマトグラフ分析と検量線は `bk-yuki-forms`、有機溶剤の管理濃度は `bk-ippan-fr03`、A・B測定の測定点は `bk-design-forms`。

## 導入クイズ

**Q1** 真空捕集びんは、びん内の圧力を、どのくらいにして使うか。

① 1.33 kPa以下　② 13.3 kPa以下　③ 101.3 kPa

**Q2** 活性炭管の脱着溶媒として、使えないのは、どれか。

① 二硫化炭素　② 精製水　③ N,N-ジメチルホルムアミド

**Q3** 検知管の濃度目盛は、何℃を基準にしているか。

① 20℃　② 25℃　③ 0℃

答え：Q1は①（13.3 kPaは、誤りの形）。Q2は②（精製水は、シリカゲル管の脱着溶媒）。Q3は①（20℃。温度補正を要するときは、補正表を使う）。

## 2. 固体捕集（捕集剤・脱着溶媒・破過）

### テーマ1　固体捕集［S］

**出題実績**：9回（平成28年度第1回、平成29年度第1回、令和元年度第1回、令和2年度第1回、令和3年度第1回〜令和7年度第1回）。

**表①　捕集剤**（J-86 3.2.4。過去問の正答）

| 捕集剤 | 特徴 |
|---|---|
| **活性炭** | **無極性**の有機溶剤に吸着力が強い。**乾燥した空気又は窒素の気流中**で、約200℃で加熱し、**脱水**して使う。空気中の水分の除去や冷却は、**不要**。単位質量当たりの**表面積は、シリカゲルより大きい** |
| **シリカゲル** | **極性が強い**ガス状物質の捕集に有効。**水の吸着力が強く**、水分含有率で**吸着容量が変わる**。100〜110℃で約1時間加熱して活性化 |
| **ポーラスポリマービーズ** | 活性炭より**捕集容量は小さい**が、表面が**不活性**で、**重合・酸化**などが起こりにくい。活性炭より**加熱脱着が容易**（過去問） |

**破過**（J-86 3.2.4(5)）：市販の捕集管は、捕集剤を**2層**に分ける。後層の検出量が前層の**10％以下**なら、両層の和で計算してよい。**10％を超える**と、捕集率が低下している可能性があり、**捕集をやり直す**。

**表②　捕集剤と脱着溶媒の組**（J-86 表Ⅲ.12 の例。過去問の正答）

| 有機溶剤 | シリカゲル管の脱着溶媒 | 活性炭管の脱着溶媒 |
|---|---|---|
| アセトン | メタノール | N,N-ジメチルホルムアミド（DMF） |
| メチルエチルケトン | アセトン | **二硫化炭素** |
| イソプロピルアルコール | DMF | DMF |
| N,N-ジメチルホルムアミド | （なし） | アセトン |
| メタノール | **精製水** | DMF |
| キシレン・トルエン・n-ヘキサン | アセトン | **二硫化炭素** |
| クロロベンゼン | メタノール | **二硫化炭素** |

**精製水**は、**シリカゲル管**だけ。**二硫化炭素**は、**活性炭管**だけ（J-86 の脱着溶媒の記号表の「対象捕集管」）。

**ひっかけパターン**（過去問で、「不適当」として出た組。㋑物質／㋺捕集管／㋩脱着溶媒）

- メタノール／**活性炭管**／**精製水**（令和3年度第1回）。
- n-ヘキサン／**活性炭管**／**精製水**（令和5年度第1回）。
- クロロベンゼン／**活性炭管**／**精製水**（令和6年度第1回）。
- メタノール／活性炭管／**二硫化炭素**（令和7年度第1回）。
- 活性炭は、「シリカゲルに比べて、単位重量当たりの**表面積が小さい**」（大きい。令和4年度第1回）。
- 2層の捕集管で、後層の検出量が前層の10％を**超えた**とき、「両層の和で計算する」（10％以下。令和2年度第1回）。

正しい組として出たもの（おとり）：キシレン／活性炭管／二硫化炭素。イソプロピルアルコール／活性炭管／DMF。アセトン／シリカゲル管／メタノール。メチルエチルケトン／シリカゲル管／アセトン。メタノール／シリカゲル管／精製水。クロロベンゼン／シリカゲル管／メタノール。

（令和3年度第1回の「イソプロピルアルコール／活性炭管／酢酸n-ブチル」は、過去問では適当な組として出ている。J-86 表Ⅲ.12〔p.76 付近〕の活性炭管は DMF で、一致しない。作業環境測定基準の別表第2は、脱着溶媒を定めていない。過去問に沿うが、組は、表Ⅲ.12 の規則で覚える。JIS K 0114:2012 に、固体捕集管・脱着溶媒の規定は、ない。）

**覚え方**：「**水（精製水）はシリカだけ**」「**CS₂ は炭（活性炭）だけ**」。無極性（キシレン・トルエン・n-ヘキサン）は、**炭＋CS₂**。極性（アセトン・メタノール）は、**シリカ**。

**例題**（`2025-08|yuki|5`、`2024-08|yuki|5`、`2023-08|yuki|5`、`2020-08|yuki|6`、`2022-08|yuki|5`）：捕集管と脱着溶媒の組を、表②の規則で照らす。

## 8. 解き方・覚え方のまとめ

1. **固体捕集**：**水（精製水）はシリカゲル管だけ**。**二硫化炭素は活性炭管だけ**。無極性は炭＋CS₂、極性はシリカ。後層が前層の **10％以下**なら、合算。
2. **活性炭**は、無極性に強く、**水分除去・冷却は不要**。表面積は、**シリカゲルより大きい**。**ポーラスポリマー**は、反応性が低く、加熱脱着が容易。
3. **真空捕集びん**：**1 L以上**、**1.33 kPa以下**、グリース**不使用**、吸引流量は**一定でない**。
4. **捕集袋**：**5 L以上**。新しい袋は、**妨害物質**を考える。**その日のうちに**分析。
5. **流量計の校正**は、**石けん膜流量計**で、**捕集器具をつないだ状態**。ポンプの流量調整も、**つないで**行う。
6. **ミゼットインピンジャー**のガラスビーズ：**接触面積が大きくなる**。**小型ガス吸収管**：**50〜100 mL/min**。
7. **パッシブサンプラー**：拡散現象。**流量校正は不要**。**気流の影響を受ける**。速度は、**物質ごとに異なる**。**拡散係数と断面積に比例**、**拡散長に反比例**。
8. **検知管**：**20℃**基準。**非特異的**で、共存物質の妨害あり。**脱着不要**。**電動ポンプも可**。**C・D測定でも用いることができる**（過去問）。
9. **物性**：沸点は、**アセトン ＞ 二硫化炭素 ＞ エチルエーテル**。**二硫化炭素**は、水より重く、水と分離して下層。**n-ヘキサン**は、密度が最小。

**公式まとめ（暗記の1行表）**

| 項目 | 内容 |
|---|---|
| 真空捕集びん | 内容積 1 L以上、1.33 kPa以下 |
| 捕集袋 | 内容積 5 L以上 |
| 小型ガス吸収管 | 捕集液 3〜5 mL、50〜100 mL/min |
| 活性炭管の脱着溶媒 | 二硫化炭素（CS）・DMF・アセトンなど（精製水は不可） |
| シリカゲル管の脱着溶媒 | メタノール・アセトン・精製水・DMF など（二硫化炭素は不可） |
| 破過の判定 | 後層 ≦ 前層の 10％ なら合算 |
| 検知管の目盛 | 20℃ 基準 |
| パッシブの速度 | ∝ 拡散係数 × 断面積 ÷ 拡散長 |
| キャニスター（個人） | 400〜600 mL |
