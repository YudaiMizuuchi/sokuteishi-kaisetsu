有機溶剤の**問8〜13**は、毎回、**ガスクロマトグラフ（GC）**。その中で、**「トルエンより保持時間の長い（短い）有機溶剤は、どれか」**（問8）、**「極性が最も高いものは、どれか」**（問2・3）、**「最もテーリングを起こしやすいものは、どれか」**（問12・13）は、物質を1つ選ぶ型。この章は、**保持時間と溶出順の原理**を、沸点・極性・カラム温度で、そろえる。ほかの章との分担：キャリアガス・注入法・検出器・質量分析計・キャピラリカラム・計算は `bk-yuki-tp01`。

## 導入クイズ

**Q1** 無極性カラムで、同族体は、どの順に溶出するか。

① 沸点の低い順　② 沸点の高い順

**Q2** カラム温度が高いほど、保持時間は、どうなるか。

① 短くなる　② 長くなる

**Q3** 無極性カラムで、最もテーリングを起こしやすいのは、どれか。

① n-ヘキサン　② メタノール　③ トルエン

答え：Q1は①（沸点の低い順）。Q2は①（温度が高いほど、短くなる）。Q3は②（極性の高い、OH基をもつ物質）。

## 2. 溶出順と極性

### 原理（pr-yuki-0009）　保持時間と溶出順［S］

**出題実績**：11回（平成27年度第1回、平成29年度第1回〜令和8年度第1回）。

**原理**（J-73 2.6.2）：GC では、成分が、気相（移動相）と液相（固定相）の間を、分配しながら進む。固定相への分配が**大きい**（保持が**強い**）成分ほど、カラムを通るのに時間がかかり、**保持時間が長い**。分配の大きさは、成分の**沸点**（蒸気になりにくさ）と、成分と固定相の**極性の近さ**で決まる。

**表①　固定相ごとの溶出の考え方**（J-73 2.6.2・2.6.4、JIS K 0114:2012、過去問の正答）

| カラム（固定相） | 溶出の考え方 | トルエンより保持時間の長い物質（過去問の正答） |
|---|---|---|
| **無極性**（メチルシリコン系。OV-1 など） | **沸点の低い順**に溶出する（同族体）。沸点の高い物質ほど、保持時間が長い | **エチレングリコールモノ-n-ブチルエーテル**（平成27年度第1回・令和3年度第1回）、**シクロヘキサノン**（令和7年度第1回） |
| **極性**（ポリエチレングリコール20M など） | **極性の高い**物質ほど、保持が**強く**、保持時間が**長い**。沸点の高い物質も長い | **キシレン類**（令和2年度第1回・令和5年度第1回・令和8年度第1回〔m-キシレン〕）、**シクロヘキサノン**（平成30年度第1回）、**エチレングリコールモノメチルエーテル**（平成27年度第1回）、**エチレングリコールモノエチルエーテルアセテート**（令和6年度第1回） |

**トルエンより保持時間の短い物質**（極性カラム、令和4年度第1回の正答）：**メチルエチルケトン**。同じ問の選択肢で、長い側は、酢酸イソペンチル、エチレングリコールモノエチルエーテルアセテート、エチレングリコールモノエチルエーテル、シクロヘキサノン。

極性カラムで、トルエンより**短い**ことが、過去問の誤りの選択肢で確認された物質：メタノール、二硫化炭素、酢酸メチル、メチルエチルケトン、酢酸エチル、n-ヘキサン、アセトン、テトラヒドロフラン、イソプロピルアルコール、エチルエーテル、2-ブタノール、酢酸 n-プロピル（令和8年度第1回・令和6年度第1回・令和2年度第1回・平成30年度第1回・平成27年度第1回の誤りの選択肢）。

**覚え方**：**無極性＝沸点順**。**極性カラム＝トルエンより長いのは、「キシレン」「シクロヘキサノン」「グリコールエーテル類」**。ケトン・エステル・エーテル・低沸点のアルコールは、トルエンより短い。

**JIS K 0114:2012 との照合**（サイト側の確認結果）：キャピラリーカラムの固定相の膜厚は、**0.05〜20 µm 程度**。ジメチルポリシロキサン（分配形キャピラリーカラム）は、**無極性で、沸点順**の溶出。**McReynolds 数が大きいほど、極性が強い**。線速度と保持時間の関係、カラム温度と保持時間の関係は、JIS に直接の記述がない（「過去問の正答による」）。

**極性が最も高いもの**（過去問の正答）：**イソブチルアルコール**（令和元年度第1回・令和4年度第1回・令和8年度第1回。ほかの選択肢：酢酸エチル、n-ヘキサン、トルエン、テトラヒドロフラン、シクロヘキサン、二硫化炭素、クロロベンゼン、酢酸イソプロピル）。**N,N-ジメチルホルムアミド**（令和6年度第1回。ほかの選択肢：クロロベンゼン、酢酸イソブチル、n-ヘキサン、エチルエーテル）。**覚え方**：「**OH基（アルコール）・アミド**が、高い」。炭化水素・ハロゲン化炭化水素は低い。

**テーリングを起こしやすい物質**（無極性カラム。過去問の正答）：**メタノール**（令和2年度第1回）、**イソプロピルアルコール**（平成30年度第1回）、**1-ブタノール**（平成27年度第1回）、**エチレングリコールモノエチルエーテル**（平成29年度第1回）。いずれも**OH基をもつ極性の物質**。ピークの後半が広くなる（JIS K 0114:2012：テーリング）。内壁が不活性化されていないと、シラノール基のため、極性の化合物でテーリングが生じる（J-73 2.6.2）。

**覚え方**：「**無極性カラムで、OH基の物質は、テーリング**」。n-ヘキサン・トルエン・キシレン・1,1,1-トリクロロエタンは、起こしにくい。

**ひっかけパターン**：極性カラムで、「n-ヘキサン」「二硫化炭素」「アセトン」を、トルエンより長いとする。無極性カラムで、「メタノール」「イソプロピルアルコール」を、トルエンより長いとする（沸点が低い）。

**例題**（`2026-08|yuki|8`、`2022-08|yuki|13`、`2025-08|yuki|8`、`2021-08|yuki|8`、`2026-08|yuki|2`、`2024-08|yuki|3`、`2020-08|yuki|13`、`2018-08|yuki|12`）。

## 3. カラム温度・膜厚・長さ・線速度

### 論点　保持時間を変える条件［A］

**出題実績**：5回（平成27年度第1回、平成29年度第1回、平成30年度第1回、令和2年度第1回、令和8年度第1回）。

**表②　保持時間と条件**（J-73 2.6.2・2.6.4、JIS K 0114:2012、過去問の正答）

| 条件 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **カラム温度** | 温度が**高い**ほど、保持時間は**短く**なる（令和8年度第1回）。温度が**低い**ほど、固定相への分配が**大きく**なり、分離は**良く**なる。ただし、低すぎると、ピークがブロードになり、テーリングする（J-73 2.6.4(3)） | — |
| **液相の膜厚** | **厚くなる**と、保持時間は**長く**なる（平成30年度第1回・令和2年度第1回）。液相の比率が高いと、保持容量が大きくなる（J-73） | 「厚くなると、保持時間は**短く**なる」（平成27年度第1回・令和8年度第1回） |
| **カラムの長さ** | **2倍**になると、保持時間も理論段数も、**約2倍**（令和8年度第1回の正しい選択肢。理論段数は長さに比例：J-73 2.6.2） | 「理論段数は、**約√2倍**」（令和5年度第1回。`bk-yuki-tp01`） |
| **内径** | 内径が**細い**ほど、単位長さ当たりの理論段数は**大きい**（理論段相当高さは小さい） | 「内径が細いカラムの方が、理論段相当高さが**大きい**」（平成30年度第1回） |
| **線速度** | 保持時間は、キャリアガスの線速度に**ほぼ反比例**する | 「**ほぼ比例**する」（平成29年度第1回・令和6年度第1回） |
| **同族体** | 無極性カラムでは、**沸点の低い順**に溶出（平成27年度第1回・平成29年度第1回） | — |

**覚え方**：「**温度↑ → 保持時間↓**」「**膜厚↑ → 保持時間↑**」「**線速度↑ → 保持時間↓（反比例）**」。

**例題**（`2026-08|yuki|13`、`2026-08|yuki|12`、`2020-08|yuki|11`、`2018-08|yuki|10`、`2015-08|yuki|13`、`2017-08|yuki|14`）。

## 4. 解き方・覚え方のまとめ

1. **保持時間は、固定相への分配（沸点と極性の近さ）で決まる**。分配が大きいほど、長い。
2. **無極性カラム**：沸点の低い順に溶出。**同族体**は、沸点順。
3. **極性カラム（PEG 20M）で、トルエンより長いもの**：キシレン類、シクロヘキサノン、グリコールエーテル類。ケトン・エステル・エーテル・低級アルコールは、短い。
4. **極性が最も高いもの**：OH基をもつアルコール（イソブチルアルコール）と、アミド（DMF）。炭化水素・ハロゲン化炭化水素は低い。
5. **無極性カラムで、OH基の物質は、テーリング**する。
6. **温度↑ → 保持時間↓**。低温は、分配が大きく、分離が良い。**膜厚↑ → 保持時間↑**。**線速度↑ → 保持時間↓（反比例）**。
7. **カラムの長さが2倍 → 保持時間も理論段数も約2倍**。

**公式まとめ（暗記の1行表）**

| 項目 | 内容 |
|---|---|
| 無極性カラムの溶出順 | 沸点の低い順（同族体） |
| 極性カラム | 極性が高いほど、保持が強く、保持時間が長い |
| カラム温度と保持時間 | 高いほど短い |
| 膜厚と保持時間 | 厚いほど長い |
| 線速度と保持時間 | ほぼ反比例 |
| 長さが2倍 | 保持時間・理論段数とも約2倍 |
| 分離度 R | 1.5より大きいと、ほぼ完全に分離 |
