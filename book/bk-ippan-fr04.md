この章では、有害物が体に入ってから出ていくまでの流れと、**「物質 → 尿中・血中の指標」の対応**を、しくみから整理します。労働衛生一般の問3〜問4で、ほぼ毎回出る範囲です。

## 導入クイズ

**Q1** スチレンとキシレンは、体内で代謝されて、尿中にそれぞれ何として排泄されるか。

**Q2** 鉛の生物学的モニタリングで、「赤血球中」で測る指標と、「尿中」で測る指標は何か。

答え：Q1は、スチレンがマンデル酸（フェニルグリオキシル酸も）、キシレンがメチル馬尿酸。Q2は、赤血球中がプロトポルフィリン、尿中がδ-アミノレブリン酸（血液中では、鉛そのものを測る）。

## 1. この章の要点

- 有機溶剤は、体内で代謝されて、**物質ごとに決まった尿中代謝物**として出る。**スチレン・エチルベンゼン → マンデル酸、キシレン → メチル馬尿酸、テトラクロロエチレン → トリクロロ酢酸・総三塩化物**。
- **鉛**の指標は3つ：**血液中の鉛、尿中のδ-アミノレブリン酸、赤血球中のプロトポルフィリン**。
- 有機溶剤は**脂溶性**が高く、**中枢神経系など脂肪に富んだ組織**に蓄積しやすい。
- **カドミウム**は、主として**腎臓皮質**に蓄積する。
- 誤りは、**物質と代謝物の入れ替え**（キシレン → エチル馬尿酸、など）と、**測る場所の入れ替え**（赤血球中のδ-アミノレブリン酸、など）の形で出る。

ランクは、23回のうち出た回数で付けた。

| 話題 | 出た回数／23回 | ランク |
|---|---|---|
| スチレン（エチルベンゼンも）は、尿中にマンデル酸として排泄される | 12 | S |
| キシレンは、尿中にメチル馬尿酸として排泄される | 11 | S |
| 鉛の指標は、血液中の鉛・尿中のδ-アミノレブリン酸・赤血球中のプロトポルフィリン | 11 | S |
| 有機溶剤は脂溶性が高く、中枢神経系など脂肪に富んだ組織に蓄積しやすい | 9 | A |
| テトラクロロエチレンの指標は、尿中の総三塩化物（代謝物はトリクロロ酢酸） | 8 | A |
| カドミウムは、主として腎臓皮質に蓄積される | 7 | B |

## 2. しくみ（原理）

### 体に入ってからの流れ：吸収 → 分布 → 代謝 → 排せつ

有害物は、肺（蒸気・粉じん）・皮膚・消化管から体に入り、血液にのって全身をめぐります。どの臓器に多く集まるかは、その物質が**どの組織と相性がよいか**で決まります。体内に入った物質は、多くが**肝臓**で酸化・抱合などの化学変化を受け（代謝）、尿や呼気などから出ていきます。体内の量が半分になるまでの時間を**生物学的半減期**といい、長い物質ほど体にたまりやすくなります。

代謝は、**無毒にする**ことが多い一方で、代謝産物のほうが毒性をもつこともあります（ベンゼンのフェノール・カテコールなど）。

### 有機溶剤は「油に溶ける」から、脳や神経にたまる

有機溶剤の多くは、水に溶けにくく、**油（脂肪）に溶けやすい**性質（脂溶性）をもちます。そのため、血液から**脂肪に富んだ組織**に移りやすく、脂質の多い**脳・神経系（中枢神経系）**に蓄積しやすくなります。有機溶剤中毒で、頭痛・めまい・麻酔作用などの中枢神経症状が目立つのは、このためです。

### なぜ、尿を調べると、ばく露が分かるのか

脂溶性のままでは、尿に出にくい。そこで肝臓が、**水に溶ける形に作り変えて**（酸化して酸にし、さらにアミノ酸のグリシンなどと結合して）尿に出します。この「作り変えた先の物質」は、**もとの物質ごとに決まっている**ので、尿中の代謝物の量から、どれだけ吸い込んだかを推定できます。これが**生物学的モニタリング**です。

- **トルエン**：側鎖のメチルが酸化されて安息香酸になり、グリシンと結合して**馬尿酸**。
- **キシレン**：同じ道筋をたどり、メチル基が残るので**メチル馬尿酸**。「トルエンの馬尿酸に、メチルが付いた」と覚える（「エチル馬尿酸」は存在しない言い方）。
- **スチレン・エチルベンゼン**：酸化の途中で**マンデル酸**になり、さらに**フェニルグリオキシル酸**にもなる。
- **テトラクロロエチレン**（トリクロロエタン、トリクロロエチレンも）：塩素を含む溶剤なので、塩素を含む**トリクロロ酢酸**などの「三塩化物」が出る。**塩素のないキシレンやトルエンから、トリクロロ酢酸は出ない**。

トルエンの馬尿酸には落とし穴があります。**食品の保存料などに含まれる安息香酸**を摂ると、同じ道筋で馬尿酸になるので、**尿中の馬尿酸が、見かけ上、高くなる**ことがあります（「低くなる」は誤り）。

### 鉛：ヘモグロビンづくりの邪魔をする

鉛は、赤血球のヘモグロビン（ヘム）をつくる過程を邪魔します。途中の材料であるδ-アミノレブリン酸が**尿中**にあふれ、プロトポルフィリンが**赤血球中**にたまります。だから、指標は3つになります。

| 指標 | どこで測るか |
|---|---|
| 鉛そのもの | 血液中 |
| δ-アミノレブリン酸 | 尿中 |
| プロトポルフィリン | 赤血球中 |

血液中の鉛は、**直近（数日以内）**のばく露を反映し、ほかの指標は、**少し遅れて（数週間以内）**上がります。鉛は骨にもたまり、体内の量は減りにくい物質です。なお、血液中のカドミウム、尿中又は血液中のマンガンも、それぞれの指標として出ます。

### カドミウム：腎臓にたまる

有機化合物と違い、金属は**代謝されず**、出ていくまでもとの金属のままです。カドミウムは、肝臓でメタロチオネインというたんぱく質と結合し、血液にもどって**腎臓（皮質）**に蓄積します。標的臓器は腎臓で、**腎障害**を起こします。マンガンではありません。

## 4. 解き方・覚え方

1. 選択肢の物質を見て、「**芳香族**（馬尿酸・マンデル酸の仲間）」「**塩素を含む溶剤**（トリクロロ酢酸・総三塩化物）」「**金属**（血液・尿・臓器）」に分ける。
2. 代謝物の名前が、**その物質の構造と合うか**を確かめる（キシレンはメチル、塩素のない物質にトリクロロ酢酸はない）。
3. **場所**（血液中・尿中・赤血球中）まで読む。

暗記の1行表（この章の表にない物質も含む）：

| 物質 | 指標 |
|---|---|
| スチレン、エチルベンゼン | 尿中のマンデル酸（スチレンは、フェニルグリオキシル酸との和でも） |
| キシレン | 尿中のメチル馬尿酸 |
| トルエン | 尿中の馬尿酸（飲食物の安息香酸で、高くなることがある） |
| n-ヘキサン | 尿中の2,5-ヘキサンジオン（ヘキサノール、シクロヘキサノンは誤り） |
| N,N-ジメチルホルムアミド | 尿中のN-メチルホルムアミド |
| 1,1,1-トリクロロエタン、トリクロロエチレン、テトラクロロエチレン | 尿中のトリクロロ酢酸又は総三塩化物 |
| 鉛 | 血液中の鉛、尿中のδ-アミノレブリン酸、赤血球中のプロトポルフィリン |
| カドミウム | 血液中のカドミウム（尿中のβ₂-ミクログロブリンも） |
| マンガン | 尿中又は血液中のマンガン |

## 5. 例題

- `2023-02|ippan|3`：化学物質の吸収・代謝・蓄積の誤りを選ぶ問。**「テトラクロロエチレンの指標は、尿中のテトラクロロエタン」が誤り（正答）**。指標は、トリクロロ酢酸などの総三塩化物。キシレン → メチル馬尿酸、スチレン → マンデル酸、鉛 → 赤血球中のプロトポルフィリン、トルエンの馬尿酸は安息香酸で高くなることがある、は正しい。決め手は、「塩素を含む溶剤の代謝物は、三塩化物」。
- `2021-02|ippan|3`：**「キシレンは、尿中にエチル馬尿酸として排泄される」が誤り（正答）**。メチル馬尿酸。血液中の鉛が指標になること、有機溶剤が中枢神経系などに蓄積しやすいこと、ジメチルホルムアミド → N-メチルホルムアミド、有機溶剤は半減期が短いので採尿時刻を正確に、は正しい。
