この章では、**ICP（誘導結合プラズマ）**を使う分析法のしくみと特徴を学びます。ICP-AES（発光分光）と ICP-MS（質量分析）の記述問題が、金属類の問7〜問9、問18〜問19に出ます。

## 導入クイズ

**Q1** プラズマをつくるガスは何か。

**Q2** ICP で、一度に何種類もの元素を測れるか。

答え：Q1は、アルゴン。Q2は、測れる（多元素同時分析ができる）。

## 1. この章の要点

- プラズマの生成には、**アルゴン**を使う。
- ICP は**多元素同時分析**ができ、**ほぼすべての金属元素**を分析できる。
- **試料溶液の粘性**は、測定値（発光強度）に**影響する**（「影響しない」は誤り）。
- ICP-MS は、**質量数（質量／電荷比）のイオン強度（カウント数）**で定量する。
- 原子吸光分析法に比べて、**化学干渉やイオン化干渉は起こりにくい**。

ランクは、12回のうち出た回数で付けた（S：6回以上、A：4〜5回、B：3回、C：それ以下）。サイトの問題カードの区分は、論点ごとに付けるので、話題のランクとずれることがある。

## 2. しくみ（原理）

### ICP は、「高温の炎」で元素を光らせる

ICP は、アルゴンガスに高周波の電流を流してつくる、**非常に高温のプラズマ**（イオンと電子が飛び交う状態）です。試料溶液を霧にして（ネブライザー）、このプラズマに吹き込むと、

1. 溶液の水分がとび、元素が**原子になる**。
2. 高温なので、原子が**励起**される（またはイオン化する）。
3. **ICP-AES**：励起された原子・イオンが元の状態に戻るとき、**元素ごとに決まった波長の光（発光線）**を出す。この光の強さで定量する。
4. **ICP-MS**：できたイオンを、**質量／電荷比**で分けて数える（イオン強度＝カウント数）。

### 特徴は、「高温」と「元素ごとの光（質量）」から

- **多元素同時分析ができる**：高温のプラズマの中では、ほぼすべての金属元素が光る（または、イオンになる）。だから、1回の吸い込みで、いくつもの元素を同時に測れる。
- **化学干渉・イオン化干渉が起こりにくい**：プラズマが高温なので、試料に含まれる共存成分と目的元素が結びついたままにはなりにくい。フレーム原子吸光（炎）より、こうした干渉が少ない。
- **アルゴン**を使うのは、反応しにくい（不活性）ガスだから。

### 試料溶液の「粘性」は、測定値に影響する

溶液は、ネブライザーで**吸い上げられて、霧**になります。溶液が**ねばっこい（粘性が大きい）**と、吸い上げられる量が変わり、プラズマに入る量が変わります。すると、**発光強度（測定値）が変わります**。だから、「粘性は測定値に影響しない」は誤りです。

酸の濃度が高いと、粘性が大きくなるので、最終試料液の酸の濃度が高すぎないようにします（「酸濃度は2 mol/L 以上が望ましい」は誤り）。ICP-MS では、試料液は**硝酸酸性**が望ましいとされます。

### ICP-AES と ICP-MS の違い

| | ICP-AES | ICP-MS |
|---|---|---|
| 測るもの | 発光線の強さ | 質量／電荷比ごとのイオン強度（カウント数） |
| 感度 | ふつう | 高い（定量下限は ICP-AES より低い） |
| そのほか | 発光線の近くの分光干渉に注意 | 同位体分析ができる |

## 4. 解き方・覚え方

「ICP の誤っているもの」は、次の順で見ます。

1. 「粘性は**影響しない**」→ 誤り。
2. 「**多元素同時分析が不可能**」→ 誤り（可能）。
3. 「原子吸光に比べて、化学干渉・イオン化干渉が**起こりやすい**」→ 誤り（起こりにくい）。
4. 「プラズマはアルゴン」「ICP-MS は質量／電荷比のイオン強度」は、正しい。
