この章では、有機溶剤の**物質ごとの健康障害**を、「どの臓器・組織が狙われるか」で整理します。労働衛生一般の問8〜問10に、ほぼ毎回出る範囲です。ひっかけは、**物質のすり替え**（メタノールを二硫化炭素の障害に、トルエンをベンゼンの障害に、など）です。

## 導入クイズ

**Q1** 網膜の微細動脈瘤などの血管障害を起こす有機溶剤は何か。

**Q2** 再生不良性貧血などの造血器障害を起こすのは、ベンゼンとトルエンのどちらか。

答え：Q1は、二硫化炭素。Q2は、ベンゼン（トルエンではない）。

## 1. この章の要点

- **ハロゲン化炭化水素（塩素化炭化水素）**は、一般に**肝臓**に対する毒性が強い。
- **二硫化炭素**は、**網膜の微細動脈瘤**などの血管障害を起こし、**高濃度ばく露で精神障害**を生じる。
- **N,N-ジメチルホルムアミド**は、**頭痛・めまい・肝機能障害**。
- **ベンゼン**は**造血器障害**（再生不良性貧血）。トルエンではない。
- **酢酸メチル**は**視神経障害**（視力低下、視野狭窄）。
- **1,2-ジクロロプロパン**は、肝臓・腎臓の障害と、長期間の高濃度ばく露による**胆管がん**。**n-ヘキサン**は**多発性神経炎**。

ランクは、23回のうち出た回数で付けた（S：11回以上、A：8〜10回、B：6〜7回、C：それ以下）。サイトの問題カードの区分は、論点ごとに付けるので、話題のランクとずれることがある。

## 2. しくみ（原理）

### 有機溶剤は、脂に溶け、肺から入る

有機溶剤は、一般に**脂溶性**が高く、**中枢神経系など脂肪に富んだ組織**に蓄積しやすい性質があります。蒸気は空気より重いので、低いところや、通気の悪い場所に**滞留**します。主に**肺**から吸い込まれ、皮膚からも吸収されます。だから、どの有機溶剤にも、**頭痛・めまいなどの中枢神経抑制作用**がありますが、問に出るのは、その物質に**特有の障害**です。

### 物質ごとの「標的」：臓器別に覚える

- **肝臓**：**ハロゲン化炭化水素**（四塩化炭素、ジクロロメタン、トリクロロエチレンなど）は、**肝臓**に障害を起こします（腎臓にも）。**N,N-ジメチルホルムアミド**は、頭痛・めまい・消化不良のほか、**肝機能障害**を起こします。ハロゲン化炭化水素のなかには**難燃性**のものがあり、「引火性が特に強い」は誤りです。
- **目（網膜）**：**二硫化炭素**は、動脈硬化を進め、**網膜の微細動脈瘤**を生じます（そのため、健康診断で眼底検査を行います）。
- **目（視神経）**：**メタノール**と、体内でメタノールに代謝される**酢酸メチル**は、**視神経**を障害します（視力低下、視野狭窄）。同じ「目」の障害でも、**二硫化炭素は網膜の血管、メタノール・酢酸メチルは視神経**と、場所が違います。
- **神経（精神）**：**二硫化炭素**は、高濃度の急性ばく露で**精神障害**を生じます。
- **神経（末梢）**：**n-ヘキサン**は、体内で 2,5-ヘキサンジオンに代謝され、**末梢神経障害（多発性神経炎）**を起こします。
- **血液**：**ベンゼン**は、長期間のばく露で**造血器障害**（再生不良性貧血）を起こし、白血病の原因になるとされています。**トルエン**やキシレンは、中枢神経への作用が中心で、造血器障害ではありません（トルエンは生殖毒性があるとされています）。
- **胆管**：**1,2-ジクロロプロパン**は、印刷工場の洗浄に使われ、長期間の高濃度ばく露で**胆管がん**を発症したことで知られます（肝臓・腎臓の障害も）。

「**目は2か所**（網膜＝二硫化炭素、視神経＝メタノール・酢酸メチル）」「**血液はベンゼン**」「**末梢神経はn-ヘキサン**」と、**物質と障害を1対1で結び付けて**覚えます。

## 4. 解き方・覚え方

「有機溶剤の健康障害のうち、誤っているもの」は、**物質と障害の組合せ**を1つずつ見ます。

1. **ベンゼン ＝ 造血器**。トルエン・キシレンに「造血器障害」とあれば誤り。
2. **二硫化炭素 ＝ 網膜微細動脈瘤・精神障害**。メタノール・酢酸メチルに「網膜微細動脈瘤」とあれば誤り。
3. **メタノール・酢酸メチル ＝ 視神経**（視力低下、視野狭窄）。
4. **ハロゲン化炭化水素 ＝ 肝臓**。「引火性が強い」とあれば誤り。

暗記の1行表：

| 物質 | 障害 |
|---|---|
| ハロゲン化炭化水素 | 肝臓（難燃性のものもある） |
| 二硫化炭素 | 網膜微細動脈瘤、高濃度で精神障害 |
| N,N-ジメチルホルムアミド | 頭痛・めまい・肝機能障害 |
| ベンゼン | 造血器障害（再生不良性貧血） |
| 酢酸メチル・メタノール | 視神経障害 |
| 1,2-ジクロロプロパン | 肝臓・腎臓、胆管がん |
| n-ヘキサン | 多発性神経炎 |

## 5. 例題

- `2026-02|ippan|10`：有機溶剤による人体への影響の、誤りを選ぶ問。**「トルエンによる健康障害では、再生不良性貧血などの造血器障害を生じる」が誤り（正答）**。造血器障害を起こすのはベンゼン。有機溶剤が脂溶性が高く中枢神経系などに蓄積しやすいこと、酢酸メチルで視力低下や視野狭窄を生じること、ハロゲン化炭化水素系有機溶剤の肝臓毒性が強いこと、n-ヘキサンの多発性神経炎は、正しい。
- `2023-02|ippan|8`：**「メタノールによる健康障害として顕著なものは、網膜細動脈瘤を伴う脳血管障害である」が誤り（正答）**。網膜の微細動脈瘤は二硫化炭素の障害で、メタノールは視神経障害。二硫化炭素の高濃度ばく露で精神障害を起こすこと、塩素化炭化水素系有機溶剤の肝臓毒性が強いことは、正しい。アセトンが脂溶性と水溶性を共に有すること、N,N-ジメチルホルムアミドの極性がトルエンより大きいことも、正しい（この章の主な論点ではない）。
