この章では、特定化学物質の分析（吸光光度分析法とガスクロマトグラフ分析法）の問に出る、**発色の前処理**、**標準溶液の標準物質**、**発色が要らない物質**、**ガスクロマトグラフの計算と導入法**を整理します。蛍光光度法の原理は `bk-bunseki-0004` で扱います。

## 導入クイズ

**Q1** シアン化水素を捕集した溶液は、酢酸と塩酸の、どちらで中和してから発色させるか。

**Q2** ガスクロマトグラフで、保持時間が同じなら、ピーク幅は、理論段数が大きいほど、広いか、狭いか。

答え：Q1は、酢酸（塩酸は誤り）。Q2は、狭い（理論段数の平方根に反比例する）。

## 1. この章の要点

- **シアン化水素**の捕集液は、**酢酸**で中和してから発色。「**塩酸**で」は誤り。
- 標準溶液の標準物質の**不適切な組合せ**：塩素／**塩化ナトリウム**、硫酸ジメチル／**硫酸ナトリウム**、硫化水素／**硫酸亜鉛**。
- **発色操作が要らない**のは、**色素（マゼンタ、オーラミン）**。
- ガスクロマトグラフ：**ピーク幅の比＝√（理論段数の逆比）**。**スプリット注入法**は、低濃度試料に**適していない**（高濃度試料向き）。

## 2. しくみ（原理）

### 吸光光度分析法：色をつけて、濃さを測る

吸光光度分析法は、**試料液に光を当て、吸収される光の量**から、濃度を求める方法です。無色の物質は、光を吸収しないので、**発色試薬**を加えて、色のついた物質に変えてから測ります（**発色操作**）。次の2点が、問に出ます。

- **シアン化水素**（ピリジン-ピラゾロン法）：捕集液（水酸化ナトリウム溶液）は、アルカリ性です。発色の反応は、**中性付近**で進むので、**酢酸**で中和してから、発色試薬を加えます。**塩酸**を使う、**酸性にする**のは、誤りです。
- **色素**（マゼンタ、オーラミン）：物質自身が**色をもつ**ので、**発色操作は不要**で、そのまま測れます。アクリロニトリル、ジアニシジン、エチレンイミン、トルエンジイソシアネートなどは、発色操作が要ります。

試料液に当てる光は、**単色光**です（光源の光を、回折格子などの**モノクロメーター**で、特定の波長に選ぶ）。波長がそろっていないと、吸光度と濃度の比例が崩れます。着色液は、**時間がたつと退色する**ことがあるので、呈色後は、決められた時間内に測ります。

### 標準溶液の標準物質

標準溶液は、**測定対象の物質を、分析で測る形に合わせて**、安定な物質から調製します。

| 測定対象 | 標準溶液の調製に使う物質 |
|---|---|
| シアン化水素 | シアン化カリウム |
| 臭化メチル | 臭化カリウム |
| フッ化水素 | フッ化ナトリウム |
| 硫化水素 | 硫化ナトリウム |
| 塩素 | 次亜塩素酸ナトリウム |
| 硫酸ジメチル | メタノール |

**不適切な組合せ**は、「塩素／**塩化ナトリウム**」「硫酸ジメチル／**硫酸ナトリウム**」「硫化水素／**硫酸亜鉛**」です。硫酸亜鉛は、硫化水素の**捕集液**に使う物質で、標準物質ではありません。

### ガスクロマトグラフ：ピークの幅と、理論段数

理論段数 N は、カラムの分離のよさを表す数で、**N ＝ 16 ×（保持時間 ÷ ピーク幅）²** です。保持時間が同じなら、**N が大きいほど、ピーク幅は狭く**なります。式を変形すると、ピーク幅は **√N に反比例**します。

> **WB／WA ＝ √（NA／NB）**

カラムAとBの保持時間が同じとき、この式で、ピーク幅の比が出ます。

**キャピラリーカラム**の試料導入法のうち、**スプリット注入法**は、導入した試料の大部分を**捨てて**、一部だけをカラムに入れる方法です。**高濃度の試料**には向きますが、微量成分が捨てられるので、**低濃度試料には適しません**。

**固定相液体**（カラムの中の、成分を分ける液体）は、**蒸気圧が低く**（流れ出さない）、分析対象物質を**溶かす力**（溶解力）があり、**反応性や熱分解性が低い**ものが適します。ポリエチレングリコールエーテルなどは、重合度によって**極性**が変わります。

検出器は、FID（水素炎イオン化検出器）が、有機化合物の広い範囲で使え、直線範囲も広い。ECD（電子捕獲検出器）は、**電子親和性の高い化合物**に高感度ですが、**直線範囲は、FIDより狭い**。

## 4. 解き方・覚え方

**標準物質の組合せ**は、「**測る形に合わせた塩**」で見ます。塩素は**次亜塩素酸ナトリウム**、硫酸ジメチルは**メタノール**、硫化水素は**硫化ナトリウム**。**塩化ナトリウム、硫酸ナトリウム、硫酸亜鉛**が入った組は、不適切と決めます。

**ピーク幅の比**は、解き方が1つです。

1. 保持時間が同じなら、**WB／WA ＝ √（NA／NB）**。
2. 分子は、**Aの理論段数**、分母は、**Bの理論段数**。
3. 平方根を取る。

| 項目 | 覚え方 |
|---|---|
| 塩素の標準物質 | 次亜塩素酸ナトリウム（塩化ナトリウムではない） |
| 発色が要らない | マゼンタ・オーラミン（色素） |
| スプリット | 低濃度に不向き（試料を捨てる） |
| 単色光 | モノクロメーターで選ぶ |

## 5. 例題

**例題1（⑤を、通しで解く）** `2023-08|tokka|7`：カラムAの理論段数が9000、カラムBが5000で、保持時間が同じ。ピーク幅の比 WB／WA は。

1. WB／WA ＝ √（NA／NB）＝ √（9000／5000）
2. ＝ √1.8 ＝ **1.34** → 選択肢4

逆に、`2026-08|tokka|6`（NA ＝ 5000、NB ＝ 9000）は、√（5000／9000）＝ √0.556 ＝ **0.75** → 選択肢3。

**例題2（②）** `2021-08|tokka|17`：標準物質の組合せの、不適切なものを選ぶ問。**「塩素／塩化ナトリウム」が不適切（正答）**。シアン化水素／シアン化カリウム、臭化メチル／臭化カリウム、硫酸ジメチル／メタノール、フッ化水素／フッ化ナトリウムは、適切。

**例題3（①）** `2025-08|tokka|3`：シアン化ナトリウムの捕集と分析の、誤りを選ぶ問。**「捕集した溶液は、塩酸で中和した後、発色操作を行う」が誤り（正答）**。酢酸で中和する。捕集液が水酸化ナトリウム溶液であること、標準原液を硝酸銀溶液で滴定して求めること、クロラミンTとピリジン-ピラゾロンで発色させることは、正しい。
