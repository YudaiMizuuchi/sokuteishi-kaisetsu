この章では、労働衛生一般の「労働衛生保護具」「防毒マスク」の問に出る、**呼吸用保護具の使い分け**、**防毒マスクの吸収缶**、**防じんマスクの使い方**、**耳栓**を整理します。酸素欠乏の場所の保護具は `bk-ippan-fr12`、吸収缶のしくみ（吸着）は `bk-ippan-0004` でも扱います。

## 導入クイズ

**Q1** 有機ガス用防毒マスクの吸収缶の色は何色か。一酸化炭素用は何色か。

**Q2** 耳栓の1種は、低音から高音まで遮音するか、主に高音だけを遮音するか。

答え：Q1は、有機ガス用＝黒、一酸化炭素用＝赤。Q2は、低音から高音まで遮音する（主に高音を遮音するのは2種）。

## 1. この章の要点

- 酸素濃度 **18％未満**で使えるのは、**給気式**（送気マスク・空気呼吸器・酸素呼吸器）**だけ**。防毒マスク・電動ファン付き呼吸用保護具は使えない。
- **隔離式**防毒マスクは、**直結式**より、使える濃度の範囲が**広い**。
- 吸収缶の色：**有機ガス用＝黒**、**一酸化炭素用＝赤**、**アンモニア用＝緑**。
- 吸収缶の**破過時間**は、**温度・湿度が高いほど短い**。メタノール・ジクロロメタン・二硫化炭素・アセトンは、試験用ガスより短い。臭気で交換時期を決められるのは、**臭気を感知できる濃度がばく露限界濃度より著しく低い**物質だけ。
- 防じんマスクは、**接顔メリヤスを使わない**（密着性が下がる）。ろ過材の粉じんは、**圧縮空気で吹き飛ばしたり、たたいたりしない**。**使い捨て式も、型式検定の対象**。
- 耳栓は、**1種＝低音から高音まで**、**2種＝主に高音**（会話程度の低音は通す）。

## 2. しくみ（原理）

### ろ過式と給気式

防じんマスクや防毒マスクのような**ろ過式**は、まわりの空気から粉じんやガスを取り除くだけで、**酸素は作れません**。だから、酸素が 18％未満の場所では使えません。使えるのは、**きれいな空気や酸素を供給する給気式**（送気マスク・空気呼吸器・酸素呼吸器）だけです。電動ファン付き呼吸用保護具も、ろ過式です。

### 防毒マスク：隔離式と直結式、吸収缶

防毒マスクは、**吸収缶**でガスや蒸気を取り除きます。吸収缶を、面体に直接つけるのが**直結式**、ホースでつなぐのが**隔離式**です。隔離式は、大きな吸収缶を使えるので、**より濃いガスにも対応**でき、使える濃度の範囲が広い。それでも、隔離式の有機ガス用は、ガス・蒸気の濃度が **2％を超える**場所（アンモニアは 3％）では使えません。

吸収缶の色は、ガスの種類を見分けるために決まっています。

| 吸収缶 | 色 |
|---|---|
| 有機ガス用 | **黒** |
| 一酸化炭素用 | **赤** |
| アンモニア用 | **緑** |
| ハロゲンガス用 | 灰色と黒（二層） |
| 硫化水素用 | 黄 |
| シアン化水素用 | 青 |

### 破過時間

**破過**は、吸収缶が吸い取りきれなくなって、ガスが通り抜け始めることで、そこまでの時間が**破過時間**です。有機ガス用の吸収缶は、有機物を**活性炭**に吸着させます。温度や湿度が高いと、吸着する力が落ちるので、**破過時間は短くなります**（「温度が低いほど短い」は誤りです）。

また、沸点が低く、活性炭に吸着されにくいメタノール・ジクロロメタン・二硫化炭素・アセトンなどは、除毒能力試験の試験用ガス（シクロヘキサン）より、**破過時間が著しく短く**なります。

**吸収缶の交換時期**は、使用時間で決めるのが基本ですが、**臭気を感知できる濃度が、ばく露限界濃度より著しく低い**物質だけは、においを感じたときを交換の目安にできます（においに気づいた時点で、まだ濃度が十分に低いので、安全側）。「ばく露限界濃度にかかわらず、臭気の有無を交換時期の判断基準としてはならない」は、誤りです。

### 防じんマスクの使い方

- **接顔メリヤス**（面体の接顔部に付ける布）を使うと、すき間ができて、**密着性が下がる**ので、使いません。
- 再使用のとき、ろ過材の粉じんを、**圧縮空気で吹き飛ばしたり、強くたたいて払い落としたり**してはいけません（ろ過材が傷む）。
- **使い捨て式**も、厚生労働大臣の規格があり、**型式検定の対象**です。

### 耳栓

耳栓には、**1種**（低音から高音までを遮音）と、**2種**（主に高音を遮音し、会話程度の低音は比較的通す）があります。1種と2種の取り違えが、誤りの形です。

## 4. 解き方・覚え方

1. 「呼吸用保護具の記述で、誤っているもの」は、まず**①**を見ます。「18％未満」の文に、**電動ファン付き**か**防毒マスク**が入っていたら、誤りです。
2. 防毒マスクの問は、**色**（黒・赤・緑）、**直結式と隔離式**の広さ、**温度の向き**（高いほど短い）、**臭気の条件**の4か所を順に確かめます。
3. 防じんマスクの問は、「**密着性を高めるため**」「**吹き飛ばす**」という、よさそうな言い方が出たら、誤りです。

| 項目 | 覚え方 |
|---|---|
| 一酸化炭素用 | ホプカライトの触媒で、一酸化炭素を無害化する。色は赤 |
| 隔離式 | 濃度が 2％を超える場所（アンモニアは 3％）では使えない |
| 防じんマスクの選定 | 有害性の高い物質を扱う作業は、取替え式を選ぶ |
| 遮光保護具 | アーク溶接用は、レーザー保護めがねとして使えない |

## 5. 例題

- `2021-02|ippan|17`：労働衛生保護具の、誤りを選ぶ問。**「酸素濃度 18％未満でも使える保護具には、送気マスク、空気呼吸器のほか、電動ファン付き呼吸用保護具がある」が誤り（正答）**。電動ファン付きは使えない。接顔メリヤスが密着性を下げること、有害性の高い物質には取替え式を選ぶことは、正しい。
- `2022-02|ippan|18`：防毒マスクの、誤りを選ぶ問。**「直結式は、隔離式より、使用できる対象ガス濃度の範囲が広い」が誤り（正答）**。隔離式のほうが広い。アンモニア用が緑・硫化水素用が黄であること、一酸化炭素用がホプカライトを使うこと、ジクロロメタン・二硫化炭素の破過時間が試験用ガスより短いことは、正しい。
- `2020-08|ippan|18`：防毒マスクの、誤りを選ぶ問。**「一酸化炭素用防毒マスクの吸収缶の色は黒色」が誤り（正答）**。赤。ハロゲンガス用が灰色と黒の二層であること、隔離式の有機ガス用は 2％を超える場所で使えないこと、臭気で交換時期を決められる物質の条件は、正しい。
- `2021-02|ippan|18`：防毒マスクの、誤りを選ぶ問。**「有機ガス用の吸収缶は、温度が低いほど破過時間が短くなる」が誤り（正答）**。高いほど短い。
- `2022-02|ippan|17`：労働衛生保護具の、誤りを選ぶ問。**「面体と顔面の密着性を高めるため、接顔メリヤスを装着して使うのがよい」が誤り（正答）**。使い捨て式防じんマスクが検定の対象であることは、正しい。
