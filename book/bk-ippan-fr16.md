## 3. 防じんマスク・電動ファン付き呼吸用保護具

### テーマ2　防じんマスクの区分と使い方［S］

**出題実績**：23回（選択肢）。

**表②　防じんマスク**（登録講習テキスト 第5編 第2章、令和5年5月25日 基発0525第3号。原文で確認）

| 項目 | 内容 |
|---|---|
| 種類 | **取替え式**（**R**。隔離式・直結式。**吸気弁・排気弁**がある）と、**使い捨て式**（**D**。弁がないもの、**排気弁のみ**のもの）。面体は、全面形と半面形 |
| 区分の読み方 | **R／D**：取替え式／使い捨て式。**S／L**：固体の粒子のみ／**液体（オイルミスト）**と固体の粒子（**Lタイプ**は、オイルミストが混在する場所で使える）。**1・2・3**：粒子捕集効率の区分で、**3が最高**。RS2とDS2では、**RS2が取替え式、DS2が使い捨て式** |
| 捕集効率 | **同じ区分なら、使い捨て式と取替え式で、粒子捕集効率は同じ**（使い捨て式が低い、ではない） |
| ヒューム | **使い捨て式も、ヒュームに使える**。金属のヒューム（溶接ヒュームを含む）・鉛は、**RS2・RL2・DS2・DL2以上**（通達） |
| 区分の選び方（登録講習テキスト 表5.2） | ①**放射性物質がこぼれたとき等による汚染のおそれがある区域内の作業**、**ダイオキシン類**のばく露のおそれのある作業：**RS3・RL3**。**オイルミスト等が混在する場合は、RL3**。②金属のヒューム、管理濃度が0.1 mg/m³以下の粉じん：RS2・RS3など、2以上。③それ以外：1以上も可。**放射性物質による汚染のおそれのある区域では、使い捨て式は使えない** |
| 選ぶとき | 有害性が高い、又は高濃度ばく露のおそれがあるときは、**粒子捕集効率が高く**、**排気弁の動的漏れ率が低い**ものを。**顔面と面体の高い密着性が要求される有害性の高い物質**を取り扱う作業は、**取替え式** |
| 酸素濃度・ガス | **酸素濃度18％未満**、**有毒ガス等が存在**する場所では、使ってはならない（防毒マスク、G-PAPR、給気式を使う） |
| 着用 | **接顔メリヤス**は、原則として、使用しない（**密着性が低下**する）。タオル、ひげ・もみあげ・前髪の挟み込みも、行わない。ヘルメットの上からのしめひもも、行わない。着用のつど、**密着性の良否を確認**する |
| ろ過材の交換 | 息苦しさを感じたら、交換する。使い捨て式は、息苦しさを感じたとき、又は表示されている**使用限度時間**に達したときは、廃棄。ヒ素・クロムなど有害性の高い粉じんに使ったろ過材、石綿・インジウムの作業で使ったろ過材は、**1回使うごとに廃棄** |
| 手入れ | ろ過材に付着した粉じんを、**圧縮空気で吹き飛ばしたり、たたいて払い落としたりしてはならない**（ろ過材を破損し、粉じんが再飛散する） |
| **電動ファン付き呼吸用保護具（PAPR）** | **ろ過式**。電池・モーター・ファンで、浄化した空気を送る。**防じん機能のもの（P-PAPR）**と**防毒機能のもの（G-PAPR）**がある。**酸素濃度18％未満では、使えない**。粒子の漏れ率の性能が高い順に、**S級・A級・B級**。面体形のものは、通常、面体内が陽圧。**吸気補助具付き防じんマスク**は、面体内が陽圧に保たれない場合がある。いずれも、厚生労働大臣の規格がある |

**ひっかけパターン**（過去問で誤りとして出た組）

- 「防じんマスクの装着で、密着性を高めるため、**接顔メリヤス**を装着するのがよい」（誤り。密着性が低下する）。
- 「**使い捨て式**防じんマスクは、**ヒューム**には使えない」「溶融金属の表面から発生するヒュームに**効果がない**」（誤り。使える）。
- 「使い捨て式は、取替え式に比べ、**同じ区分でも粒子捕集効率が低い**」（誤り）。
- 「**RS2は使い捨て式、DS2は取替え式**」（逆）。
- 「防じんマスクの再使用のため、**圧縮空気**で、ろ過材上の粉じんを**吹き飛ばして**払い落とす」（してはならない）。
- 「RL1、RL2、RL3のうち、粒子捕集効率が最も大きいのは**RL3**」は正しい。

**例題**（2022-08|ippan|17）接顔メリヤス、使い捨て式の放射性区域、アーク溶接用遮光保護具、手入れ、RS2・DS2、のうち誤っているもの。
→ 「RS2が使い捨て式、DS2が取替え式」（逆。Rが取替え式）。

## 4. 防毒マスク

### テーマ3　防毒マスクの種類・吸収缶・破過［S］

**出題実績**：23回中20回（問18・19）。

**表③　防毒マスク**（登録講習テキスト 第5編 第2章、防毒マスクの規格、令和5年5月25日 基発0525第3号、JIS T 8152:2012〔表13〕。サイト側の確認〔令和8年11月5日〕）

| 項目 | 内容 |
|---|---|
| 種類と使用範囲 | **隔離式**：ガス又は蒸気の濃度が**2％（アンモニアは3％）以下**。**直結式**：**1％（アンモニアは1.5％）以下**。**直結式小型**：**0.1％以下**で、**非緊急用**（酸素濃度18％以上）。**隔離式が、最も高濃度**で使える（直結式の方が広い、ではない）。酸素濃度が**18％未満**の場所では、使えない（送気マスク等） |
| 吸収缶の色 | **有機ガス用＝黒**。**一酸化炭素用＝赤**。**アンモニア用＝緑**。**亜硫酸ガス用＝黄赤**。**ハロゲンガス用＝灰色と黒の二層**（以上は、防毒マスクの規格の表）。**酸性ガス用＝灰色**、**硫化水素用＝黄色**、**シアン化水素用＝青色**は、規格の表になく、**JIS T 8152:2012（表13）**の色（JISだけの色：臭化メチル用＝茶色、水銀用・ホルムアルデヒド用・エチレンオキシド用・メタノール用・リン化水素用＝オリーブ色。複数のガスに対応する吸収缶は、色を縞状に並べて表示する）。外部の側面が色分けされ、**色分け以外の方法でも種類が表示**される（規格第8条第5項） |
| 防じん機能 | 有毒ガスと粉じんが**混在**する場所（吹付け塗装の、有機溶剤の蒸気と塗料の粒子など）：**防じん機能を有する防毒マスク**（区分S1・S2・S3・L1・L2・L3）、G-PAPR、給気式。吸収缶の**ろ過材のある部分に、白線**が入っている。吸収缶は、粉じんをほとんど通さない、のではない |
| 破過・破過時間 | 吸収剤が飽和して、除毒能力を失うことを**破過**、そこまでの時間を**破過時間**という。**ガス濃度に反比例**し、高濃度では短い |
| 温度・湿度 | **有機ガス用**：使う環境の**温度又は湿度が高いほど、破過時間が短く**なる。**沸点が低い物質ほど顕著**。**一酸化炭素用**：湿度が高いほど、破過時間が短くなる |
| 有機ガス用の吸収缶 | 試験用ガスは**シクロヘキサン**（除毒能力試験）。**メタノール、二硫化炭素、ジクロロメタン、アセトン**などは、破過時間が**著しく短い**（活性炭にほとんど吸収されない、など）。これらに使った吸収缶は、吸着物が脱着して面体内に漏れ出すことがあるため、**再使用しない** |
| **一酸化炭素用** | **ホプカライト**を使い、**触媒作用**で一酸化炭素を**二酸化炭素に変えて**無害化する。**活性炭の吸着ではない**。低濃度では、触媒作用が緩慢で、効率が低い（防毒マスクを避けて、送気マスクを使う） |
| 使用時間の管理 | **使用時間記録カード**に、使用した時間を記録し、**破過曲線図**と比べて、使用限度時間を超えて使わない。破過を知るために、**有毒ガス等の臭いに頼るのは、適切でない**（令和5年の通達） |
| 複数の有毒ガスが混在 | **それぞれの有毒ガスについて合格した吸収缶**を選ぶ。**最も毒性の強いガス用の防毒マスクだけでは、よくない**。破過した吸収缶をそのまま使うと、**環境濃度より高い濃度**のガス・蒸気を吸入するおそれがある |
| 酸素欠乏・不明 | 有害物質の種類・濃度が不明、酸素欠乏のおそれがある場所では、ろ過式（防毒マスク）を使ってはならない。**給気式**を使う（酸素欠乏のおそれがある場所では、指定防護係数1,000以上の全面形面体の給気式） |
| 保管 | 吸収缶は、吸湿・乾燥で能力が低下するため、使用直前まで開封しない。使用後は、上栓・下栓を閉める。ビニール袋に入れて密閉する |

**臭いによる交換時期**（旧通達と、現行の通達）

| | 内容 |
|---|---|
| 旧（平成17年の防毒マスク通達。令和5年に廃止） | 防毒マスクの使用中に臭気等を感知した時点を、吸収缶の交換時期とする方法は、**有害物質の臭気等を感知できる濃度が、ばく露限界濃度より著しく小さい物質に限り**、行って差し支えない（アセトン、酢酸エチル、スチレン、メチルエチルケトンなどが例示されていた） |
| 現行（令和5年5月25日 基発0525第3号） | 着用者の感覚では、有毒ガス等の危険性を感知できないおそれがあるので、吸収缶の破過を知るために、**有毒ガス等の臭いに頼るのは、適切ではない**。臭気等の異常を感知したら、速やかに作業を中止して避難する |

過去問（令和2年度第1回、令和3年度第1回、令和4年度第1回）には、旧通達の考え方で出た記述がある（「臭気を感知できる濃度がばく露限界濃度より著しく低い物質に限って、吸収缶の交換時期を臭気を感知した時点とすることができる」は、当時、正しい記述）。令和8年度第2回以降は、現行の通達にもとづく記述が出題されうる。

**ひっかけパターン**（過去問で誤りとして出た組）

- 「**直結式**防毒マスクは、**隔離式**より使用できる濃度の範囲が**広い**」（逆。隔離式が広い）。
- 「**一酸化炭素用**防毒マスクは、**活性炭**で一酸化炭素を吸着して取り除く」「一酸化炭素用の吸収缶の色は**黒色**」（ホプカライトの触媒作用。色は赤。黒は有機ガス用）。
- 「有機ガス用防毒マスクの吸収缶は、使用する環境の**温度が低い**ほど破過時間が短くなる」（逆。温度又は湿度が**高い**ほど短い）。
- 「複数の有毒ガスが混在する場合、**最も毒性の強いガス用**の防毒マスクを使う」（誤り）。
- 「防毒マスクの吸収缶は、**粉じんをほとんど通さない**ため、ガスと粉じんが混在する環境で、防毒マスクを使う」（誤り。防じん機能を有する防毒マスクを使う）。
- 「防毒マスクを着用するときは、**ヘルメットの上から**しめひもを使うと、密着性が高まる」（誤り。行わない）。
- 「国内で使用される防毒マスクは、有害ガスの種類にかかわらず、**型式検定の対象**」（誤り。5種類のみ）。

## 5. 面体の密着の確認（フィットテスト・シールチェック）

### テーマ4　フィットテストとシールチェック［B］

**出題実績**：選択肢として、密着性の確認方法（陰圧法・陽圧法）が出る。

**表④　面体の密着**（令和5年5月25日 基発0525第3号。原文で確認）

| 項目 | 内容 |
|---|---|
| **フィットテスト** | 面体を有する呼吸用保護具を使う労働者について、**1年以内ごとに1回**。顔面と面体との密着の程度を示す係数（**フィットファクタ**）を求め、**要求フィットファクタを上回っている**ことを確認する。顔に合った面体を選ぶ方法。顔との密着を要求しない**ルーズフィット形**は、対象外 |
| **シールチェック** | 面体を着用した直後に、**労働者自身**が、装着状態の密着性を調べる方法 |
| 陰圧法 | **吸気口をふさいで**、息をゆっくり**吸う**。空気が面体内に流入せず、**面体が顔面に吸いつけられる**ことを確認する |
| 陽圧法 | **排気口をふさいで**、息を**吐く**。空気が面体内から流出せず、呼気が滞留して、**面体が膨張する**ことを確認する |
| 着用の留意 | しめひもは、**耳にかけず**、**後頭部**で固定する。**タオル**を挟む、**ひげ・もみあげ・前髪**の挟み込み、**ヘルメットの上からしめひも**を使うことは、行わない |

**ひっかけパターン**：「**陽圧法**は、息を**吸って**、面体が顔面に吸いつけられるかを確認する」（逆。吸うのが陰圧法）。

## 7. 解き方・覚え方のまとめ

1. **酸素濃度18％未満・濃度不明は、給気式**：防じんマスク・防毒マスク・電動ファン付き呼吸用保護具（ろ過式）は、使えない。使えるのは、**送気マスク、空気呼吸器、酸素呼吸器**。
2. **防じんマスクの記号**：**R＝取替え式、D＝使い捨て式。S＝固体のみ、L＝オイルミストも。数字が大きいほど、捕集効率が高い**。放射性・ダイオキシン類は、**RS3・RL3**（オイルミストがあれば、RL3）。
3. **使い捨て式の誤解を疑う**：使い捨て式も、**ヒュームに使える**。同じ区分なら、**捕集効率も同じ**。
4. **防毒マスクの数字**：隔離式 2％（アンモニア3％）、直結式 1％（アンモニア1.5％）、直結式小型 0.1％。**隔離式が最も高濃度**。
5. **色**：**有機ガス＝黒、一酸化炭素＝赤、アンモニア＝緑、亜硫酸ガス＝黄赤、酸性ガス＝灰色、硫化水素＝黄、シアン化水素＝青、ハロゲンガス＝灰色と黒**。
6. **一酸化炭素用は、触媒**（ホプカライト）。**活性炭の吸着ではない**。
7. **温度・湿度が高いほど、破過時間は短い**（有機ガス用）。メタノール・二硫化炭素・ジクロロメタン・アセトンは、破過時間が著しく短い。使った吸収缶は、再使用しない。
8. **混在**：粉じんとガスが混在＝防じん機能付き防毒マスク。ガスが2種類以上＝それぞれ合格した吸収缶。
9. **臭いで吸収缶の交換時期を決めない**（現行の通達）。
10. **手入れ・着用の禁止**：ろ過材を**圧縮空気で吹く、たたく**。**接顔メリヤス**、**タオル**、**ヘルメットの上からのしめひも**。
11. **そのほか**：耳栓と耳覆いの併用は可。防振手袋に、他の手袋を重ねない。化学防護手袋は、使用可能時間を超えたら再使用しない。保護めがねは粒子・飛沫、遮光保護具は有害光線。
