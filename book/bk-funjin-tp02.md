## 9. 解き方・覚え方のまとめ

1. **検量線**：縦軸＝補正した石英強度、横軸＝石英量。標準試料は、0.2〜1.2 mg/cm²、7段階。
2. **炭酸カルシウムがあれば、基底標準板は亜鉛をやめて、アルミニウム**。
3. **遊離けい酸が見えなければ、感度を上げて再分析。それでも見えなければ 0％**。
4. **検出下限 3σ（÷勾配）、定量下限 10σ**。簡易には、√N。
5. **尖鋭でない理由**：受光スリットが広い、玉ずいが多い。**遅い走査・狭いスリット・光軸のずれ**は、理由にならない。
6. **対象鉱物**：石英・クリストバライト・トリジマイト・オパール・玉ずい・けい藻土。**対象外**：滑石・カオリン。
7. **りん酸法**：定量下限 **1％**。最適加熱条件は、**微斜長石 1％以下・石英 95％以上**。**クリストバライト・トリジマイトには使わない**。
8. **分粒装置**：流速が速いほど、50％分粒粒径は**小さい方**。**圧力計**で採取量の目安。**堆積粉じんは、腰より高い位置**。
9. **位相差顕微鏡**：位相板（対物）とリング絞り（コンデンサー）。

**公式まとめ（暗記の1行表）**

| 項目 | 内容 |
|---|---|
| 検出下限・定量下限 | 3σ／k、10σ／k（k：検量線の勾配） |
| りん酸法の定量下限 | 石英 1％ |
| 最適加熱条件 | 微斜長石の残渣 ≦ 1％、石英の残渣 ≧ 95％ |
| 検量線用標準 | 0.2〜1.2 mg/cm²、7段階 |
| 吸入性粉じん用インパクター | 相対沈降径 4.0 μm の粒子を 50％除去 |
| 石英の転移温度 | 573℃（α石英 ⇔ β石英） |
