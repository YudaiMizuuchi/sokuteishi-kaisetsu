鉱物性粉じんの**問15〜19**は、毎回、**X線回折分析**。誤っているものを選ぶ形と、**計算**（回折角、石英含有率、吸収補正係数）が出る。選択肢は、**原子番号の大小（1小さい／1大きい）、高角度側と低角度側、広くなる・狭くなる**の一語を入れ替えてある。

この章は、X線回折の**原理**（ブラッグの条件、特性X線とフィルター、基底標準吸収補正法）と、**計算**を、そろえる。ほかの章との分担：定性分析・検量線の作り方・装置の条件・りん酸法・対象鉱物は `bk-funjin-tp02`。

## 導入クイズ

**Q1** ブラッグの条件を表す式は、どれか。

① 2d sinθ ＝ nλ　② d sinθ ＝ nλ　③ 2d cosθ ＝ nλ

**Q2** 対陰極が Cu のとき、Kβ線を除くフィルターに使う物質は、どれか。

① Ni（原子番号が1小さい）　② Zn（原子番号が1大きい）

**Q3** 基底標準吸収補正を行うと、定量範囲は、どうなるか。

① 広くなる　② 狭くなる

答え：Q1は①（d は格子面間隔、θ はブラッグ角、λ は X線の波長、n は整数）。Q2は①（銅の Kβ線の吸収端を利用する。Ni の薄膜）。Q3は①（吸収の影響を補正するので、定量範囲が広くなる）。

## 2. ブラッグの条件と回折線

### 原理1　ブラッグの条件（pr-funjin-0011）［S］

**出題実績**：8回（走査速度・回折角計算の話題。平成28年度第1回、平成29年度第1回、令和元年度第1回〜令和5年度第1回、令和7年度第1回）。

**原理**：結晶は、原子が規則正しく並び、格子面をつくる。格子面の間隔 d と同じ程度の波長のX線が入ると、行路差が波長の整数倍のとき、回折X線が強め合う。行路差は 2d sinθ なので、

**2d sinθ ＝ nλ**（d：格子面間隔、θ：ブラッグ角〔入射角〕、λ：X線の波長、n：整数）

これが、回折が起こる条件（ブラッグの条件）。回折線は、ブラッグの条件を満たす方向にだけ、生じる（平成27年度第1回・平成30年度第1回）。λ が分かっている特性X線を当て、回折角（2θ）を測れば、d が計算できる（J11 7.2.1）。JIS K 0131:1996 は、n＝1 の形（2d sinθ ＝ λ）で書き、Kα₁と Kα₂が分離しているときは、Kα₁の波長で d を求める。

**表①　対陰極が Cu のときの回折角（2θ）**（過去問の正答。d は、この章で、λ＝1.54 Å〔Cu の Kα。一般に知られる値で、テキストでは未確認〕として、ブラッグの式から計算）

| 鉱物 | 回折角（2θ） | d（Å） |
|---|---|---|
| **石英**（主回折線） | **26.66°** | 3.34 |
| 石英（3強線のほか） | **20.87°**、**50.18°** | 4.26、1.82 |
| **クリストバライト**（主回折線） | **22.0°** | 4.04 |
| **トリジマイト**（単斜晶系。主回折線） | **20.5°** | 4.33 |

- 石英の3強線の組は、**20.87°、26.66°、50.18°**（令和元年度第1回）。
- 石英の回折角でないものとして、**22.00°**（令和4年度第1回）。クリストバライトの回折角は、22.00°（令和3年度第1回）。
- 石英の主回折線を、トリジマイトの値（d：3.34 Å）とする文は、誤り。トリジマイトの主回折線（d：4.33 Å）は、20.5°（令和2年度第1回・令和4年度第1回）。

**計算**（この章で計算）：d＝3.34 Å のとき、sinθ＝1.54／（2×3.34）＝0.2305。θ≒13.33°。2θ≒**26.66°**。

**ひっかけパターン**：「石英の主回折線（d：3.34 Å）は、**トリジマイト**（単斜晶系）の主回折線」（令和5年度第1回）。回折角の取り違え（石英を 22.0°、クリストバライトを 26.66° など）。

**覚え方**：「**石英 26.66°**」「**クリストバライト 22.0°**」「**トリジマイト 20.5°**」。d が大きいほど、2θ は**小さい**。

**走査速度**：ゴニオメータの走査速度が**速すぎる**と、回折線の**ピーク位置のずれ**と**強度の低下**が生じる（令和4年度第1回の正しい選択肢。ほか、平成29年度第1回〜令和5年度第1回）。回折線の**ピーク位置・強度に影響する**（J11 表7.1：定量分析の走査速度は、1／4〜1°/min）。

**例題**（`2022-08|funjin|15`、`2021-08|funjin|17`、`2019-08|funjin|16`、`2025-08|funjin|17`、`2021-08|funjin|18`）。

## 3. 特性X線とフィルター

### 原理2　特性X線と Kβ除去フィルター（pr-funjin-0012）［S］

**出題実績**：10回（平成28年度第1回、平成29年度第1回、令和元年度第1回〜令和8年度第1回）。

**原理**：X線管球は、タングステンなどのフィラメントの熱電子を、高電圧で加速して、金属の対陰極に衝突させる。放射されるX線は、連続X線と、元素に特有の**特性X線**から成る（J11 7.1.1）。内側（K殻）の電子が飛び出し、あとの空孔に外側の電子が落ちこむとき、エネルギー差がX線になる。**L殻からK殻**に落ちこむものが **Kα線**、**M殻からK殻**のものが **Kβ線**（J11 7.1.2）。

**表②　特性X線とフィルター**（J11 7.1・7.2.1、JIS K 0131:1996、過去問の正答）

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **波長と原子番号** | 特性X線の波長は、K・L 系列ごとに異なるが、**原子番号が大きくなると短く**なる（令和2年度第1回〜令和8年度第1回の選択肢） | 「原子番号が大きくなると**長く**なる」（令和2年度第1回） |
| **Kα の波長の順** | Cr、Fe、Cu の Kα の波長は、短い方から **Cu、Fe、Cr**（原子番号が大きい順）。Cu の Kα は、Fe の Kα より**短い** | Cu の Kα が Fe の Kα より「**長い**」（平成28年度第1回） |
| **Kβ除去フィルター** | 対陰極より、原子番号が **1小さい**物質（Cu には **Ni**）。K吸収端を利用して、Kα は通し、Kβ は吸収する | 「原子番号が **1大きい**」（Cu に **Zn**。令和元年度第1回・令和3年度第1回・令和6年度第1回）。「**1又は2大きな**」（令和8年度第1回） |
| **モノクロメーター** | グラファイトや水晶の単結晶で、回折X線をもう一度回折させる。Kβ線は**ほぼ完全に除去**され、蛍光X線のバックグラウンドも除かれる。**Kβフィルターを使う場合より、回折X線の強度は弱い** | 「モノクロメーターにより単色化した回折X線の強度は、Kβ除去フィルターによる場合より**強い**」（令和7年度第1回） |
| **単色化の理由** | Kα と Kβ が混ざると、同じ格子面から複数のピークが生じ、解析が複雑になる | — |
| **対陰極の条件** | 印加電圧を上げると、連続X線の強度は電圧の**2乗**に比例して強くなる。管電流を上げると、**波長は変わらず**、強さが電流にほぼ**比例**する | 「特性X線の強度は、印加電圧の値にかかわらず、**印加電圧と管電流の積**に比例する」（平成29年度第1回） |

**覚え方**：「**フィルターは、1小さい**（Cu→Ni）」。「**原子番号が大きいほど、波長は短い**」。「**モノクロは、きれいだが、弱い**」。

**例題**（`2026-08|funjin|15`、`2025-08|funjin|16`、`2024-08|funjin|14`、`2022-08|funjin|15`、`2020-08|funjin|15`）。

## 4. 基底標準吸収補正法

### 原理3　基底標準吸収補正法（pr-funjin-0013）［S］

**出題実績**：12回（平成27年度第1回〜令和8年度第1回の、毎回）。

**原理**（J11 7.2.3）：回折線の強度 I は、試料中の含有率 W に比例し、**試料の平均質量吸収係数に反比例**する。同じ含有率でも、ほかの成分が違うと、回折線の強度が変わる。粉じんのような**微量試料**は、厚さが薄く、吸収の影響が小さい。しかし、吸収を無視できる範囲は、きわめて狭い。そこで、**銀メンブランフィルター又はメンブランフィルターに捕集**して、**吸収補正法と直接法を、1回の測定で同時に行う**のが、**基底標準吸収補正法**（作業環境測定で広く応用）。

**表③　基底標準吸収補正法**（J11 7.2.3、過去問の正答。手順の詳細は、ガイドブックにもとづく：未確認）

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| **目的** | 試料による吸収の影響を補正して、遊離けい酸含有率の**多少にかかわらず**、標準試料で作った検量線を**そのまま適用**できるようにした方法 | — |
| **補正の考え方** | 試料の**後ろ**に置いた**基底標準物質**の回折強度の**変化量**から、試料のX線吸収量を補正する | — |
| **基底標準板** | 石英の測定回折線より**高角度側**で、それに**近い**回折線をもつ材質（**亜鉛又はアルミニウム**）（11回） | 「石英の測定回折線より**低角度側**」（令和2年度第1回・令和7年度第1回） |
| **補正係数** | 使用X線の波長が一定なら、粉じん採取**前後**の**基底標準物質の回折強度の減少率の関数**（令和5年度第1回） | 「**計測された金属の回折線の強度と、石英の回折線の強度との比**から求める」（平成30年度第1回・令和元年度第1回・令和4年度第1回） |
| **測定の手順** | 粉じん**採取前**のフィルターを載せた金属板の回折強度。**採取後**のフィルターを載せた金属板の回折強度と、**石英**の回折線強度 | — |
| **検量線** | **縦軸**に、**吸収補正係数を乗じた石英の回折線強度**、**横軸**に、石英量（mg/cm²） | — |
| **定量範囲** | 吸収補正を行うと、**定量範囲は広く**なり、夾雑物（マトリックス）の吸収の影響を少なくできる（精度が向上する） | 「定量範囲は**狭く**なる」「**やや狭く**なる」（令和3年度第1回・令和6年度第1回・令和8年度第1回） |
| **空隙** | フィルターが湾曲して、金属基底標準板との間に空隙があると、結果に**影響する** | 「多少の空隙があっても、定量分析結果に**影響はない**」（令和5年度第1回） |

**計算**（この章で計算。過去問と同じ型）

石英含有率（％）＝（**補正係数 × 石英の回折線強度**）÷（**単位量当たりの強度**）× フィルターの面積 ÷ 粉じんの質量 × 100

有効直径 20 mm のフィルターの面積は、π × 1.0² ＝ **3.14 cm²**。

- 令和8年度第1回：粉じん 1.26 mg、強度 280 cps、補正係数 1.25、1 mg/cm² で 7,000 cps。補正後の強度 ＝ 280 × 1.25 ＝ 350 cps → 350／7000 ＝ 0.050 mg/cm² → 0.050 × 3.14 ＝ 0.157 mg → 0.157／1.26 ＝ 0.125 → **12.5％**。
- 令和7年度第1回（クリストバライト）：1.26 mg、325 cps、6,500 cps（1 mg/cm²）、補正係数 1.20。325 × 1.20 ＝ 390 cps → 0.060 mg/cm² → 0.188 mg → **15％**。
- 令和6年度第1回（補正係数を求める）：含有率 12.0％、粉じん 1.20 mg、強度 280 cps、7,000 cps（1 mg/cm²）。石英量 ＝ 1.20 × 0.12 ＝ 0.144 mg → 0.0458 mg/cm² → 必要な強度 ＝ 0.0458 × 7000 ＝ 321 cps。補正係数 ＝ 321／280 ＝ **1.15**。

**覚え方**：「**後ろの金属が、どれだけ弱まったか**が、補正係数」（石英との比ではない）。「**基底標準は、高角度側**」。「**補正しても、定量範囲は広がる**」。

**例題**（`2026-08|funjin|17`、`2026-08|funjin|18`、`2025-08|funjin|19`、`2024-08|funjin|19`、`2023-08|funjin|18`、`2022-08|funjin|18`）。

## 5. 解き方・覚え方のまとめ

1. **ブラッグの条件は、2d sinθ ＝ nλ**。回折線は、この条件を満たす方向だけに生じる。
2. **Cu の 2θ：石英 26.66°（ほか 20.87°・50.18°）、クリストバライト 22.0°、トリジマイト 20.5°**。取り違えが、ひっかけ。
3. **特性X線の波長は、原子番号が大きいほど短い**。Kα の波長は、Cu < Fe < Cr。
4. **Kβ除去フィルターは、対陰極より原子番号が1小さい**（Cu → Ni）。「1大きい」は、誤り。
5. **モノクロメーター**：Kβ をほぼ除去。ただし、**フィルターより強度は弱い**。
6. **走査速度が速すぎる**と、ピーク位置がずれ、強度が低下する。
7. **基底標準吸収補正法**：標準試料の検量線を、そのまま適用。**基底標準板は高角度側**（亜鉛・アルミニウム）。**補正係数は、基底標準の強度減少率の関数**。**定量範囲は広がる**。
8. **検量線**：縦軸＝補正係数を乗じた石英強度、横軸＝石英量。
9. **計算**：石英含有率＝（補正係数×強度／単位強度）×面積（3.14 cm²）÷ 粉じん質量 × 100。
