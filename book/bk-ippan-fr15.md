この章では、局所排気装置の**フードの型式、制御風速の定義、ダクトの圧力損失、機器の並び**を整理します。労働衛生一般の問16・問17に、ほぼ毎回出る範囲です。装置の働きの原理は、ほかの章（`bk-ippan-0026`）で扱い、ここでは、問題文の言い回しの**正誤の見分け方**に絞ります。

## 導入クイズ

**Q1** 囲い式フードの制御風速は、フード開口面の「最小風速」か「平均風速」か。

**Q2** 同じ断面積のダクトで、圧力損失が大きいのは、円形か長方形か。

答え：Q1は、最小風速。Q2は、長方形（コーナー部の抵抗が大きい）。

## 1. この章の要点

- 局所排気装置の流れは、**フード → 枝ダクト → 主ダクト → 空気清浄装置 → ファン（排風機）→ 排気ダクト → 排気口**。
- **ダクトの圧力損失**：長いほど大きい。断面積を小さくすると大きい。同じ断面積なら**長方形が円形より大きい**。
- **囲い式フード**の制御風速は、開口面の**最小風速**（平均風速は誤り）。**外付け式フード**は、捕捉点（開口面から最も離れた点）の風速。
- **建築ブース型**は囲い式。**キャノピ型**は、熱による上昇気流を利用するレシーバ式。
- **排風機は、空気清浄装置の後**。**フランジ**を付けると、少ない排風量ですむ。**合流角度は 45° を超えない**。外付け式は、**下方吸引型の方が上方吸引型より有効**（熱による上昇気流がある場合を除く）。

## 2. しくみ（原理）

### 装置の流れと、機器の並び

局所排気装置は、有害物質を発生源の近くで吸い込み、屋外に出す装置です。**フード**で捕まえ、**ダクト**で運び、**空気清浄装置**できれいにし、**ファン（排風機）**で吸引して、**排気口**から出します。

**排風機は、空気清浄装置の後**に置きます。空気清浄装置の前に置くと、有害物質（粉じんなど）がファンに付着して、腐食や劣化の原因になります。「排風機を、吸引ダクトと空気清浄装置の**間**に設ける」は、誤りです。粉じん障害防止規則も、除じん装置を付ける局所排気装置の排風機は、**除じんをした後の空気が通る位置**に置くと定めています。

### フードの型式と制御風速

フードは、大きく3つに分けます。

- **囲い式**：発生源を囲って、有害物質が外に出ないようにする。**排気効果が最も大きい**。カバー型・グローブボックス型、ドラフトチェンバ型、**建築ブース型**。なお、スロット型は**外付け式**です（「囲い式に分類される」は誤り）。ドラフトチェンバ型は囲い式です（「外付け式」は誤り）。建築ブース型は、**作業面を除き周りが覆われている**ので、囲い式です。「外付け式に分類される」は誤りです。
- **外付け式**：発生源の外から、吸い込み気流で吸引する。側方・**下方**・上方吸引型がある。**下方吸引型や側方吸引型の方が、上方吸引型より、一般に有効**です（熱による上昇気流がある場合を除く。上昇気流があるときは、上方で吸うのが合理的）。
- **レシーバ式**：発生源から、一定方向に飛ぶ（流れる）気流に乗った有害物質を受けて捕集する。**キャノピ型**は、熱による上昇気流を利用します。

**制御風速**は、「発散し、拡散しようとする有害物質を捕捉する、吸い込み気流の**最低**風速」です。測る場所は、フードの型式ごとに決まっています。

- **囲い式**：フード**開口面における最小風速**。「平均風速」は、誤り。
- **外付け式**：有害物質を吸引しようとする範囲内で、**開口面から最も離れた点（飛散限界＝捕捉点）**における風速（最小風速）。

「最低風速」だから、囲い式の制御風速は、開口面の**最も遅いところ**で決めます（平均で測ると、遅い部分から漏れる）。また、局所排気装置の制御風速を「作業者の呼吸位置で必要な最小の風速」とするのは、誤りです。

### ダクトの圧力損失

ダクトは、有害物質を含む空気を運ぶ管で、空気を運ぶときの**抵抗（圧力損失）**が生じます。

- **長いほど、圧力損失は大きい**。曲がり部（ベンド）が多いほど大きい。だから、ダクトは、できるだけ短く、曲がりを少なく配管します。
- **断面積を小さくすると、圧力損失は大きく**なります（空気の流れが速くなり、壁面との摩擦が増える）。反対に、**断面積を大きく**すると、圧力損失は**小さく**なりますが、排風量が一定なら、**搬送速度は遅く**なります（遅すぎると、粉じんがたまる）。
- **同じ断面積なら、長方形（角形）は円形より圧力損失が大きい**（コーナー部の抵抗が大きい）。円形がよい。
- 主ダクトと枝ダクトの**合流角度は、45° を超えない**ようにします（急な合流は、乱れて、損失が大きくなる）。

### フランジ：吸い込む範囲を限る

フード開口部の周囲に**フランジ**（つば）を付けると、**後ろ側からの空気を吸わなくなる**ので、前方の空気を効率よく吸えます。だから、フランジがないときに比べて、**少ない排風量**で、同じ効果が得られます。「大きな排風量が必要になる」は誤りです。

## 4. 解き方・覚え方

「局所排気装置の誤っているもの」は、次の順で見ます。

1. **「平均風速」**（囲い式の制御風速）があれば、まず疑う。
2. **圧力損失**：断面積の大小と、円形・長方形の向きを確認する（「円形の方が大きい」は誤り）。
3. **機器の並び**：排風機は、空気清浄装置の**後**。
4. **フランジ**：少ない排風量。「大きな排風量」は誤り。
5. 分類：建築ブース型・ドラフトチェンバ型は**囲い式**、キャノピ型は**レシーバ式**。

暗記の1行表：

| 項目 | 内容 |
|---|---|
| 囲い式の制御風速 | 開口面の最小風速 |
| 外付け式の制御風速 | 開口面から最も離れた点（捕捉点）の風速 |
| 圧力損失が大きい | 長い、細い、角形 |
| 排風機 | 空気清浄装置の後 |
| フランジ | 少ない排風量 |
| 合流角度 | 45° を超えない |
| 外付け式フード | 下方吸引型が有効（上昇気流がある場合を除く） |
| キャノピ型 | レシーバ式（熱による上昇気流） |

## 5. 例題

- `2025-02|ippan|17`：局所排気装置の、誤りを選ぶ問。**「囲い式フードの制御風速は、フード開口面における平均風速である」が誤り（正答）**。最小風速が正しい。外付け式の制御風速（開口面から最も離れた点の風速）、建築ブース型が囲い式であること、断面積を小さくすると圧力損失が増えること、合流角度が 45° を超えないことは、正しい。
- `2021-02|ippan|16`：**「ダクトの断面積が同じなら、円形は長方形に比べて圧力損失が大きい」が誤り（正答）**。長方形の方が大きい。下方吸引型の有効性、囲い式の制御風速が最小風速であること、断面積を大きくすると圧力損失が小さくなり搬送速度が遅くなること、空気清浄装置が吸引ダクトと排風機の間にあることは、正しい。
