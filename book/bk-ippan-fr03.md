労働衛生一般の**問3**は、令和5年度第1回から令和8年度第1回まで**7回連続**で、「化学物質による健康影響及びその管理指標等」。毒性試験の値（LD₅₀、NOAEL など）と、試験の名前が問われる。**問20**は、確認できた令和2年度第1回〜令和8年度第1回の13回すべてで、**管理濃度と許容濃度**。どちらも「誤っているものを選ぶ」形で、選択肢は、定義の一語（個体／集団、最高／最低、算術／幾何、あり／なし）を入れ替えてある。

この章は、**指標の定義を、1つずつ、一語まで**そろえる。ほかの章との分担：管理区分を決める計算は `bk-design-forms`、リスクアセスメントと濃度基準値は `bk-ippan-fr01`、吸収・代謝・生物学的モニタリングは `bk-ippan-fr04`、物質別の症状は `bk-ippan-fr06`、粉じん・じん肺は `bk-ippan-fr07`。

**Q1** 許容濃度が想定している労働として、正しいのは、どれか。

① 1日8時間、週40時間程度、肉体的に激しくない労働　② 1日12時間、肉体的に激しい労働　③ 短時間の作業だけ

① 作業者1人ひとりの個人ばく露濃度　② 単位作業場所の測定値を統計処理した値（評価値）　③ 住宅の室内空気の濃度

## 2. 毒性を表す指標（問3）

### テーマ1　毒性試験の値：LD₅₀・LC₅₀・NOEL・NOAEL・LOEL・LOAEL・VSD［B］

**出題実績**：問3に、令和5年度第1回から7回連続（選択肢。問題文に「健康影響及びその管理指標」）。

**表①　毒性試験の値**（根拠：過去問の正答。登録講習テキストは、LD₅₀・LC₅₀を急性毒性のデータ、NOAEL・NOEL を、ばく露限界を推定する材料として書く〔第4編 第5章3〕。定義の文言は、過去問による）

| 略称 | 名前 | 意味 | 見るもの |
|---|---|---|---|
| **LD₅₀** | 半数致死量 | **1回の投与**で、一群の試験動物の**50％が死亡する**と予想される投与量 | **急性毒性** |
| **LC₅₀** | 半数致死濃度 | **短時間の吸入ばく露**で、一群の実験動物の**50％を死亡させる**と予想される濃度 | **急性毒性** |
| **NOEL** | 無影響量（テキストは「最大無作用量」） | 毒性試験で、**影響が認められなかった最高**のばく露量 | 慢性毒性 |
| **LOEL** | 最小影響量 | 毒性試験で、**何らかの影響が認められた最低**のばく露量 | 慢性毒性 |
| **NOAEL** | 無毒性量 | 毒性試験で、**有害な影響が認められなかった最高**のばく露量 | ばく露限界を決める材料 |
| **LOAEL** | 最小毒性量 | 毒性試験で、**有害な影響が認められた最小**のばく露量 | ばく露限界を決める材料 |
| **VSD** | 実質安全量 | **しきい値がないとされる発がん物質**のリスク評価に使う。がんのリスクの増加が、**ある限られた確率以下**にとどまると考えられる量 | 発がん物質のリスク評価 |

NOEL・LOEL を慢性毒性の指標とすることは、過去問の正答による（令和8年度第1回 問3）。テキストに、急性・慢性の仕分けは、書かれていない。

**覚え方**

- 「無（NO）」は、影響が出ない**最高**の量。「最小（LO）」は、影響が出る**最低**の量。ばく露量の線の上で、2つの値は隣り合う（NO が下側、LO が上側）。
- 「影響」と「毒性」の違いは、**有害（AE＝adverse effect）かどうか**。NOEL・LOEL は、有害でなくても、影響があれば数える。NOAEL・LOAEL は、**有害な**影響だけを数える。
- 「半数致死」の半数は、**動物の50％**。投与量の半分ではない。

**ひっかけパターン**（過去問で誤りとして出た組）

- LD₅₀ を「試験動物の**致死量の1／2**に相当する投与量」（半数は、動物の50％が死亡する量。令和8年度第1回）。
- LD₅₀ を「**慢性毒性**を評価する指標」（急性。令和5年度第1回）。
- 急性毒性の指標として、「**NOEL や NOAEL**」（急性の指標は、LD₅₀・LC₅₀。令和7年度第1回）。
- 「しきい値が**ない**発がん物質のリスク評価には **NOAEL**、しきい値が**ある**物質には **LOAEL**」（組合せが違う。しきい値がない発がん物質は VSD。令和7年度第2回）。

正しい選択肢として、繰り返し出た組（おとり）：LC₅₀・LD₅₀は、いずれも急性毒性の指標。NOEL は、影響が認められなかった最高のばく露量。LOAEL は、有害な影響が認められた最小のばく露量。

**例題**（`2026-08|ippan|3`、`2026-02|ippan|3`、`2025-08|ippan|3`）：選択肢のなかの、名前と定義の組を、表①で一つずつ照らす。

### テーマ2　量-影響関係と量-反応関係［C］

**表②　量-影響関係と量-反応関係**（登録講習テキスト 第2編 第4章2）

| | 量-影響関係 | 量-反応関係 |
|---|---|---|
| 見る相手 | **個体**（個人） | **集団**（有害物質にばく露した人の集まり） |

**覚え方**：「**反応**する人の**割合**＝**集団**」。「**影響**の**大きさ**＝**個体**」。

## 3. スクリーニング試験と生殖毒性（問3）

### テーマ4　変異原性試験・催奇形性試験・生殖毒性［C］

**出題実績**：5回（問3の選択肢。令和5年度第1回〜令和8年度第1回のうち）。

**表④　試験の名前と、見るもの**（登録講習テキスト 第2編 第6章3、過去問の正答。生殖毒性の定義は、許容濃度等の勧告〔2025年度〕の V も確認）

| 試験・用語 | 見るもの | ポイント |
|---|---|---|
| **変異原性試験** | 化学物質が、**細胞の遺伝子に突然変異**を引き起こすかどうか（遺伝情報の異常） | **発がん性のスクリーニング試験**として使う。**細菌**を用いるものが広く使われる。哺乳類培養細胞を用いる**染色体異常試験**も、発がん性のスクリーニング試験（過去問） |
| **催奇形性試験** | 化学物質が、**胎児期の臓器・組織の形成**に与える影響 | 発がん性の試験では**ない** |
| **生殖毒性** | **性機能及び生殖能**への悪影響と、**子の発生**への悪影響 | 勧告では、男女両性の生殖機能への有害な影響と、次世代児（胎児・乳児）への有害な影響を、まとめて扱う |

テキストは、変異原性を、遺伝子突然変異だけでなく、染色体の形態や数の変化による遺伝情報の異常も含む、と書く。がん化は、正常な細胞の、発がん遺伝子や発がん抑制遺伝子の変化で進む。このため、変異原性試験は、発がん性の試験の一つとして使われる。

**ひっかけパターン**（過去問で誤りとして出た組）

- **変異原性試験**を「化学物質による**胎児期の臓器・組織形成**への影響を見る試験」（催奇形性試験の定義との入れ替え。令和6年度第1回）。
- 発がん性のスクリーニング試験に、「変異原性試験や**催奇形性試験**」（催奇形性試験は、胎児。令和6年度第2回）。

正しい選択肢として出た組（おとり）：変異原性試験は、発がん性のスクリーニング試験。細菌を用いる変異原性試験と、哺乳類培養細胞を用いる染色体異常試験は、いずれも発がん性のスクリーニング試験。催奇形性試験は、胎児の臓器・組織形成への影響をみる。

**覚え方**：「**変異**＝**遺伝子**＝**がん**」。「**奇形**＝**胎児**」。

**例題**（`2024-08|ippan|3`、`2025-02|ippan|3`）：変異原性試験と催奇形性試験の定義が、入れ替わっていないかを見る。

## 4. 許容濃度（問20）

### テーマ5　許容濃度の定義と使い方［S］

**出題実績**：22回（問20の選択肢。問題文に「許容濃度」）。

**表⑤　許容濃度（日本産業衛生学会）の性格**（登録講習テキスト 第2編 第5章1.2、許容濃度等の勧告〔2025年度〕の「性格および利用上の注意」と I・II・表I-3、過去問の正答）

| 項目 | 内容 |
|---|---|
| **定義** | 労働者が**1日8時間、週40時間程度**、**肉体的に激しくない**労働強度で、有害物質にばく露される場合に、**平均ばく露濃度**がその数値以下であれば、**ほとんどすべての労働者**に健康上の悪い影響が見られないと判断される濃度 |
| **ばく露濃度** | **呼吸用保護具を装着していない**状態で、労働者が作業中に吸入するであろう空気中の濃度 |
| **最大許容濃度** | **作業中のどの時間をとっても**、ばく露濃度がその数値以下であれば、ほとんどすべての労働者に健康上の悪い影響が見られないと判断される濃度。刺激や中枢神経抑制など、短時間で出る影響が主な物質に使う |
| **濃度変動** | **変動の幅があまり大きくない場合**に利用する（平均の指標のため） |
| **経皮吸収** | 数値は、**経皮吸収がない**ことを前提に提案されている。「**皮**」の印は、皮膚と接触して、経皮的に吸収される量が、全身への健康影響又は吸収量からみて、**無視できない程度**に達することがある物質 |
| **ほかの条件** | 許容濃度を使うときは、**労働強度、温熱条件、気圧**（放射線も）などを考える。これらで、健康への影響が強まることがある |
| **混合** | 同様の健康影響を起こす2種以上の物質：各物質の濃度を、その許容濃度で割った値の**総和 I が1を超える**と、許容濃度等を超える曝露と判断する |
| **毒性の比較** | 数値は、物質の**毒性の強さの相対的な比較の尺度に、使ってはならない**（考えた影響の種類が、物質ごとに違う） |
| **労働の場以外** | 数値を、**労働の場以外**での環境要因の許容限界値に使ってはならない |
| **生物学的許容値** | 生物学的モニタリング値が、その勧告値の範囲内であれば、ほとんどすべての労働者に健康上の悪い影響が見られないと判断される濃度 |
| **勧告の範囲** | 化学物質のほか、**騒音、振動、高温、寒冷**などの物理的因子の許容基準も、勧告されている |
| **粉じんの許容濃度** | 第1種、第2種、第3種の粉塵に分け、**第1種が最も小さい**（吸入性粉塵で、0.5、1、2 mg/m³。表I-3） |

このほか、勧告は、ばく露が最大になると予想される時間を含む15分間の平均ばく露濃度が、許容濃度の1.5倍を超えないことが望ましい、と書く（特に注記のない限り。出題実績なし）。

**登録講習テキストとの違い**：混合物質の扱いは、テキストが「相加が成り立たないことを示す証拠がない場合は、毒性は相加と想定」と書く。2025年度の勧告は、「同様の健康影響を発生させる2種以上の物質」と書く。令和7年度第1回の過去問は、「健康影響が相加されると仮定できる場合」の書き方で、勧告に近い（食い違うときは、現行の勧告を優先）。

**ひっかけパターン**（過去問で誤りとして出た組）

- 許容濃度の数値は、「種類の異なる物質の**毒性の強さの相対的な尺度に用いることができる**」（用いてはならない。令和4年度第2回・令和3年度第2回）。
- 許容濃度は、「**経皮吸収を考慮して**定められている」（経皮吸収がないことを前提とする。令和5年度第1回・令和3年度第1回・令和元年度第1回ほか）。
- 「皮」の物質は**経皮吸収があることを前提**に、それ以外は経皮吸収がないことを前提に定められている（皮の有無にかかわらず、**経皮吸収がない前提**。令和6年度第2回）。
- 許容濃度は、作業環境測定の**第1評価値及び第2評価値と比較**して用いる指標（評価値と比べるのは、管理濃度。平成27年度第1回）。

正しい選択肢として、繰り返し出た組（おとり）：許容濃度は、変動があまり大きくない場合に使う（11回）。数値は、経皮吸収がないことを前提に勧告されている（6回）。1日8時間・1週40時間程度、肉体的に激しくない労働を想定（5回）。労働強度・温熱条件・気圧などを考える。労働の場以外の許容限界値には使わない。「皮」の物質は、経皮的に吸収されやすい（言い換え。平成27年度第2回）。

**覚え方**

- 「**皮**」は、**注意の印**。数値は、皮の有無にかかわらず、**経皮吸収がない前提**。皮のある物質は、皮膚から吸収されると、数値を守っても、ばく露が増える。
- 許容濃度は、**平均**の指標（8時間の平均ばく露濃度）。だから、変動が大きいと、使えない。
- 「許容」は、**人**（個人のばく露）の物差し。「管理」は、**場所**の物差し（テーマ7）。

## 7. 解き方・覚え方のまとめ

1. **問3は、名前と定義の組を、一語ずつ照らす**：LD₅₀＝**急性**・**1回の投与**・**50％が死亡**。NOEL・NOAEL＝影響（有害な影響）が出ない**最高**の量。LOEL・LOAEL＝影響（有害な影響）が出る**最低**の量。AE（有害）が付くと「毒性」。
2. **量-影響＝個体・影響の大きさ**。**量-反応＝集団・影響を示した人の割合**（S字状）。入れ替えが、ひっかけ。
3. **急性か慢性か**：LD₅₀・LC₅₀は**急性**。NOEL・LOELは**慢性**。急性毒性の指標に「NOEL や NOAEL」は、誤り。
4. **しきい値**：しきい値がある物質は、NOAEL などから、ばく露限界を決める。**しきい値がない発がん物質は、VSD**。この組を崩した選択肢が、ひっかけ。
5. **ばく露限界**＝ほとんど全ての労働者が、影響を受けないと考えられる、濃度・量の**しきい値**。**TLV-TWA**＝8時間・週40時間。**TLV-STEL**＝どの15分間でも超えない。**TLV-C**＝瞬間的にでも超えない。**BEI**＝生物学的モニタリング。
6. **試験**：変異原性試験＝**遺伝子**の突然変異＝発がん性のスクリーニング。催奇形性試験＝**胎児**の臓器・組織形成。入れ替えが、ひっかけ。
7. **許容濃度は、人・平均・時間つき**：1日8時間・週40時間程度、肉体的に激しくない労働。**変動が大きくない**ときに使う。**経皮吸収がない前提**（皮の有無にかかわらず）。**毒性の比較に使えない**。**労働の場以外に使えない**。評価値とは比べない。
8. **勧告の分類**：発がん性は**第1群・第2群A・第2群B**（第3群は、ない）。感作性・生殖毒性は**第1〜第3群**。第1群は「明らか（知られている）」、第2群は「おそらく」。**第1群にも、許容濃度のある物質がある**。
9. **管理濃度は、場所・時間なし**：評価値（統計処理した値）と比べる。**ばく露限界ではない**。**天井値はない**。有機溶剤は**すべて ppm**。**25℃、1気圧**。特定化学物質には、定められていないものがある。特別管理物質にも、定められているものがある。
10. **粉じんの式は「遊離けい酸」と「1.19」**：E＝3.0／（1.19 Q＋1）。**混合有機溶剤は、濃度÷管理濃度の和、基準は1**（含有率は掛けない）。
11. **評価値**：第1評価値＝高濃度側5％の推定値。第2評価値＝**算術**平均の推定値。D測定値は、管理濃度と直接比べる。
