この章では、金属類の分析の**標準液を、どの試薬で調製するか**と、**水銀の標準液の保存**を整理します。「金属 → 標準液の試薬」の1つの表を覚えれば、金属類の各問で、1行ずつ得点できます。

## 導入クイズ

**Q1** バナジウムの標準液の調製に使う試薬は何か。

**Q2** 水銀の標準液は、ポリエチレン容器で保存してよいか。

答え：Q1は、メタバナジン酸アンモニウム。Q2は、よくない（硬質ガラス容器に入れて、冷暗所で保存する）。

## 1. この章の要点

- **標準液の試薬**は、金属ごとに決まっている（下の表）。**試薬の組合せを入れ替えた形**が、誤りとして出る。
- **水銀の標準液**は、**硬質ガラス容器**に入れて、**冷暗所**で保存する。**ポリエチレン・テフロンの容器は用いない**。
- **ヒ素**（水素化物発生原子吸光）は、三酸化二ヒ素を**アルカリ溶液**に溶かす。**希硝酸では溶かさない**。
- **マンガン**（原子吸光）は、**酸化マンガン(Ⅳ)**（過マンガン酸カリウムではない）。

## 2. しくみ（原理）

### 標準液の試薬は、「純粋で、水に溶け、組成が一定」な化合物

標準液は、**濃度が正確にわかっている液**です。そのもとになる試薬は、**組成が一定**で、**水（や酸）によく溶け**、**安定**な化合物が選ばれます。金属ごとに、次の試薬が使われます。

| 金属・分析法 | 標準液の調製 |
|---|---|
| クロム(Ⅵ) | **二クロム酸カリウム**又は**クロム酸カリウム**を、精製水に溶かす |
| バナジウム | **メタバナジン酸アンモニウム**（温精製水に溶かす） |
| マンガン（原子吸光） | **酸化マンガン(Ⅳ)**（塩酸に加熱溶解） |
| ヒ素（水素化物発生原子吸光） | **三酸化二ヒ素**を、**水酸化ナトリウム溶液**（アルカリ）に溶かす |
| カドミウム | **塩化カドミウム（無水物）**を精製水に溶かし、硝酸（又は塩酸）を加える |
| ベリリウム（蛍光光度） | **硫酸ベリリウム（四水和物）**を精製水に溶かし、硫酸を加える |
| 水銀（原子吸光） | 塩化水銀(Ⅱ)を精製水に溶かし、硫酸を加える |

### 取り違えの形（それぞれの理由）

- **マンガン**：「過マンガン酸カリウムを用いて調製する」は、**原子吸光分析法では誤り**（酸化マンガン(Ⅳ)）。吸光光度分析法では、過マンガン酸カリウムを使うので、問題文が「原子吸光分析法」かどうかを見ます（8回中1回が誤りの形）。
- **ヒ素**：三酸化二ヒ素は、水や**希硝酸には溶けにくく**、**アルカリ溶液**に溶けます。「**希硝酸で溶解**して調製する」は誤り（4回中3回が誤りの形）。なお、吸光光度分析法では、**10 M 硝酸**で加熱して溶かします。
- **カドミウム**：「**硝酸カドミウム**を精製水に溶かして」は誤り（4回中1回）。**塩化カドミウム（無水物）**。
- **ベリリウム**：硫酸ベリリウムは、**四水和物**（結晶水を持つ）のまま用います。「**高温乾燥後、使用する**」は誤り（3回中1回）。高温にすると結晶水が失われ、組成が変わってしまうためです。

### 水銀の標準液は、容器に注意

水銀は、**容器の壁に吸着しやすく**、また、**還元されて逃げやすい**金属です。

- **ポリエチレン**：表面に吸着しやすく、ポリエチレン自身に**還元性**もあります。水銀は、とくにこの影響を受けやすい。
- **テフロン**：金属の溶出は少ないが、**表面吸着性は、硬質ガラスより大きい**。

だから、水銀の標準液（標準原液）は、**硬質ガラス容器**に入れ、**冷暗所**で保存します。「ポリエチレン容器で、安定に保存できる」「テフロン容器なら、保存可能」は誤りです（6回中2回）。

## 4. 解き方・覚え方

「標準液の調製・保存」の選択肢は、**金属 → 試薬**の対応と、**保存容器**を、1つずつ確かめます。

1. **マンガン**は、問題文が**原子吸光**なら、**酸化マンガン(Ⅳ)**。
2. **ヒ素**は、**アルカリ**に溶かす。希硝酸は誤り。
3. **水銀**は、**硬質ガラス・冷暗所**。ポリエチレン・テフロンは誤り。

暗記の1行表：

| 金属 | 試薬 |
|---|---|
| クロム(Ⅵ) | 二クロム酸カリウム、クロム酸カリウム |
| バナジウム | メタバナジン酸アンモニウム |
| マンガン（原子吸光） | 酸化マンガン(Ⅳ) |
| ヒ素（水素化物発生） | 三酸化二ヒ素 ＋ 水酸化ナトリウム |
| カドミウム | 塩化カドミウム（無水物） |
| ベリリウム | 硫酸ベリリウム（四水和物） |

## 5. 例題

- `2020-08|kinzoku|16`：水素化物発生原子吸光分析法によるヒ素の測定の、誤りを選ぶ問。**「ヒ素の標準原液は、三酸化二ヒ素を希硝酸で溶解して調製する」が誤り（正答）**。アルカリ溶液に溶かす。予備還元に塩化スズ(Ⅱ)とヨウ化カリウムを用いること、水素-アルゴンフレームで原子化することは、正しい。
- `2023-08|kinzoku|17`：原子吸光分析法による水銀の分析の、誤りを選ぶ問。**「標準液は、テフロン容器を用いれば保存可能である」が誤り（正答）**。硬質ガラス容器に入れて、冷暗所で保存する。捕集に過マンガン酸カリウム-希硫酸を用いること、共存する水蒸気が妨害物質となることは、正しい。
