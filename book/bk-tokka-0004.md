この章では、特定化学物質の分析で使う**検出器**（GC の FID・FPD・ECD など、HPLC の紫外可視・電気化学）を、**「どんな物質に反応するか」**から整理します。特定化学物質の問5〜問10に、ほぼ毎回出る範囲です。中心は、**物質に含まれる元素（硫黄・リン・窒素・ハロゲン）と、検出器の組合せ**です。同じ検出器の章は有機溶剤にもあります（`bk-yuki-0011`）。

## 導入クイズ

**Q1** 炎光光度検出器（FPD）は、ベンゼンの検出器として使えるか。

**Q2** ホルムアルデヒドの検出器に、水素炎イオン化検出器（FID）は適しているか。

答え：Q1は、使えない（ベンゼンは、硫黄もリンも含まない）。Q2は、適さない（FID は、ホルムアルデヒドを検出しない）。

## 1. この章の要点

- **FPD（炎光光度検出器）**：**リン・硫黄**を含む化合物に選択性がある（還元炎を用いる）。ベンゼン、ホルムアルデヒド、アクリルアミド、ジクロロメタンには使えない。
- **ECD（電子捕獲検出器）**：**電子親和力の強い物質**（ハロゲン化合物など）を高感度で検出する。直線範囲は、FID より**狭い**。ベンゼン、エチルベンゼン、ナフタレン、アクリロニトリルには使えない。
- **FID（水素炎イオン化検出器）**：水素炎中で**燃焼してイオン化する物質のみ**を検出する。**ホルムアルデヒド**は検出されない。ハロゲン化炭化水素への感度は低い。
- **紫外可視吸光光度検出器**（HPLC）：紫外可視部に吸収のある物質（**芳香族炭化水素**、不飽和炭化水素）に使える。
- **電気化学検出器**（HPLC）：**酸化または還元される物質**を検出する。

## 2. しくみ（原理）

### 検出器は、「反応のしかた」で、向く物質が決まる

検出器は、物質が示す**ある性質**を、電気信号に変えます。だから、その性質をもつ物質にしか、反応しません。

- **FID**：水素炎の中で、物質が**燃えてイオンになる**と、電極の間に電流が流れる。**燃えてイオンになる物質**（ほとんどの有機化合物）が対象。燃えにくい物質（ハロゲン化物、酸化物など）は感度が低く、無機の酸化物は検出されない。**ホルムアルデヒド**、ギ酸、二硫化炭素などは、有機化合物でも検出されない。
- **FPD**：水素の量を多くした**還元炎**の中で、**リン・硫黄（・スズ）**を含む化合物が、**特定の波長の光**を出す。その光を測る。だから、**リンや硫黄を含む化合物にだけ**反応する。
- **ECD**：放射性同位元素（ニッケル63など）の**β線**で電子を出させ、電子電流を流しておく。そこに、**電子を捕まえやすい物質**が入ると、電流が減る。**ハロゲンを含む化合物**などに、高感度。応答の**直線範囲は狭い**。
- **TID（FTD）**：アルカリ塩をつけた白金コイルで、**窒素・リン**を含む化合物がイオン化して、電流が増える。
- **MS（質量分析計）**：成分をイオン化して、質量電荷比ごとに検出する。**分子構造の情報**が得られ、多くの物質の同定に使える。

HPLC の検出器は、次のとおりです。

- **紫外可視吸光光度検出器**：紫外〜可視の光の**吸収**を測る。**吸収のある物質**（芳香族炭化水素、不飽和炭化水素など）が対象。
- **電気化学検出器**：電極で**酸化または還元**される物質が、電子を出し入れする電流を測る。酸化・還元できる物質が対象で、高感度・高選択性。

### 物質の「元素」から、検出器を選ぶ

特定化学物質の問は、「物質 ／ 検出器」の組合せを、「不適当なもの」として選ばせます。物質に含まれる**元素**で、判断します。

| 物質（含む元素・性質） | 適当な検出器 | 不適当な検出器（過去問） |
|---|---|---|
| 硫酸ジメチル、硫化水素（硫黄を含む） | **FPD** | |
| アクリロニトリル、アクリルアミド（窒素を含む） | **FTD（TID）** | アクリロニトリル／**ECD**、アクリルアミド／FPD |
| MOCA、塩素化ビフェニル（塩素を含む） | **ECD** | |
| ナフタレン、DDVP、o-フタロジニトリル | **MS** | ナフタレン／**ECD** |
| 臭化メチル、塩化ビニル | **FID** | |
| ジクロロメタン（硫黄もリンもない） | | ジクロロメタン／**FPD** |
| ホルムアルデヒド | | ホルムアルデヒド／**FID** |

**考え方**：硫黄・リンを含むなら FPD、窒素・リンなら FTD、ハロゲンなど電子親和力の強い基なら ECD、炭化水素などなら FID、構造がわかればよいなら MS。**ベンゼン、ナフタレンのように、炭化水素だけの物質に、ECD や FPD は使えません**（ハロゲン・硫黄・リンがないため）。

## 4. 解き方・覚え方

「検出器の誤っているもの」「組合せの不適当なもの」は、次の順で見ます。

1. **物質の元素**を確認する：S・P → FPD、N・P → FTD、ハロゲン → ECD。
2. **炭化水素だけの物質**（ベンゼンなど）に FPD・ECD が出たら、不適当。
3. **FID**：ホルムアルデヒドは検出されない。ハロゲン化炭化水素に感度が高い、は誤り。
4. HPLC：紫外可視は**吸収のある物質**、電気化学は**酸化還元できる物質**。

暗記の1行表：

| 検出器 | 向く物質 |
|---|---|
| FID | 燃えてイオン化する物質（ホルムアルデヒドは不可） |
| FPD | リン・硫黄を含む化合物 |
| ECD | 電子親和力の強い物質（ハロゲン） |
| FTD（TID） | 窒素・リンを含む化合物 |
| MS | 構造情報（同定） |
| 紫外可視 | 吸収のある物質（芳香族など） |
| 電気化学 | 酸化・還元される物質 |

## 5. 例題

- `2026-08|tokka|5`：GC検出器の、誤りを選ぶ問。**「炎光光度検出器は、窒素や硫黄を含む化合物に選択性がある」が誤り（正答）**。窒素ではなく、リンと硫黄。FID が燃焼してイオン化する物質のみを検出すること、ECD が電子親和力の強い物質を高感度で検出すること、ECD の直線範囲が FID より狭いこと、質量分析計が分子構造情報を得られることは、正しい。
- `2025-08|tokka|5`：特定化学物質と GC 検出器の、不適当な組合せを選ぶ問。**「アクリロニトリル ／ 電子捕獲検出器（ECD）」が不適当（正答）**。アクリロニトリルは、窒素を含む（FTD が適当）が、ハロゲンを含まないので、ECD には向かない。アクリルアミド／FTD、臭化メチル／FID、ナフタレン／MS、硫酸ジメチル／FPD は、適当な組合せ。
