労働衛生関係法令の**問1**は、23回すべて、「労働（安全）衛生管理体制」。誰を、何人以上の事業場で、いつまでに、どんな資格の者から選ぶか、が問われる。誤っているものを選ぶ形で、人数の数字（50人、300人、500人、1,000人、3,000人）と、業種、専属・専任、が1つだけ崩してある。この章は、その数字を、1つの表にそろえる。教育（問3）と、化学物質管理者（問2）も、ここに加える。

## 導入クイズ

**Q1** 衛生管理者は、選任すべき事由が発生した日から何日以内に選任するか。

① 7日　② 14日　③ 30日

**Q2** 常時1,500人の労働者を使用する事業場で、選任しなければならない衛生管理者は、何人以上か。

① 3人　② 4人　③ 5人

**Q3** 事業場の労働者で、作業環境測定を実施している作業環境測定士を、衛生委員会の委員にすることについて、正しいのはどれか。

① 指名しなければならない　② 指名することができる　③ 指名できない

答え：Q1は②（14日。規則第7条第1項第1号）。Q2は②（千人を超え二千人以下は4人。規則第7条第1項第4号）。Q3は②（指名することができる。法第18条第3項）。3問とも、この章の表の1行で答えが出る。

| 種類 | 内容 |
|---|---|
| **雇入れ時・作業内容変更時の教育**（法第59条第1項・第2項、規則第35条） | 労働者を**雇い入れたとき**、**作業内容を変更したとき**は、**遅滞なく**、従事する業務に関する安全・衛生のための教育を行う。十分な知識・技能があれば、その事項は**省略**できる |
| **特別教育**（法第59条第3項、規則第36条〜第39条） | **危険又は有害な業務**（規則第36条に列挙）に労働者を就かせるときは、**特別の教育**を行う。科目の全部又は一部に十分な知識・技能があれば、その科目は**省略**できる（第37条）。**受講者・科目等の記録を作成し、3年間保存**（第38条）。細目は、厚生労働大臣が定める（第39条）。**講師の要件を定める条文はない** |
| **職長等の教育**（法第60条、令第19条、規則第40条） | **建設業、製造業（たばこ製造業、繊維工業〔紡績業・染色整理業を除く〕、衣服その他の繊維製品製造業、紙加工品製造業〔セロファン製造業を除く〕を除く）、電気業、ガス業、自動車整備業、機械修理業**で、**新たに職務につくこととなった職長**（作業主任者を除く）に行う。**業種にかかわらず、ではない** |
| **能力向上教育等**（法第19条の2、第60条の2） | **衛生管理者、安全衛生推進者、衛生推進者**など、労働災害の防止のための業務に従事する者に、能力の向上を図るための教育・講習等を行い、又は受ける機会を与えるよう**努めなければならない**（努力義務）。危険又は有害な業務に現に就いている者への教育も、努力義務（第60条の2） |

**特別教育が必要な業務の例**（規則第36条）

| 必要な業務（例） | 号 |
|---|---|
| **アーク溶接**等の業務 | 第3号 |
| **高圧室内作業**に係る業務 | 第24号の2 |
| 酸素欠乏危険場所における作業に係る業務 | 第26号 |
| **エックス線装置・ガンマ線照射装置**を取り扱う業務 | 第28号 |
| **特定粉じん作業**に係る業務（注水・注油をしながら行うものを除く） | 第29号 |
| **ずい道等**の掘削等の業務 | 第30号 |
| **ダイオキシン類**対策の廃棄物焼却施設の、ばいじん・焼却灰を取り扱う業務、保守点検等、解体等の業務 | 第34号〜第36号 |
| **石綿則第4条第1項**の作業（建築物等の解体等）に係る業務 | 第37号 |

**特別教育が必要でない業務（過去問）**：**有機溶剤業務**、**特定化学物質**を取り扱う業務は、規則第36条に載っていない（作業主任者の選任で管理する）。**石綿の分析**の業務も、載っていない。

**ひっかけパターン**（過去問で誤りとして出た組）

- 「**有機溶剤業務**に労働者を就かせるときは、特別教育」（正しくは、特別教育の対象でない）。
- 「**業種にかかわらず**、新たに職務に就く**職長**に、教育を行わなければならない」（正しくは、令第19条の業種）。
- 「特別教育の**講師**は、法令で定める要件を満たす者」（要件の定めはない）。
- 「特別教育の科目は、十分な知識・技能があっても、**省略できない**」（正しくは、省略できる）。

## 8. 解き方・覚え方のまとめ

1. **問1は、数字の表を決まった順に思い出す**：総括（業種で100・300・1,000）→ 衛生管理者（50人以上、14日、専属、人数1〜6）→ 専任（1,000人超、500人超＋有害業務30人以上）→ 衛生工学（500人超＋有害業務30人以上）→ 産業医（50人以上、専属は1,000人以上又は有害業務500人以上、3,000人超で2人）→ 衛生委員会（50人以上、月1回）。
2. **「業種に関係なく」を疑う**：衛生管理者・産業医は、**業種に関係なく**50人以上。衛生委員会も50人以上だが、過去問は「業種に応じて、衛生委員会又は安全衛生委員会」を正しいとしている。業種で人数が変わるのは、総括安全衛生管理者（100・300・1,000人）。
3. **「準ずる者」を疑う**：総括安全衛生管理者に充てるのは、統括管理する者。議長・第1号委員は、準ずる者も可。
4. **作業環境測定士は、委員に「指名することができる」**。義務ではない。
5. **教育**：特別教育は、規則第36条の業務（有機溶剤は、ない）。職長教育は、令第19条の業種。能力向上教育は、努力義務。記録は3年。
