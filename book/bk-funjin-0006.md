この章では、鉱物性粉じんの問3・4によく出る、**慣性衝突式分粒装置（インパクター）**の原理を整理します。「ノズルで加速した空気が曲がるとき、慣性の大きい粒子は衝突板に当たる」という1本の筋から、**50％分粒粒径を決めるもの**、**流量が大きいとき**、**衝突板・ノズル孔の汚れ**の向きが分かります。分粒装置の種類は `bk-funjin-tp05` で扱います。

## 導入クイズ

**Q1** 円形ノズル式インパクターの50％分粒粒径は、ノズルを通過する空気の速度が速いほど、大きくなるか、小さくなるか。

**Q2** 衝突板に付着した粉じんが多くなると、通過する粒子の粒径は、大きい方へ移行するか、小さい方へ移行するか。

答え：Q1は、小さくなる。Q2は、大きい方へ移行する。

## 1. この章の要点

- 円形ノズル式インパクターの50％分粒粒径は、ノズルを通過する空気の**速度の1/2乗に反比例**します（粒子の密度の平方根にも反比例）。
- 吸引流量を所定より**大きく**すると、50％分粒粒径は**小さく**なり、測定値は**小さく**なります。

## 2. しくみ（原理）

### 衝突板に当たる粒子と、通り抜ける粒子

慣性衝突式分粒装置は、**ノズル**から空気を勢いよく噴き出し、すぐ前に置いた**衝突板**に当てます。空気は、衝突板に当たって、横に曲がります。このとき、**慣性の大きい（大きい・重い）粒子**は、曲がりきれず、まっすぐ進んで**衝突板に当たり、くっつきます**。**小さい粒子**は、空気と一緒に曲がって、衝突板を回り込み、**フィルターに届きます**。

吸入性粉じんの測定では、**相対沈降径 4 µm の粒子の50％**が衝突板に捕らえられるように作ってあります（この大きさが、**50％分粒粒径**）。

### ① 50％分粒粒径を決めるもの

ノズルを通る空気の**速度が速い**ほど、粒子の慣性が強まり、**小さい粒子まで**衝突板に当たります。つまり、**50％分粒粒径は小さく**なります（円形ノズルでは、速度の**1/2乗に反比例**）。粒子の**密度が大きい**ほど（重いほど）、同じく慣性が強いので、粒径は小さくなります。したがって、「粒子の密度の平方根に**比例**する」は誤りで、**平方根に反比例**します。

### ② 流量が大きいとき

吸引流量を大きくすると、ノズルを通る**速度が上がります**。すると、①のとおり、**50％分粒粒径は小さく**なります。衝突板に当たる粒子が増え、**フィルターに届く粉じんが減る**ので、**測定値は小さく**なります。「大きな流量で吸引すると、測定値は大きくなる」は誤りです。

### ③ 汚れ・付着

- **衝突板に粉じんが付着**すると、衝突板が粉じんで覆われ、当たった粒子が**はね返ったり（再飛散）**、はじかれたりします。大きい粒子も、衝突板に捕らえられずに通り抜け、**通過する粒子の粒径は、大きい方へ移行**します。フィルターに届く粉じんが増え、**測定値は大きく**なります。
- **ノズル孔に汚れが付着**すると、孔が狭くなり、空気の**速度が上がります**。①のとおり、**50％分粒粒径は小さい方へ移行**します。

**衝突板は大きい方、ノズル孔は小さい方**。向きが逆です。

## 3. 頻出の表

| 項目 | 正しい記述 | ひっかけパターン（誤り） |
|---|---|---|
| ① 50％分粒粒径を決めるもの（5回・A） | 円形ノズル式インパクターの50％分粒粒径は、ノズルを通過する空気の**速度の1/2乗に反比例**する | 「ノズルを通過する**粒子の密度の平方根（1/2乗）に比例**する」（5回中3回。どれも正答。正しくは、密度の平方根にも反比例） |
| ② 流量が大きいとき（5回・A） | 吸引流量（流速）を所定より大きくすると、50％分粒粒径は**小さく**なる（4回・B）。所定より大きな流量で吸引すると、測定値は**小さく**なる（3回・B） | 「大きな流量で吸引すると、測定値は**大きく**なる」（3回中1回。正答）。4回・B の論点は、すべて正しい記述 |
| ③ 汚れ・付着（5回・A） | 衝突板の付着粉じんが多くなると、通過する粒子の粒径は**大きい**方へ移行する（測定値は大きくなる）（5回・A）。ノズル孔に汚れが付着すると、**小さい**方へ移行する（2回・C） | どちらも、すべて正しい記述（衝突板とノズル孔で、向きが逆） |
| ④ 穴埋め（2回・C） | 「吸入性／衝突板／大きい／高い」（4 µm の粒子の50％が衝突板に捕集され、粒径が大きい粒子ほど高い効率で捕集される）、「吸入性／4 µm／大きく」（吸引流量が低下すると、50％分粒粒径は大きくなる） | 穴埋め・組合せの問題 |

## 4. 解き方・覚え方

向きは、**慣性が強いほど、小さい粒子まで当たる**で決めます。

1. **速度が速い・流量が大きい・密度が大きい** → 慣性が強い → 50％分粒粒径は**小さい** → 測定値は**小さい**。
2. **流量が小さい** → 50％分粒粒径は**大きい**（穴埋めの「吸引流量が低下すると、大きく」）。
3. **衝突板に粉じんがたまる** → 大きい粒子も通り抜ける → 粒径は**大きい方**へ、測定値は**大きく**。
4. **ノズル孔が汚れる** → 狭くなって速くなる → 粒径は**小さい方**へ。

| 覚えること | 一言 |
|---|---|
| 分粒粒径と速度 | 速度の1/2乗に**反比例**（密度の平方根にも反比例） |
| 流量が大きい | 分粒粒径**小**、測定値**小** |
| 衝突板の付着 | **大きい**方へ（測定値は大きい） |
| ノズル孔の汚れ | **小さい**方へ |
