この章では、原子吸光分析の3つの原理——**基底状態の原子が光を吸収する**こと、**光源が線光源（中空陰極ランプ）**であること、**バックグラウンド補正**——を説明します。金属類の問3〜問4（分析法と、その原理の基礎となる現象の組合せ）と問6〜問7（原子吸光分析法）で、ほぼ毎回出る範囲です。炎の種類や原子化は、`bk-kinzoku-0008` で扱います。

## 導入クイズ

**Q1** 原子吸光分析で、光を吸収するのは、基底状態の原子か、励起状態の原子か。

**Q2** 光源の輝線の線幅は、吸収線の線幅より広いか、狭いか。

答え：Q1は、基底状態の原子。Q2は、狭い。

## 1. この章の要点

- 光を吸収するのは**基底状態の原子**。吸光度は、**光路長**と、**基底状態の金属原子の濃度**の積に比例する。
- 光源は**線光源**で、ふつう**中空陰極ランプ**。**輝線の線幅は、吸収線の線幅より狭い**（「広い」は誤り）。
- 中空陰極ランプは、**陰極が測定対象金属（又はその合金）**。金属原子が**封入ガスのイオンと衝突して発光**し、その金属固有の輝線を出す。**至適電流値**で使う（感度のための高電流は誤り）。
- **バックグラウンド**は、**重水素ランプ**で補正する（タングステンランプは誤り）。

## 2. しくみ（原理）

### 原理1：光を吸うのは、基底状態の原子

試料の溶液を、炎（又は電気炉）で熱すると、金属の化合物が分解して、**原子の蒸気**になります（原子化）。原子は、ふつう、エネルギーのいちばん低い**基底状態**にあり、熱で、ごく一部が**励起状態**に上がります。基底状態の原子は、励起されるときに必要なエネルギーに当たる波長の光（**共鳴線**）だけを、選んで吸収します。これが**原子吸収**です。

炎の中の原子は、ほとんどが基底状態です。亜鉛のような励起されにくい原子は、5 000 K の炎でも、励起状態の原子が、基底状態の原子の**100万分の1**程度です。だから、**基底状態の原子の吸収**を測れば、ほとんどすべての原子を数えられます。炎が、**吸収セル**の役目をする、吸光光度法の一種と考えます。したがって、ランベルト・ベールの法則が成り立ち、

**吸光度 ＝ 吸光係数 × 光路長 × 基底状態の金属原子の濃度**

です。

基底状態を測ることには、もう1つの利点があります。炎の温度は、なかなか一定になりません。励起状態の原子が1.0％から1.1％に増えたとき、**発光**の強さは10％変わりますが、基底状態は99.0％から98.9％に減るだけで、**吸光度**は約0.1％しか変わりません。そのため、原子吸光分析は、発光分析より**精度が高く**、温度や共存物質の影響も受けにくくなります。

「分析法と、その原理の基礎となる現象」の組合せは、次のとおりです。

| 分析法 | 基礎となる現象 |
|---|---|
| 原子吸光分析法 | **基底状態の原子**が、共鳴線の光を**吸収**する |
| ICP 発光分光分析法（ICP-AES） | プラズマ中で**励起された原子（イオン）**が、**発光**する |
| ICP 質量分析法（ICP-MS） | 原子の**イオン化**（ICP でイオンにした原子を、質量数／電荷数の比で分けて検出する） |
| 吸光光度分析法 | **基底状態の分子・イオン**（キレート分子など）が、光を**吸収**する。吸収するのは、溶液の色の**補色**の光 |
| 蛍光光度分析法 | **励起状態の分子・イオン**が、基底状態に戻るときに出す**蛍光**（発光） |

誤りの形は、**「基底状態」と「励起状態」の入れ替え**です。いちばん多いのは、原子吸光を「**励起状態**の原子の光吸収」とする形で、ICP-AES を「基底状態の原子の発光」、蛍光光度を「基底状態の分子の発光」とする形も出ます。吸光光度を「**溶液の色に相当する波長**の光の吸収」とする形も、誤りです（吸収するのは、補色の光）。

### 原理2：光源は、「幅の狭い線」でなければならない

原子の吸収線は、**非常に細い**（線幅は0.001 nm 程度）。この細い吸収線に光を当てて吸収を測るには、光源の光も、**同じくらい細いか、もっと細い**必要があります。吸収線の細い窓に、細い光を通すイメージです。光源の線幅のほうが**広い**と、窓からはみ出した光は吸われずに素通りするので、吸収の割合が減り、**感度も精度も下がり**、検量線も曲がります。そこで、光源には、**線幅の狭い輝線**を出す**線光源**を使います。

その代表が、**中空陰極ランプ**です。

- **陰極**が、測定しようとする**金属（又はその合金）**でできていて、**アルゴンやネオンの低圧ガス**が封入されています。
- 電流を流すと、封入ガスのイオンが陰極に当たって、金属原子がはじき出されます。この金属原子が、さらに**封入ガスのイオンと衝突して励起され、金属固有の輝線を発光**します。だから、ランプは、**元素ごと**に必要です。
- **電流を大きくしすぎる**と、ランプの中の金属原子が増え、その原子が**自分の光を吸ってしまう（自己吸収）**ので、輝線の形が悪くなり、**感度が下がります**。寿命も縮みます。そのため、**指定された最適の電流値（至適電流値）**で使います。「感度を良くするために高電流で使用する」は誤りです。

### 原理3：バックグラウンド補正は、重水素ランプ

試料に塩類が多い、有機溶媒を使うなどすると、炎の中で、分子やすすのような粒子ができます。これが、光を吸収・散乱して、**原子ではないのに、吸収があるように見えます**（バックグラウンド吸収）。測定値に上乗せされるので、**補正**が必要です（分光干渉。バックグラウンド補正で除く）。

補正の基本は、**広い波長の光（連続光）**を使う方法です。

- 中空陰極ランプの光：**原子の吸収＋バックグラウンド吸収**を受ける。
- 連続光の光：細い吸収線を持つ原子にほとんど吸われず、**バックグラウンド吸収だけ**を受ける。
- 両者の**差**が、原子の吸収。

この連続光の光源が、**重水素ランプ**です。金属の共鳴線の多くは紫外部にあり（亜鉛は213.9 nm）、紫外部の連続光を出すのが重水素ランプだからです。タングステンランプは、可視部用の連続光源なので、ここでは使いません。重水素ランプは補正用であって、測定元素の**光源ではありません**。このほかの補正法に、ゼーマン効果を使う方法と、ランプの自己反転を使う方法があります。

## 4. 解き方・覚え方

1. **「線幅」が出たら、光源は「狭い」**。「広い」とあれば誤り。
2. **吸収するのは基底状態**。吸光度は「光路長 × 基底状態の原子の濃度」。発光（励起状態）との入れ替えに注意。
3. **中空陰極ランプ**：陰極＝測定金属、発光＝封入ガスのイオンとの衝突、電流＝至適（高電流は誤り）。
4. **バックグラウンド**は**重水素ランプ**（連続光）。タングステンは誤り。

|---|---|
| 吸収するもの | 基底状態の原子 |
| 吸光度 | 光路長 × 基底状態の原子の濃度に比例 |
| 光源 | 線光源（中空陰極ランプ） |
| 線幅 | 光源の輝線 ＜ 吸収線 |
| ランプの電流 | 至適電流値（高電流は誤り） |
| バックグラウンド補正 | 重水素ランプ |

## 5. 例題

- `2017-08|kinzoku|7`：原子吸光分析法の誤りを選ぶ問。**「光源の輝線の線幅は、吸収線の線幅よりも広い」が誤り（正答）**。狭い。中空陰極ランプを至適電流値で作動させること、吸光度が光路長と基底状態の原子の濃度の積に比例すること、封入ガスのイオンとの衝突で発光すること、電気加熱原子化法がフレーム法より感度が高いことは、正しい。決め手は、「線光源は、吸収線より細い」。
- `2019-08|kinzoku|6`：**「光源の輝線の線幅は、吸収線の線幅より広い」が誤り（正答）**。中空陰極ランプの陰極が測定対象金属又はその合金であること、封入ガスのイオンとの衝突で発光すること、吸光度が光路長に比例すること、電気加熱式原子化法がフレーム法より高感度であることは、正しい。
