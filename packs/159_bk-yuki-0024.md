## 原理：気体の体積とppm濃度の換算（pr-yuki-0024。原理としての回数 5回・A）

25℃・1気圧の気体1 molの体積は、24.45 L。体積分率（ppm）は、質量濃度÷モル質量×24.45で求める。

公式：ppm ＝ mg/m³ × 24.45 ÷ M

## 付録：ppm への換算の計算（全5問。問題文・選択肢・正答）

mg/m³ → ppm は、× 24.47 ÷ モル質量（25 ℃、1気圧）。全問を解き直して、正答と合うことを確かめてある。

- 2016-08（活性炭管）：脱着液 2.0 mL 中に 0.1 µg × (2000÷2) ＝ 100 µg。空気 0.2×10＝2 L → 50 mg/m³ → ×24.47÷60 ＝ 20.4 → **20 ppm**
- 2018-08（活性炭管）：0.1 µg × (1000÷1) ＝ 100 µg。2 L → 50 mg/m³ → ×24.47÷58 ＝ 21.1 → **20 ppm**
- 2019-08（真空捕集びん。標準ガスとの比）：標準ガス＝3.0×1.8/50＝0.108 µL → ×0.66＝71.3 µg → ÷86＝0.829 µmol → ×24.47＝20.3 µL → 1.0 L 中で 20.3 ppm。面積が 1/2 なので **10 ppm**
- 2023-08（同じ形）：標準ガス＝5.0×5.0/50＝0.50 µL → ×0.89＝445 µg → ÷88＝5.06 µmol → ×24.47＝123.7 ppm。面積が 1/5 なので 24.7 → **25 ppm**
- 2017-08（体積分率。気体の状態方程式）：通す前の量 ∝ 100×620÷295＝210.2、通したあと ∝ 110×550÷305＝198.4。減った 11.8 が、A の 0.90 倍 → A＝13.1。13.1÷210.2 ＝ **0.06**
